# Центр усунення несправностей

Цей посібник допомагає операторам збирати корисний контекст без обходу меж безпеки NOVUS OS. Використовуйте статус Panel, записи аудит-логів та затверджений робочий процес інцидентів для виробничих проблем (production issues).

## Panel недоступна або неповна

Запишіть уражену URL-адресу, час, помилку браузера та видимий стан Panel. Підтвердіть, чи впливає проблема на одного користувача, чи на кількох користувачів. Не змінюйте розгорнуті файли, конфігурацію служб чи кеш безпосередньо; передайте зібрані докази команді реагування платформи.

## Автентифікацію або доступ заборонено

Підтвердіть, що використовуються правильний обліковий запис, роль та поточний метод автентифікації. Попросіть уповноваженого адміністратора доступу перевірити відповідний стан облікового запису, сеансу та політик. Не передавайте облікові дані або матеріали для відновлення в тікеті.

## Керована операція зазнала невдачі

Збережіть ідентифікатор операції або кореляції, вибраний ресурс, час запиту та повідомлення про помилку. Перевірте статус вузла та робочого навантаження в Panel. Використовуйте повторну спробу лише тоді, коли інтерфейс пропонує безпечну дію повтору; в іншому випадку створіть або оновіть інцидент.

## Розбіжність документації чи контрактів

Для розробки пересоберіть знімок документації та запустіть задокументовані ворота якості (quality gates). Зміни API повинні бути відображені в канонічному довіднику OpenAPI 3.1 та інвентарі кінцевих точок, зручному для читання людиною, перед випуском.
