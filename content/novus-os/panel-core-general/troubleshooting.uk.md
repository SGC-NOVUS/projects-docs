# Центр усунення несправностей

Цей посібник допомагає операторам збирати корисний контекст без обходу меж безпеки NOVUS OS. Використовуйте статус Panel, записи аудит-логів та затверджений робочий процес інцидентів для виробничих проблем (production issues).

## Panel недоступна або неповна

Зафіксуйте уражений URL, час, помилку браузера та видимий стан Panel. Підтвердьте, чи проблема стосується одного користувача чи кількох користувачів. Не змінюйте розгорнуті файли, конфігурацію служб чи кеш безпосередньо; передайте зібрані докази команді реагування платформи.

## Автентифікація або доступ заборонені

Підтвердьте, що використовуються правильний обліковий запис, роль та поточний метод автентифікації. Попросіть уповноваженого адміністратора доступу перевірити відповідний стан облікового запису, сеансу та політики. Не передавайте облікові дані чи матеріали відновлення в тікеті.

## Керувана операція зазнала невдачі

Збережіть ідентифікатор операції або кореляції, вибраний ресурс, час запиту та повідомлення про помилку. Перевірте статус вузла та робочого навантаження в Panel. Використовуйте повторну спробу (retry) лише тоді, коли інтерфейс пропонує безпечну дію повтору; в іншому разі створіть або оновіть інцидент.

## Розбіжність документації чи контракту

Для розробки пересоберіть знімок документації та запустіть задокументовані ворота якості (quality gates). Зміни в API повинні бути відображені в канонічному довіднику OpenAPI та людиночитаному інвентарі ендпоінтів перед випуском (release).
