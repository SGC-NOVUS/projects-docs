# Операції платформи

Робочий простір Platform Operations надає авторизованим операторам єдину поверхню керування для керованих служб, стану вузлів, запланованих робіт та операційних сповіщень. Адміністрування хостів залишається за автентифікованим агентом NOVUS Agent та затвердженими процедурами реагування.

## Робочий процес оператора

1. Перевірте поточний стан, сповіщення та чергу робіт у Panel.
2. Виберіть ураховану керовану службу або вузол.
3. Використовуйте доступну дію Panel і виконайте її вимоги щодо підтвердження.
4. Спостерігайте за станом операції, доки вона не завершиться або не повідомить про безпечну повторну спробу.
5. Зареєструйте дію та результат через процес зміни в організації.

## Межі

- Panel оцінює дозволи оператора та відображає результати.
- NOVUS Agent виконує затверджену локальну роботу на хості за допомогою типізованого транспорту.
- Оператори не використовують прямі оболонки хоста, менеджери служб чи локальні шляхи керування середовищем виконання для звичайних операцій Panel.
- Аудиторські записи зберігають ідентифікатор ініціатора, ціль та результат.

## Ескалація

Якщо служба недоступна або запитувана дія не може завершитися, збережіть ідентифікатор кореляції Panel, мітки часу та урахований ресурс. Використовуйте робочий процес інцидентів у разі впливу на роботу продуктивного середовища. Не обходьте Panel і не змінюйте конфігурацію хоста безпосередньо.

Внутрішнє володіння службами, межі сумісності та процедури відновлення обмежені 
робочим простором інженерії.
