# Операції платформи

Робочий простір Platform Operations надає авторизованим операторам єдину поверхню керування керованими сервисами, станом вузлів, запланованою роботою та операційними сповіщеннями. Адміністрування хостів залишається за захищеним автентифікацією NOVUS Agent та затвердженими процедурами реагування.

## Робочий процес оператора

1. Перевірте поточний стан, сповіщення та чергу робіт у Panel.
2. Виберіть задіяний керований сервіс або вузол.
3. Використовуйте доступну дію Panel та виконайте її вимоги щодо підтвердження.
4. Спостерігайте за станом операції, доки вона не завершиться або не повідомитиме про безпечну повторну спробу.
5. Зареєструйте дію та результат через процес управління змінами організації.

## Межі

- Panel оцінює дозволи оператора та відображає результати.
- NOVUS Agent виконує затверджену локальну роботу на хості за допомогою типізованого транспорту.
- Оператори не використовують прямі оболонки хоста, менеджери сервісів або локальні шляхи керування середовищем виконання для рутинних операцій Panel.
- Журнали аудиту зберігають ідентифікатор ініціатора, ціль та результат.

## Ескалація

Якщо сервіс недоступний або запитану дію не вдається завершити, збережіть ідентифікатор кореляції Panel, мітки часу та задіяний ресурс. Використовуйте робочий процес інцидентів у разі впливу на продуктивне середовище. Не оминайте Panel і не змінюйте конфігурацію хоста безпосередньо.

Внутрішнє володіння сервісами, межі сумісності та процедури відновлення обмежені робочим простором інженерії.
