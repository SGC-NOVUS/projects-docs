# Мониторинг

Рабочая область Monitoring управляет утвержденными целевыми объектами проверки работоспособности, зондами, оповещениями и представлениями статуса для ресурсов NOVUS OS.

## Рабочий процесс оператора

1. Создайте или выберите контролируемый целевой объект в Panel.
2. Настройте утвержденный тип зонда, пороговое значение и политику уведомлений.
3. Просмотрите историю, текущее состояние и все связанные инциденты.
4. Подтвердите или разрешите инциденты через рабочий процесс Service Desk.
5. Изменяйте настройки хранения или уведомлений только с помощью авторизованных действий в Panel.

## Элементы управления безопасности

- Целевые объекты и зонды проверяются перед активацией.
- Изменения оповещений требуют разрешения monitoring-management.
- Учетные данные для уведомлений хранятся у владельца защищенной интеграции и никогда не отображаются в результатах мониторинга.
- Автоматизированные задачи мониторинга выполняются под управлением планировщика платформы, а не команд хоста оператора.

## Устранение неполадок

Сохраняйте целевой объект, результат проверки и идентификатор инцидента при сбое проверки. Проверьте работоспособность узла и интеграции в Panel, затем передайте повторяющиеся сбои доставки или телеметрии через рабочий процесс инцидентов.
