# Terminal

Робочий простір Terminal надає автентифіковану консоль на базі браузера для
авторизованої операційної роботи. Це поверхня Panel, а не пряме з'єднання між
браузером і хостом.

## Робочий процес оператора

1. Відкрийте робочий простір Terminal та виберіть затверджений режим сеансу.
2. Підключайтеся лише після підтвердження цільового вузла та області робочого навантаження.
3. Використовуйте сеанс для авторизованої операційної роботи та відключайтеся після завершення.
4. Використовуйте засіб перегляду логів для отримання дозволених діагностичних даних замість запиту доступу до сирих логів хоста.

## Модель безпеки

- Операції з Terminal та логами вимагають автентифікованого сеансу Panel та
  дозволу.
- Життєвий цикл сеансу, введення в терміналі та події зміни розміру використовують автентифікований транспорт виконання.
- Доступ до логів обмежено затвердженою областю; довічні шляхи хоста не
  розголошуються.
- Збої під час підключення та операцій зберігають дані кореляції для робочого процесу інцидентів.

## Усунення несправностей

Якщо сеанс недоступний, збережіть відображену помилку, ціль і мітку часу.
Перевірте статус вузла через Panel і використовуйте лише безпечну повторну спробу, запропоновану
робочим простором. Ескалуйте стійкі збої сеансу або авторизації.

Транспортні, демонічні та сумісні деталі обмежені внутрішньою інженерною процедурою.
