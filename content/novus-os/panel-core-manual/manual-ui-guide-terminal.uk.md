# Terminal

Робочий простір Terminal надає автентифіковану консоль на базі браузера для
авторизованих операційних завдань. Це інтерфейс Panel, а не пряме з'єднання
браузера з хостом.

## Робочий процес оператора

1. Відкрийте робочий простір Terminal і виберіть затверджений режим сеансу.
2. Підключайтеся лише після підтвердження цільового вузла та області навантаження.
3. Використовуйте сеанс для авторизованої операційної роботи та відключайтеся після завершення.
4. Використовуйте засіб перегляду логів для отримання дозволених діагностичних даних замість запиту доступу до сирих логів хоста.

## Модель безпеки

- Операції з Terminal та логами вимагають автентифікованого сеансу Panel та
  дозволу.
- Життєвий цикл сеансу, введення в терміналі та події зміни розміру використовують автентифікований транспорт середовища виконання.
- Доступ до логів обмежено затвердженою областю; довічні шляхи хоста не
  розголошуються.
- Помилки підключення та операцій зберігають дані кореляції для робочого процесу інцидентів.

## Усунення несправностей

Якщо сеанс недоступний, збережіть відображену помилку, ціль та мітку часу.
Перевірте стан вузла через Panel і використовуйте лише безпечну повторну спробу, запропоновану
робочим простором. Передайте стійкі помилки сеансу або авторизації на ескалацію.

Відомості про транспорт, демон і сумісність обмежені внутрішньою інженерною процедурою.
