# Platform Operations

Рабочее пространство Platform Operations предоставляет авторизованным операторам единый интерфейс управления для управляемых сервисов, состояния узлов, запланированных задач и оперативных оповещений. Администрирование хостов остается за защищенным аутентификацией NOVUS Agent и утвержденными процедурами реагирования.

## Operator Workflow

1. Проверьте текущее состояние, оповещения и очередь задач на панели управления (Panel).
2. Выберите затронутый управляемый сервис или узел.
3. Используйте доступное действие панели и выполните требования для его подтверждения.
4. Отслеживайте состояние операции до ее завершения или сообщения о безопасной повторной попытке.
5. Зафиксируйте действие и результат в рамках процесса управления изменениями в организации.

## Boundaries

- Панель оценивает права оператора и отображает результаты.
- NOVUS Agent выполняет разрешенные локальные задачи на хосте через типизированный транспорт.
- Операторы не используют прямые оболочки хоста, менеджеры служб или пути управления локальной средой выполнения для ручных операций на панели.
- Журналы аудита сохраняют идентичность инициатора, цель и результат.

## Escalation

Если служба недоступна или запрошенное действие не может быть завершено, сохраните идентификатор корреляции панели, временные метки и затронутый ресурс. Используйте рабочий процесс инцидентов при влиянии на промышленную среду (production). Не обходите панель и не изменяйте конфигурацию хоста напрямую.

Внутреннее владение сервисами, границы совместимости и процедуры восстановления
ограничены инженерным рабочим пространством.
