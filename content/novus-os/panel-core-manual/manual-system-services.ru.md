# Операции с платформой

Рабочая среда Platform Operations предоставляет авторизованным операторам единую панель управления для управляемых сервисов, состояния узлов, запланированных работ и оперативных оповещений. Администрирование хоста остается за аутентифицированным NOVUS Agent и утвержденными процедурами реагирования.

## Рабочий процесс оператора

1. Проверьте текущее состояние, оповещения и поставленные в очередь задачи в Panel.
2. Выберите затронутый управляемый сервис или узел.
3. Используйте доступное действие Panel и выполните требования для его подтверждения.
4. Отслеживайте состояние операции до ее завершения или сообщения о безопасном повторе.
5. Зарегистрируйте действие и результат через процесс управления изменениями организации.

## Границы

- Panel оценивает права оператора и отображает результаты.
- NOVUS Agent выполняет утвержденную локальную работу на хосте через типизированный транспорт.
- Операторы не используют прямые оболочки хоста, менеджеры сервисов или локальные пути управления средой выполнения для ручных операций в Panel.
- Записи аудита сохраняют инициализирующую учетную запись, цель и результат.

## Эскалация

Если сервис недоступен или запрошенное действие не может быть завершено, сохраните идентификатор корреляции Panel, метки времени и затронутый ресурс. Используйте рабочий процесс инцидентов при влиянии на продуктивную среду. Не обходите Panel и не изменяйте конфигурацию хоста напрямую.

Внутреннее владение сервисами, границы совместимости и процедуры восстановления
ограничены инженерной рабочей средой.
