# NOVUS Agent Transport

NOVUS Agent Transport — это граница Panel для привилегированных операций с нодами. Он выбирает зарегистрированный транспорт ноды, применяет авторизацию Panel и возвращает нормализованные результаты службам Panel. Операторы не подключаются к службам среды выполнения ноды напрямую.

## Ожидания оператора

- Регистрируйте и связывайте ноды через рабочий процесс Panel.
- Используйте соответствующее рабочее пространство Panel для выполнения действий со средой выполнения, хранилищем, резервным копированием, веб-сайтами и безопасностью.
- Проверяйте состояние здоровья ноды и статус операции в Panel перед повторной попыткой выполнения работы.
- Сохраняйте идентификаторы корреляции при эскалации сбоя операции ноды.

## Модель безопасности

Panel оценивает политику оператора перед отправкой намерения агенту (Agent).
Agent обеспечивает соблюдение собственной области видимости ноды и границы аутентифицированного транспорта.
Учетные данные и доступ к реестру никогда не возвращаются клиентам браузера и не отображаются в документации для операторов.
