# NOVUS Agent Transport

NOVUS Agent Transport — это граница Panel для привилегированных операций с нодами. Он выбирает зарегистрированный транспорт ноды, применяет авторизацию Panel и возвращает нормализованные результаты службам Panel. Операторы не подключаются к службам исполняемой среды ноды напрямую.

## Ожидания оператора

- Регистрация и сопряжение нод через рабочий процесс Panel.
- Использование соответствующего рабочего пространства Panel для действий с исполняемой средой, хранилищем, резервным копированием, веб-сайтами и безопасностью.
- Проверка работоспособности ноды и статуса операции в Panel перед повторной попыткой выполнения работы.
- Сохранение идентификаторов корреляции при эскалации сбоя операции ноды.

## Модель безопасности

Panel оценивает политику оператора перед передачей намерения в Agent.
Agent применяет собственную область видимости ноды и границу аутентифицированного транспорта.
Учетные данные и доступ к реестру никогда не возвращаются клиентам браузера и не отображаются в документации для операторов.
