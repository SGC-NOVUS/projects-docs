# Scheduler

Робочий простір Scheduler керує затвердженими періодичними завданнями для операцій, що належать Panel. Завдання виконуються через системний планувальник (scheduler) та підпорядковуються дозволам, записам аудиту й області видимості ресурсів.

## Operator Workflow

1. Перегляньте активні завдання та їхній останній результат.
2. Створіть або відредагуйте завдання за допомогою форми розкладу Panel.
3. Підтвердьте цільовий ресурс та дозволену дію.
4. Простежте історію виконання та дослідіть невдалі запуски.
5. Вимкніть завдання перед внесенням суттєвих змін у продакшн.

## Safety Controls

- Вирази розкладу (schedule expressions) та корисні навантаження (payloads) завдань перевіряються перед збереженням.
- Завдання не можуть надавати більших повноважень, ніж дозволяє ініціююча політика.
- Історія виконання зберігає інформацію про час, результат та кореляцію.
- Конфігурація планування на хості є внутрішньою відповідальністю платформи.
