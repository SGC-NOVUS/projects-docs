# Scheduler

Робочий простір Scheduler керує затвердженими регулярними завданнями для операцій, якими володіє Panel. Завдання виконуються через системний планувальник (scheduler) і підпадають під дію прав доступу, записів аудиту та області ресурсів.

## Робочий процес оператора

1. Перегляньте активні завдання та їхній останній результат.
2. Створіть або відредагуйте завдання за допомогою форми розкладу Panel.
3. Підтвердьте цільовий ресурс та дозволену дію.
4. Простежте історію виконання та дослідіть невдалі запуски.
5. Вимкніть завдання перед внесенням суттєвих змін до продуктивного середовища.

## Елементи безпеки

- Вирази розкладу та корисні навантаження завдань перевіряються перед збереженням.
- Завдання не можуть надавати більших повноважень, ніж дозволяє ініціююча політика.
- Історія виконання зберігає інформацію про час, результат та кореляцію.
- Конфігурація планувальника хоста є внутрішньою відповідальністю платформи.
