# Dashboard

Dashboard надає операційний огляд керованих вузлів, робочих навантажень,
сповіщень, завдань та стану платформи. Це робочий простір, орієнтований на читання, із затвердженими
діями для авторизованих операторів.

## Робочий процес оператора

1. Перегляньте поточний стан, ємність та зведення сповіщень.
2. Виберіть ресурс, щоб відкрити його виділений робочий простір керування.
3. Використовуйте відображену дію лише після підтвердження її цілі та необхідної області дії.
4. Відстежуйте хід виконання завдань та зберігайте ідентифікатори кореляції для невдалих операцій.
5. Створіть або оновіть інцидент, коли збій впливає на виробничий сервіс.

## Модель безпеки

- Дані Dashboard збираються через автентифіковані середовища виконання.
- Дії залишаються захищеними правами доступу та перевіряються відповідним доменом.
- Dashboard ніколи не надає прямого доступу до хосту, сокета середовища виконання чи файлової системи.
- Розгортання та обслуговування ресурсів залишаються внутрішніми процедурами платформи.
