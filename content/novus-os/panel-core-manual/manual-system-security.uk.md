# Безпека системи

NOVUS OS застосовує багаторівневі засоби захисту для ідентифікації, прав доступу, сеансів браузера, Control-Plane, транспорту агента та керованих робочих навантажень. Цей посібник призначений для авторизованих операторів, які використовують Panel; він не є довідником команд із захисту хоста.

## Відповідальність за безпеку

| Область | Відповідальність оператора |
| --- | --- |
| Ідентифікація | Використовуйте індивідуальний обліковий запис, багатофакторну верифікацію там, де це вимагається, та роль із мінімально необхідними привілеями для кожного завдання. |
| Доступ | Регулярно перевіряйте доступ користувачів, команд та API; видаляйте доступ, який більше не потрібен. |
| Вузли | Підключайте та керуйте вузлами виключно через затверджений робочий процес Panel. |
| Робочі навантаження | Використовуйте робочі процеси Panel для операцій із середовищем виконання, файлами, мережею та резервним копіюванням замість прямого доступу до хоста. |
| Іциденти | Зберігайте відповідні докази аудиту Panel та дотримуйтеся затвердженого процесу реагування на інциденти. |

## Безпечна експлуатація

- Переглядайте сповіщення та статус безпеки в Panel перед внесенням привілейованих змін.
- Використовуйте обов'язковий процес підтвердження або багатофакторну автентифікацію для чутливих операцій.
- Зберігайте сеанси браузера, облікові дані API, токени інтеграції та матеріали відновлення конфіденційними.
- Перевіряйте цільовий вузел, екземпляр та область дії (scope) операції перед її підтвердженням.
- Реєструйте виробничі зміни через процес управління змінами організації.

## Коли щось здається несправним

1. Зупиніть уражений воркфлоу, якщо Панель надає безпечний шлях скасування.
2. Не намагайтеся виконувати пряме виправлення на хості або обходити вимогу авторизації.
3. Збережіть відповідний стан Панелі, ідентифікатори аудиту та мітки часу для уповноваженої групи реагування.
4. Ескалуйте підозру на витік облікових даних, несанкціонований доступ або порушення цілісності через приватний процес безпеки.
