# Terminal

Рабочее пространство Terminal предоставляет аутентифицированную консоль на базе браузера для авторизованных операционных работ. Это интерфейс Panel, а не прямое соединение браузера с хостом.

## Рабочий процесс оператора

1. Откройте рабочее пространство Terminal и выберите разрешенный режим сессии.
2. Подключайтесь только после подтверждения целевого узла и области рабочей нагрузки.
3. Используйте сессию для авторизованной операционной работы и отключайтесь по ее завершении.
4. Используйте средство просмотра логов для получения разрешенных диагностических данных вместо запроса прямого доступа к логам хоста.

## Модель безопасности

- Операции с терминалом и логами требуют аутентифицированной сессии Panel и соответствующих прав.
- Жизненный цикл сессии, ввод в терминале и события изменения размера используют аутентифицированный транспорт среды выполнения.
- Доступ к логам ограничен утвержденной областью; произвольные пути хоста не предоставляются.
- Сбои подключения и операций сохраняют данные корреляции для рабочего процесса инцидентов.

## Устранение неполадок

При недоступности сессии сохраните отображаемую ошибку, цель и временную метку. Проверьте статус узла через Panel и используйте только безопасную повторную попытку, предлагаемую рабочим пространством. Эскалируйте постоянные сбои сессии или авторизации.

Сведения о транспорте, демоне и совместимости ограничены внутренней инженерной процедурой.
