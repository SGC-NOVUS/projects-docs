# Системная безопасность

NOVUS-OS применяет многоуровневые элементы управления безопасностью для идентификации, разрешений, сеансов браузера, Control-Plane, транспорта Agent и управляемых рабочих нагрузок. Это руководство предназначено для авторизованных операторов, использующих Panel; оно не является справочником по командам усиления защиты хоста.

## Зоны ответственности за безопасность

| Область | Ответственность оператора |
| --- | --- |
| Идентификация | Используйте индивидуальную учетную запись, многофакторную верификацию там, где это требуется, и роль с наименьшими привилегиями для каждой задачи. |
| Доступ | Регулярно проверяйте доступ пользователей, команд и API; удаляйте доступ, который больше не требуется. |
| Ноды | Выполняйте сопряжение и управление нодами только через утвержденный рабочий процесс Panel. |
| Рабочие нагрузки | Используйте рабочие процессы Panel для операций с рантаймом, файлами, сетью и резервным копированием вместо прямого доступа к хосту. |
| Инциденты | Сохраняйте соответствующие данные аудита Panel и следуйте утвержденному процессу реагирования на инциденты. |

## Безопасные операции

- Проверяйте оповещения и статус безопасности в Panel перед внесением привилегированных изменений.
- Используйте требуемый процесс подтверждения или многофакторную аутентификацию для чувствительных операций.
- Храните сеансы браузера, учетные данные API, токены интеграции и материалы для восстановления в тайне.
- Проверяйте целевую ноду, инстанс и область действия (scope) действия перед его подтверждением.
- Регистрируйте изменения в продакшене с помощью процесса контроля изменений организации.

## Если что-то идет не так

1. Остановите затронутый рабочий процесс, если Панель предоставляет безопасный способ отмены.
2. Не предпринимайте попытки непосредственного устранения неполадок на хосте и не обходите требования авторизации.
3. Сохраните соответствующий статус Панели, идентификаторы аудита и метки времени для группы реагирования с соответствующими полномочиями.
4. Эскалируйте предполагаемую компрометацию учетных данных, несанкционированный доступ или нарушения целостности через закрытый процесс обеспечения безопасности.
