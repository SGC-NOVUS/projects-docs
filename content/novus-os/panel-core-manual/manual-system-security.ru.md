# Безопасность системы

NOVUS OS применяет многоуровневые средства защиты для управления идентификацией, правами доступа, сеансами браузера, Control-Plane, транспортом Agent и управляемыми рабочими нагрузками. Это руководство предназначено для авторизованных операторов, использующих Panel; оно не является справочником команд по защите хоста.

## Зоны ответственности за безопасность

| Область | Ответственность оператора |
| --- | --- |
| Идентификация | Используйте индивидуальную учетную запись, многофакторную верификацию там, где это требуется, и роль с наименьшими привилегиями для каждой задачи. |
| Доступ | Регулярно проверяйте доступ пользователей, команд и API; отзывайте доступ, который больше не требуется. |
| Ноды | Выполняйте сопряжение нод и управление ими только через утвержденный рабочий процесс Panel. |
| Рабочие нагрузки | Используйте рабочие процессы Panel для операций с рантаймом, файлами, сетью и резервным копированием вместо прямого доступа к хосту. |
| Инциденты | Сохраняйте соответствующие данные аудита Panel и следуйте утвержденному процессу реагирования на инциденты. |

## Безопасные операции

- Проверяйте оповещения и статус безопасности в Panel перед внесением привилегированных изменений.
- Используйте требуемый процесс подтверждения или многофакторную аутентификацию для чувствительных операций.
- Сохраняйте в тайне сеансы браузера, учетные данные API, токены интеграции и материалы для восстановления.
- Проверяйте целевую ноду, инстанс и область действия (scope) действия перед его подтверждением.
- Регистрируйте производственные изменения через процесс контроля изменений организации.

## При возникновении проблем

1. Остановите затронутый рабочий процесс, если Панель предоставляет безопасный способ отмены.
2. Не пытайтесь выполнять исправление непосредственно на хосте или обходить требования авторизации.
3. Сохраните соответствующий статус Панели, идентификаторы аудита и метки времени для уполномоченной группы реагирования.
4. Передайте информацию о предполагаемом раскрытии учетных данных, несанкционированном доступе или нарушениях целостности через закрытый процесс обеспечения безопасности.
