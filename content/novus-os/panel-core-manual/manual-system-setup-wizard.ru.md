# Мастер настройки (Setup Wizard)

Мастер настройки подготавливает новое окружение NOVUS Panel с помощью пошагового
рабочего процесса с аутентификацией. Он проверяет каждый этап перед тем, как платформа активирует
соответствующую возможность.

## Жизненный цикл настройки

1. Проверка готовности окружения и необходимой информации.
2. Настройка учетных данных и администратора с помощью мастера.
3. Настройка утвержденных параметров платформы, узлов и интеграций.
4. Просмотр итогового отчета о готовности.
5. Завершение настройки только после того, как Panel зафиксирует успешную проверку.

## Элементы управления безопасностью

- Запросы на настройку проверяются и записываются как аудируемые переходы состояний.
- Защищенная конфигурация и учетные данные остаются вне полезной нагрузки настройки,
  видимой в браузере.
- Подготовка базы данных, ключей и узлов использует идемпотентные рабочие процессы платформы.
- Процедуры восстановления и перезапуска ограничены авторизованными инженерными работами.
