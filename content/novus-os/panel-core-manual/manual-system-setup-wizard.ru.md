# Мастер установки

Мастер установки (Setup Wizard) подготавливает новое окружение NOVUS Panel с помощью пошагового рабочего процесса с аутентификацией. Он проверяет каждый этап перед тем, как платформа активирует соответствующую возможность.

## Жизненный цикл установки

1. Проверьте готовность окружения и необходимую информацию.
2. Завершите настройку учетных данных и администратора с помощью мастера.
3. Настройте утвержденные параметры платформы, узлов и интеграций.
4. Изучите полученный отчет о готовности.
5. Завершите установку только после того, как Panel запишет успешную валидацию.

## Элементы управления безопасностью

- Запросы на установку проверяются и записываются как аудируемые переходы состояний.
- Защищенная конфигурация и учетные данные остаются за пределами полезных данных установки, видимых в браузере.
- Подготовка базы данных, ключей и узлов использует идемпотентные рабочие процессы платформы.
- Процедуры восстановления и перезапуска ограничены авторизованными инженерными работами.
