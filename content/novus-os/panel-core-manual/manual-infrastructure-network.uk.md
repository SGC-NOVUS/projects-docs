# Website Network Operations

Робочий простір Websites дозволяє уповноваженим операторам керувати конфігурацією підтримуваних вебсайтів, сертифікатами та виконанням часу виконання через NOVUS-OS. Panel авторизує кожен запит, а NOVUS Agent виконує роботу на рівні вузла.

## Operator Workflow

1. Виберіть керований вебсайт і підтвердьте його вузол та домен.
2. Перегляньте конфігурацію, сертифікат і статус часу виконання в Panel.
3. Використовуйте надані дії для збереження перевіреної конфігурації, керування правилами перезапису, запиту на оновлення сертифіката або планування схваленої дії часу виконання.
4. Моніторте операцію, доки вона не зафіксує успіх або безпечний стан для повторної спроби.
5. Використовуйте дію відновлення лише після перевірки цільового об’єкта та запитуваного значення підтвердження.

## Safety Model

- Зміни вебсайту мають налаштовані права доступу, проходять валідацію та аудитуються.
- Зміни конфігурації перевіряються перед перезавантаженням активного середовища виконання.
- Agent створює відновлювану ревізію перед заміною керованої конфігурації.
- Чутливі дії часу виконання використовують встановлений робочий процес підтвердження та асинхронних завдань.

## Troubleshooting

Зберігайте ідентифікатор завдання, вебсайт і вузол у разі збою дії. Перегляньте результат операції в Panel і створіть інцидент у разі повторюваних збоїв, помилок сертифікатів або недоступності вузлів. Не змінюйте конфігурацію хоста або стан служби поза межами затвердженої операційної процедури.

Деталі реалізації обмежені внутрішньою інженерною процедурою.
