# Website Network Operations

Робочий простір Websites дозволяє авторизованим операторам керувати конфігурацією підтримуваних вебсайтів, сертифікатами та операціями середовища виконання через NOVUS OS. Panel авторизує кожен запит, а NOVUS Agent виконує локальні завдання на вузлі.

## Operator Workflow

1. Виберіть керований вебсайт і підтвердьте його вузел і домен.
2. Перевірте стан конфігурації, сертифіката та середовища виконання в Panel.
3. Використовуйте надані дії, щоб зберегти перевірену конфігурацію, керувати правилами перезапису (rewrite rules), замовити операції із сертифікатами або запланувати схвалену дію середовища виконання.
4. Моніторте операцію, доки вона не зафіксує успіх або безпечний стан для повторної спроби.
5. Використовуйте дію відновлення лише після перевірки цільового значення та запитаного значення підтвердження.

## Safety Model

- Зміни вебсайтів мають права доступу, проходять валідацію та аудитуються.
- Зміни конфігурації перевіряються перед перезавантаженням активного середовища виконання.
- Agent створює відновлювану ревізію перед заміною керованої конфігурації.
- Чутливі дії середовища виконання використовують встановлений робочий процес підтвердження та асинхронних завдань.

## Troubleshooting

Зберігайте ідентифікатор завдання, вебсайт і вузел, якщо дія завершується з помилкою. Перегляньте результат операції в Panel і створіть інцидент у разі повторюваних помилок, помилок сертифікатів або недоступності вузлів. Не змінюйте конфігурацію хоста або стан служби поза межами затвердженої операційної процедури.

Деталі реалізації обмежені внутрішньою інженерною процедурою.
