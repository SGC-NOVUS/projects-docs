# Шлюзи файлів

Шлюзи файлів визначають схвалені точки монтування сховища, доступні для керованого екземпляра середовища виконання. Оператори використовують Panel для перегляду та збереження декларацій шлюзів; служба середовища виконання забезпечує дотримання отриманої області дії.

## Робочий процес оператора

1. Виберіть керований екземпляр та перегляньте записи його шлюзів.
2. Виберіть схвалене джерело та призначення середовища виконання, запропоновані Panel.
3. Виберіть доступ лише для читання або читання-запису відповідно до потреб робочого навантаження.
4. Збережіть декларацію та перегляньте повернений результат перевірки.
5. Використовуйте дію відновлення прав доступу лише тоді, коли Panel повідомляє про її доступність та наявність відповідних повноважень.

## Засоби безпеки

- Шляхи шлюзів обмежені областю дії сховища екземпляра.
- Обхід каталогу, дублювання декларацій та монтування у корінь середовища виконання відхиляються.
- Дії запису та відновлення прав доступу вимагають прав на запис в екземпляр.
- Результати записуються для аудиту та кореляції інцидентів.

## Обробка збоїв

Збережіть ідентифікатор екземпляра та помилку перевірки. Виправте декларацію в Panel або ескалуйте повторюваний збій області дії; не створюйте точки монтування на хості та не змінюйте права доступу хоста безпосередньо.

Деталі резолюції монтування та примусового застосування в середовищі виконання обмежені внутрішньою інженерною процедурою.
