# File Gateways

File Gateways визначають затверджені точки монтування сховища, доступні керованому екземпляру середовища виконання. Оператори використовують Panel для перегляду та збереження оголошень шлюзів; служба середовища виконання забезпечує дотримання отриманої області дії.

## Operator Workflow

1. Виберіть керований екземпляр і перегляньте його записи шлюзів.
2. Виберіть затверджене джерело та призначення середовища виконання, запропоновані Panel.
3. Виберіть доступ лише для читання або читання-запису відповідно до потреб робочого навантаження.
4. Збережіть оголошення та перегляньте повернений результат перевірки.
5. Використовуйте дію відновлення дозволів (permission-repair) лише тоді, коли Panel повідомляє про її доступність та наявність відповідних повноважень.

## Safety Controls

- Шляхи шлюзів обмежені областю зберігання екземпляра.
- Обхід каталогу (traversal), дублюючі оголошення та монтування в корінь середовища виконання відхиляються.
- Дії запису та відновлення дозволів вимагають прав на запис екземпляра.
- Результати записуються для аудиту та кореляції інцидентів.

## Failure Handling

Зберігайте ідентифікатор екземпляра та помилку перевірки. Виправте оголошення в Panel або ескалуйте повторюваний збій області дії; не створюйте монтування хоста та не змінюйте дозволи хоста безпосередньо.

Деталі роздільної здатності монтування та примусового застосування середовища виконання обмежені внутрішньою інженерною процедурою.
