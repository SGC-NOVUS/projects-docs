# Runtime Matrices

Runtime Matrices определяют утвержденные шаблоны рабочей нагрузки, требования к ресурсам, объявления сети и требования к управляемому хранилищу. Операторы выбирают матрицу через Panel при создании или обновлении инстанса.

## Рабочий процесс оператора

1. Выберите категорию рабочей нагрузки и поддерживаемую матрицу.
2. Просмотрите сводку по выделенным ресурсам, сети и хранилищу.
3. Примените утвержденные переопределения через форму Panel.
4. Подтвердите итоговый план перед инициализацией.
5. Проверьте результат задания и сохраните его идентификатор для работы с инцидентами.

## Средства контроля безопасности

- Данные матрицы проверяются перед инициализацией.
- Объявления хранилища и сети ограничены рамками управляемого инстанса.
- Неподдерживаемые изменения образов, томов или портов отклоняются политикой времени выполнения.
- Результаты инициализации подвергаются аудиту и сопоставляются с инстансом.

Создание матриц и детали маппинга среды выполнения доступны только в внутреннем инженерном рабочем пространстве.
