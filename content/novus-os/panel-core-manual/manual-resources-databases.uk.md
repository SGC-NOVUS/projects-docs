# Databases

Робочий простір Databases керує створеними користувачами Data-Plane базами даних та відображає інвентаризацію лише для читання з підключених вузлів. Дані Control-Plane ізольовані від операцій із базами даних тенантів.

## Operator Workflow

1. Виберіть вузел та область бази даних у Panel.
2. Перегляньте бази даних, таблиці, користувачів і привілеї перед запитом на зміни.
3. Використовуйте надані форми для створення бази даних, управління користувачами або налаштування привілеїв.
4. Підтверджуйте деструктивні дії лише після перевірки вибраного ресурсу.
5. Використовуйте робочий простір Backups для створення точки відновлення перед деструктивною зміною або експортом.

## Access Model

- Адміністрування баз даних вимагає дозволу database-management.
- Для експорту потрібен спеціальний дозвіл backup-export.
- Підключені вузли підтримують розподілену інвентаризацію. Операції запису доступні лише там, де це явно дозволено контрактом поточного вузла.
- Системні сховища Control-Plane не надаються як цільові бази даних тенантів.

## Safe Operations

Panel перевіряє імена, області та привілеї перед перенаправленням запиту власнику бази даних. Облікові дані не повертаються у відповідях API та не відображаються після створення. Використовуйте принцип найменших привілеїв, ротуйте облікові дані через затверджений робочий процес та реєструйте виробничі зміни через контроль змін.

## Recovery And Escalation

Для невдалих операцій збережіть ідентифікатор запиту Panel та стан помилки. Не виконуйте прямі команди бази даних і не змінюйте схеми поза межами затвердженої процедури обслуговування. Відновлення та діагностика схем виконуються уповноваженою командою платформи.

Implementation, topology and migration procedures are restricted to the internal
engineering procedure.
