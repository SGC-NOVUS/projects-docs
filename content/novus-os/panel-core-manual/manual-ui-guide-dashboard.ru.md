# Dashboard

Dashboard предоставляет операционный обзор управляемых нод, ворклоадов, алертов, задач и состояния платформы. Это рабочее пространство, ориентированное на чтение, с разрешенными действиями для авторизованных операторов.

## Operator Workflow

1. Проверьте текущее состояние, емкость и сводки алертов.
2. Выберите ресурс, чтобы открыть его специализированное рабочее пространство управления.
3. Используйте отображаемое действие только после подтверждения его цели и требуемой области видимости.
4. Отслеживайте прогресс задач и сохраняйте идентификаторы корреляции для неудачных операций.
5. Создайте или обновите инцидент, когда сбой затрагивает продакшн-сервис.

## Safety Model

- Данные Dashboard собираются через аутентифицированные службы рантайма.
- Действия остаются регламентированными правами и проверяются аудитом домена-владельца.
- Dashboard никогда не предоставляет прямой доступ к хосту, рантайм-сокету или файловой системе.
- Развертывание и обслуживание ассетов остаются внутренними процедурами платформы.
