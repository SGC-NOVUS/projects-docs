# Dashboard

Dashboard предоставляет операционный обзор управляемых нод, ворклоадов, алертов, задач и состояния здоровья платформы. Это рабочее пространство, ориентированное на чтение, с утвержденными действиями для авторизованных операторов.

## Operator Workflow

1. Проверьте текущее состояние здоровья, емкость и сводки алертов.
2. Выберите ресурс, чтобы открыть его специализированное рабочее пространство управления.
3. Используйте отображаемое действие только после подтверждения его цели и требуемой области видимости.
4. Отслеживайте прогресс задач и сохраняйте идентификаторы корреляции для сбоев в работе.
5. Создайте или обновите инцидент, когда сбой затрагивает продакшн-сервис.

## Safety Model

- Данные Dashboard собираются через аутентифицируемые службы времени выполнения.
- Действия остаются ограниченными правами и проверяются владеющим доменом.
- Dashboard никогда не предоставляет прямой доступ к хосту, сокету среды выполнения или файловой системе.
- Развертывание и обслуживание ассетов остаются внутренними процедурами платформы.
