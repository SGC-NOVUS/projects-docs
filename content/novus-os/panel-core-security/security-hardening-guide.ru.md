# Безопасность платформы NOVUS OS

Это руководство предназначено для авторизованных операторов NOVUS OS. Используйте рабочую область Security в Panel для настройки правил брандмауэра, проверки доступа, мониторинга статуса безопасности и запросов на восстановление. Конфигурация на уровне хоста выполняется исключительно в соответствии с утвержденной инженерной процедурой.

## Уровень безопасности

NOVUS OS сочетает в себе рабочие процессы Panel на основе разрешений, аутентифицированный транспорт Agent, зашифрованные секреты, многофакторные средства контроля и записи аудита. Платформа изолирует конфигурацию безопасности от рабочих нагрузок тенантов и применяет принцип наименьших привилегий для каждой операции.

## Рабочий процесс оператора

1. Проверяйте оповещения, события аудита и статус узлов в рабочей области Security.
2. Подтверждайте целевую область перед изменением правил брандмауэра или реагированием на событие доступа.
3. Используйте обязательное подтверждение или запрос многофакторной аутентификации для критических действий.
4. Фиксируйте изменения с помощью процессов управления изменениями в организации.
5. Передавайте информацию об отклонениях конфигурации, подозрении на утечку учетных данных и недоступности служб безопасности авторизованной группе реагирования.

## Реагирование на инциденты

При появлении аномального сигнала безопасности сохраните его идентификаторы аудита Panel,
метки времени и затронутые ресурсы. Останавливайте только те воркфлоу, для которых Panel
предлагает безопасное действие по отмене. Не изменяйте службы хоста, учетные данные или
состояние файловой системы напрямую; группа реагирования следует защищенной процедуре восстановления.

## Операционные проверки

- Доступ назначается индивидуальным учетным записям и регулярно пересматривается.
- Чувствительные действия требуют разрешений и подтверждения, предусмотренных
  Panel.
- Ноды объединяются в пары и управляются с помощью утвержденных воркфлоу Panel.
- Готовность к резервному копированию и восстановлению проверяется через соответствующие модули Panel.
- Производственные изменения имеют ответственную запись об изменении.
