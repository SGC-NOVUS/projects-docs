# NOVUS Agent-Core: Справочник конфигурации

Авторитетным источником конфигурации является `internal/config/config.go`. Все поддерживаемые настройки Agent представляют собой переменные окружения; недокументированные переменные не являются поддерживаемым интерфейсом.

## Прослушиватели и TLS

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_HTTP_LISTEN` | `:8080` | Адрес прослушивателя совместимости HTTP/WebSocket. |
| `NOVUS_AGENT_GRPC_LISTEN` | `:9443` | Адрес gRPC-прослушивателя с защитой TLS. |
| `NOVUS_AGENT_WS_ALLOWED_ORIGINS` | вычисляется из происхождения `NOVUS_AGENT_PANEL_URL` плюс запасной вариант `http://127.0.0.1,http://localhost` | Разделенный запятыми список разрешенных источникови WebSocket (origin allowlist); запросы с `Origin`, не входящим в список, отклоняются. |
| `NOVUS_AGENT_SSH_LISTEN` | `:2022` | Адрес прослушивателя совместимости SSH/SFTP. |
| `NOVUS_AGENT_SSH_HOST_KEY_FILE` | `<dirname(NOVUS_AGENT_STATE_FILE)>/ssh_host_rsa_key` | Путь к постоянному закрытому ключу хоста SSH (создается при отсутствии, переиспользуется между перезапусками). |
| `NOVUS_AGENT_TLS_CERT` | Расположение TLS-сертификата, управляемого Agent | TLS-сертификат для gRPC-прослушивателя. |
| `NOVUS_AGENT_TLS_KEY` | Расположение TLS-ключа, управляемого Agent | Закрытый ключ, связанный с TLS-сертификатом. Не размещайте материалы ключа в файлах репозитория или общедоступных примерах. |
| `NOVUS_AGENT_TLS_AUTOGEN_DIR` | Каталог TLS, управляемый Agent | Расположение, используемое, когда Agent создает или обновляет самозаверяющий сертификат. |

TLS является обязательным для gRPC. Если материалы сертификата отсутствуют, Agent может выполнить первоначальную загрузку (bootstrap) самозаверяющего сертификата; операторам следует использовать утвержденную процедуру развертывания для установления доверия.

Для транспорта совместимости SSH/SFTP Agent сохраняет ключ хоста по настроенному пути и принудительно применяет права доступа к файлу закрытого ключа во время загрузки.

Для транспорта совместимости консоли WebSocket включите параметры запроса контекста сеанса (`session_uuid` или `session_id`) и контекста узла (`node_uuid` или `node_id`), чтобы можно было применять проверки привязки контекста JWT.
Адаптер принимает оба псевдонима ключей запроса и проверяет утверждения контекста JWT на соответствие разрешенной привязке узла/контейнера/сеанса.
Agent также может синхронизировать белый список WebSocket в памяти во время выполнения из аутентифицированных метаданных gRPC без перезапуска:
- `x-novus-ws-allowed-origins`: список источников, разделенных запятыми.
- `x-novus-panel-url`: URL панели, используемый для вычисления источника, а также безопасные локальные запасные источники.

## State And Security

| Variable | Default | Purpose |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_FILE` | Расположение файла состояния Agent | Зашифрованное локальное состояние сопряжения. Псевдоним совместимости: `NOVUS_AGENT_STATE_PATH` (при активации псевдонима выдается предупреждение об устаревании при запуске). |
| `NOVUS_AGENT_STATE_ENCRYPTION_KEY` | пусто | Необязательный ключ шифрования состояния, предоставляемый безопасной средой хоста. |
| `NOVUS_AGENT_PAIRING_TOKEN_TTL_MINUTES` | `15` | Время жизни токена сопряжения; значения менее одной минуты заменяются на `15`. |
| `NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS` | `15` | Допустимое расхождение системных часов запроса для подписанных gRPC-запросов. |
| `NOVUS_AGENT_RATE_LIMIT_PER_MINUTE` | `600` | Ограничение частоты запросов на одну панель. |
| `NOVUS_AGENT_RATE_LIMIT_BURST` | `120` | Емкость всплеска для алгоритма token-bucket. |
| `NOVUS_AGENT_AUDIT_LOG_ENABLED` | `true` | Включает структурированные события аудита безопасности Agent. |

## Runtime, Files And Telemetry

| Variable | Default | Purpose |
| --- | --- | --- |
| `NOVUS_AGENT_DOCKER_SOCKET` | system Docker socket | Docker-транспорт, используемый для операций рантайма Агента. |
| `NOVUS_AGENT_VFS_POLICY_MODE` | `host_admin` | Режим политики VFS: `host_admin` разрешает корневые пути VFS на уровне всего хоста, `scoped_runtime` ограничивает их настроенными корневыми путями рантайма. |
| `NOVUS_AGENT_VFS_SCOPED_ROOTS` | `/var/lib/novus/volumes/games,/var/lib/novus/volumes/service,/var/lib/novus/volumes/web` | Корневые пути с ограничением области видимости (разделенные запятыми), используемые при `NOVUS_AGENT_VFS_POLICY_MODE=scoped_runtime`. Псевдоним совместимости: `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (при использовании псевдонима во время запуска выдается предупреждение об устаревании). |
| `NOVUS_AGENT_VFS_UPLOAD_DIR` | Agent-managed upload directory | Временное хранилище для возобновляемой выгрузки файлов. |
| `NOVUS_AGENT_VFS_WORK_DIR` | Agent-managed work directory | Временное хранилище для операций с файлами и архивами. |
| `NOVUS_AGENT_SSL_CERT_DIR` | Agent-managed certificate directory | Источник метаданных сертификатов веб-сайтов только для чтения. |
| `NOVUS_AGENT_BACKUP_DIR` | Agent-managed backup directory | Рабочая директория локального резервного копирования. |
| `NOVUS_AGENT_TELEMETRY_DISK_MOUNT` | `/` | Точка монтирования диска, используемая для телеметрии хоста. |

Рантайм разрешает корневые пути VFS через режим политики:
- `host_admin`: область видимости корня для всего хоста для явных рабочих процессов администратора.
- `scoped_runtime`: базовая изоляция до настроенных корневых путей томов рантайма.

Явно установите режим в production-среде в соответствии с вашими эксплуатационными требованиями.

Примечание о поддержке устаревших версий: если задан только `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (без явного `NOVUS_AGENT_VFS_POLICY_MODE`), загрузчик сопоставляет поведение с `scoped_runtime` для обратной совместимости.

## Миграция канонических ключей

Используйте канонические ключи во всех новых развертываниях и средствах автоматизации. Устаревшие псевдонимы предназначены исключительно для обеспечения совместимости и генерируют предупреждения при запуске, если используются в качестве активного источника.

| Устаревший псевдоним | Канонический ключ | Поведение во время выполнения |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_PATH` | `NOVUS_AGENT_STATE_FILE` | Псевдоним считывается только тогда, когда канонический ключ не задан; генерируется событие предупреждения при запуске `config_deprecated_env_alias_used`. |
| `NOVUS_AGENT_VFS_ALLOWED_ROOTS` | `NOVUS_AGENT_VFS_SCOPED_ROOTS` | Псевдоним считывается только тогда, когда канонический ключ не задан; генерируется событие предупреждения при запуске `config_deprecated_env_alias_used`. |

Правило приоритета: канонический ключ имеет преимущество, когда заданы как канонический ключ, так и устаревший псевдоним.

## PTY

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_PTY_SHELL` | `/bin/bash` | Интерактивная оболочка по умолчанию. |
| `NOVUS_AGENT_PTY_CWD` | `/` | Рабочая директория PTY по умолчанию. |
| `NOVUS_AGENT_PTY_ALLOWED_SHELLS` | Белый список утвержденных оболочек | Разделенный запятыми список путей к оболочкам, разрешенным для PTY-сессий. |

Агент проверяет выбранную оболочку по настроенному белому списку. Клиенты браузера не подключаются к хосту PTY напрямую; терминальные сессии остаются в рамках транспортного контракта между Panel и Agent.

## Совместимость с Panel

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOV_AGENT_PANEL_URL` | пусто | Необязательный URL Panel для рабочих процессов совместимости. |
| `NOVUS_AGENT_PANEL_TOKEN` | пусто | Необязательный токен Panel для рабочих процессов совместимости. Передавайте его только через утвержденный канал управления секретами. |

## Пример безопасной конфигурации

```ini
NOVUS_AGENT_GRPC_LISTEN=:9443
NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS=15
NOVUS_AGENT_RATE_LIMIT_PER_MINUTE=600
NOVUS_AGENT_RATE_LIMIT_BURST=120
NOVUS_AGENT_AUDIT_LOG_ENABLED=true
NOVUS_AGENT_PTY_SHELL=/bin/bash
NOVUS_AGENT_PTY_ALLOWED_SHELLS=/bin/bash,/bin/sh
```

Не копируйте значения секретов, пути к закрытым ключам TLS, токены сопряжения или токены Panel в документацию, систему контроля версий, историю командной строки или аргументы процессов.
