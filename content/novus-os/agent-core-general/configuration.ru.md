# NOVUS Agent-Core: Справочник конфигурации

Авторитетным источником конфигурации является файл `internal/config/config.go`. Все поддерживаемые настройки Agent задаются через переменные окружения; не задокументированные переменные не являются поддерживаемым интерфейсом.

## Прослушиватели и TLS

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_HTTP_LISTEN` | `:8080` | Адрес прослушивателя совместимости HTTP/WebSocket. |
| `NOVUS_AGENT_GRPC_LISTEN` | `:9443` | Адрес прослушивателя gRPC с защитой TLS. |
| `NOVUS_AGENT_WS_ALLOWED_ORIGINS` | вычисляется из происхождения `NOVUS_AGENT_PANEL_URL` с запасным вариантом `http://127.0.0.1,http://localhost` | Разделенный запятыми список разрешенных источников WebSocket; запросы с источниками (`Origin`), отсутствующими в списке, отклоняются. |
| `NOVUS_AGENT_SSH_LISTEN` | `:2022` | Адрес прослушивателя совместимости SSH/SFTP. |
| `NOVUS_AGENT_SSH_HOST_KEY_FILE` | `<dirname(NOVUS_AGENT_STATE_FILE)>/ssh_host_rsa_key` | Путь к постоянному приватному ключу хоста SSH (создается при отсутствии, переиспользуется между перезапусками). |
| `NOVUS_AGENT_TLS_CERT` | Расположение TLS-сертификата, управляемое Agent | TLS-сертификат для прослушивателя gRPC. |
| `NOVUS_AGENT_TLS_KEY` | Расположение TLS-ключа, управляемое Agent | Приватный ключ, соответствующий TLS-сертификату. Не помещайте материал ключа в файлы репозитория или публичные примеры. |
| `NOVUS_AGENT_TLS_AUTOGEN_DIR` | Директория TLS, управляемая Agent | Расположение, используемое при создании или ротации самоподписанного сертификата агентом. |

Протокол TLS является обязательным для gRPC. Если материалы сертификата отсутствуют, Agent может выполнить первоначальную загрузку самоподписанного сертификата; операторам следует использовать утвержденную процедуру развертывания для установления доверия.

Для транспорта совместимости SSH/SFTP Agent сохраняет ключ хоста по настроенному пути и принудительно применяет права доступа к файлу приватного ключа во время загрузки.

Для транспорта совместимости консоли WebSocket включите параметры запроса контекста сеанса (`session_uuid` или `session_id`) и контекста узла (`node_uuid` или `node_id`), чтобы можно было применять проверки привязки контекста JWT.
Адаптер принимает как псевдонимы ключей запроса, так и проверяет утверждения (claims) контекста JWT по разрешенной привязке узел/контейнер/сеанс.
Agent также может синхронизировать список разрешенных источников WebSocket в памяти во время работы на основе аутентифицированных метаданных gRPC без перезапуска:
- `x-novus-ws-allowed-origins`: разделенный запятыми список источников.
- `x-novus-panel-url`: URL панели, используемый для вычисления источника вместе с безопасными локальными резервными источниками.

## Состояние и безопасность

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_FILE` | Расположение файла состояния Agent | Зашифрованное локальное состояние сопряжения. Псевдоним совместимости: `NOVUS_AGENT_STATE_PATH` (при активности псевдонима выдается предупреждение об устаревании при запуске). |
| `NOVUS_AGENT_STATE_ENCRYPTION_KEY` | пусто | Необязательный ключ шифрования состояния, предоставляемый защищенной средой хоста. |
| `NOVUS_AGENT_PAIRING_TOKEN_TTL_MINUTES` | `15` | Время жизни токена сопряжения; значения менее одной минуты заменяются на `15`. |
| `NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS` | `15` | Допустимое расхождение часов запроса для подписанных gRPC-запросов. |
| `NOVUS_AGENT_RATE_LIMIT_PER_MINUTE` | `600` | Ограничение частоты запросов от панели. |
| `NOVUS_AGENT_RATE_LIMIT_BURST` | `120` | Емкость всплеска токена (token-bucket burst). |
| `NOVUS_AGENT_AUDIT_LOG_ENABLED` | `true` | Включает структурированные события аудита безопасности Agent. |

## Среда выполнения, файлы и телеметрия

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_DOCKER_SOCKET` | системный сокет Docker | Транспорт Docker, используемый операциями среды выполнения Agent. |
| `NOVUS_AGENT_VFS_POLICY_MODE` | `host_admin` | Режим политики VFS: `host_admin` разрешает корни VFS в масштабе всего хоста, `scoped_runtime` ограничивает настроенными корнями среды выполнения. |
| `NOVUS_AGENT_VFS_SCOPED_ROOTS` | `/var/lib/novus/volumes/games,/var/lib/novus/volumes/service,/var/lib/novus/volumes/web` | Разделенные запятыми ограниченные корни, используемые при `NOVUS_AGENT_VFS_POLICY_MODE=scoped_runtime`. Псевдоним совместимости: `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (при активности псевдонима выдается предупреждение об устаревании при запуске). |
| `NOVUS_AGENT_VFS_UPLOAD_DIR` | Директория загрузки, управляемая Agent | Временное хранилище для возобновляемых загрузок файлов. |
| `NOVUS_AGENT_VFS_WORK_DIR` | Рабочая директория, управляемая Agent | Временное хранилище для операций с файлами и архивами. |
| `NOVUS_AGENT_SSL_CERT_DIR` | Директория сертификатов, управляемая Agent | Источник метаданных сертификата веб-сайта только для чтения. |
| `NOVUS_AGENT_BACKUP_DIR` | Директория резервного копирования, управляемая Agent | Рабочая директория локального резервного копирования. |
| `NOVUS_AGENT_TELEMETRY_DISK_MOUNT` | `/` | Монтирование диска, используемое для телеметрии хоста. |

Среда выполнения разрешает корни VFS через режим политики:
- `host_admin`: область корневого каталога хоста для явных рабочих процессов администратора.
- `scoped_runtime`: базовая изоляция до настроенных корней томов среды выполнения.

Явно установите режим в рабочей среде в соответствии с вашими операционными требованиями.

Примечание о поддержке устаревших версий: если задан только `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (без явного `NOVUS_AGENT_VFS_POLICY_MODE`), загрузчик сопоставляет поведение с режимом `scoped_runtime` для обратной совместимости.

## Миграция канонических ключей

Используйте канонические ключи во всех новых развертываниях и автоматизации. Устаревшие псевдонимы предназначены исключительно для совместимости и выводят предупреждения при запуске, если используются в качестве активного источника.

| Устаревший псевдоним | Канонический ключ | Поведение среды выполнения |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_PATH` | `NOVUS_AGENT_STATE_FILE` | Псевдоним считывается только тогда, когда канонический ключ не задан; генерируется событие предупреждения запуска `config_deprecated_env_alias_used`. |
| `NOVUS_AGENT_VFS_ALLOWED_ROOTS` | `NOVUS_AGENT_VFS_SCOPED_ROOTS` | Псевдоним считывается только тогда, когда канонический ключ не задан; генерируется событие предупреждения запуска `config_deprecated_env_alias_used`. |

Правило приоритета: канонический ключ побеждает, когда заданы как канонический ключ, так и устаревший псевдоним.

## PTY

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_PTY_SHELL` | `/bin/bash` | Интерактивная оболочка по умолчанию. |
| `NOVUS_AGENT_PTY_CWD` | `/` | Рабочая директория PTY по умолчанию. |
| `NOVUS_AGENT_PTY_ALLOWED_SHELLS` | Утвержденный список разрешенных оболочек | Разделенные запятыми пути к оболочкам, разрешенным для сеансов PTY. |

Agent проверяет выбранную оболочку по настроенному списку разрешенных. Браузерные клиенты не подключаются к хосту PTY напрямую; сеансы терминала остаются за транспортным контрактом панели с агентом (Panel-to-Agent).

## Совместимость с Панелью

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_PANEL_URL` | пусто | Необязательный URL Панели для рабочих процессов совместимости. |
| `NOVUS_AGENT_PANEL_TOKEN` | пусто | Необязательный токен Панели для рабочих процессов совместимости. Предоставляйте его только через утвержденный путь управления секретами. |

## Пример безопасной конфигурации

```ini
NOVUS_AGENT_GRPC_LISTEN=:9443
NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS=15
NOVUS_AGENT_RATE_LIMIT_PER_MINUTE=600
NOVUS_AGENT_RATE_LIMIT_BURST=120
NOVUS_AGENT_AUDIT_LOG_ENABLED=true
NOVUS_AGENT_PTY_SHELL=/bin/bash
NOVUS_AGENT_PTY_ALLOWED_SHELLS=/bin/bash,/bin/sh
```

Не копируйте секретные значения, пути к приватным ключам TLS, токены сопряжения или токены Панели в документацию, систему контроля версий, историю оболочки или аргументы процессов.
