# NOVUS Agent-Core: Справочник конфигурации

Авторитетным источником конфигурации является `internal/config/config.go`. Все поддерживаемые настройки Agent задаются через переменные окружения; недокументированные переменные не являются поддерживаемым интерфейсом.

## Прослушиватели и TLS

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_HTTP_LISTEN` | `:8080` | Адрес прослушивателя совместимости HTTP/WebSocket. |
| `NOVUS_AGENT_GRPC_LISTEN` | `:9443` | Адрес gRPC-прослушивателя с защитой TLS. |
| `NOVUS_AGENT_WS_ALLOWED_ORIGINS` | вычисляется из исходного адреса `NOVUS_AGENT_PANEL_URL` плюс резервные значения `http://127.0.0.1,http://localhost` | Список разрешенных источников (allowlist) WebSocket, разделенных запятыми; запросы с источниками, отсутствующими в списке, отклоняются. |
| `NOVUS_AGENT_SSH_LISTEN` | `:2022` | Адрес прослушивателя совместимости SSH/SFTP. |
| `NOVUS_AGENT_SSH_HOST_KEY_FILE` | `<dirname(NOVUS_AGENT_STATE_FILE)>/ssh_host_rsa_key` | Путь к персистентному приватному ключу хоста SSH (создается при отсутствии, переиспользуется между перезапусками). |
| `NOVUS_AGENT_TLS_CERT` | Расположение TLS-сертификата, управляемое Agent | TLS-сертификат для gRPC-прослушивателя. |
| `NOVUS_AGENT_TLS_KEY` | Расположение TLS-ключа, управляемое Agent | Приватный ключ, сопряженный с TLS-сертификатом. Не размещайте материал ключа в файлах репозитория или публичных примерах. |
| `NOVUS_AGENT_TLS_AUTOGEN_DIR` | Каталог TLS, управляемый Agent | Расположение, используемое при создании или ротации Agent самоподписанного сертификата. |

Протокол TLS является обязательным для gRPC. Если материал сертификата отсутствует, Agent может выполнить бутстрапинг самоподписанного сертификата; операторам следует использовать утвержденную процедуру развертывания для установления доверия.

Для транспортного протокола совместимости SSH/SFTP Agent сохраняет ключ хоста по настроенному пути и принудительно применяет права доступа к файлу приватного ключа во время загрузки.

Для транспортного протокола совместимости консоли WebSocket включите параметры запроса контекста сеанса (`session_uuid` или `session_id`) и контекста узла (`node_uuid` или `node_id`), чтобы можно было принудительно выполнять проверки привязки контекста JWT.
Адаптер принимает как псевдонимы ключей запроса, так и проверяет утверждения контекста JWT на соответствие разрешенной привязке узла/контейнера/сеанса.
Agent также может синхронизировать список разрешенных WebSocket в памяти во время работы на основе аутентифицированных метаданных gRPC без перезапуска:
- `x-novus-ws-allowed-origins`: список источников, разделенных запятыми.
- `x-novus-panel-url`: URL панели, используемый для вычисления источника вместе с безопасными локальными резервными источниками.

## Состояние и безопасность

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_FILE` | Расположение файла состояния Agent | Зашифрованное локальное состояние сопряжения. Псевдоним совместимости: `NOVUS_AGENT_STATE_PATH` (при активации псевдонима выдается предупреждение об устаревании при запуске). |
| `NOVUS_AGENT_STATE_ENCRYPTION_KEY` | пусто | Необязательный ключ шифрования состояния, предоставляемый защищенной средой хоста. |
| `NOVUS_AGENT_PAIRING_TOKEN_TTL_MINUTES` | `15` | Время жизни токена сопряжения; значения менее одной минуты заменяются на `15`. |
| `NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS` | `15` | Допустимое отклонение системных часов запроса для подписанных gRPC-запросов. |
| `NOVUS_AGENT_RATE_LIMIT_PER_MINUTE` | `600` | Ограничение частоты запросов с расчетом на одну панель. |
| `NOVUS_AGENT_RATE_LIMIT_BURST` | `120` | Емкость всплеска токен-бакета (token-bucket). |
| `NOVUS_AGENT_AUDIT_LOG_ENABLED` | `true` | Включает структурированные события аудита безопасности Agent. |

## Среда выполнения, файлы и телеметрия

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_DOCKER_SOCKET` | системный сокет Docker | Транспорт Docker, используемый операциями среды выполнения Agent. |
| `NOVUS_AGENT_VFS_POLICY_MODE` | `host_admin` | Режим политики VFS: `host_admin` разрешает корни VFS в масштабе хоста, `scoped_runtime` ограничивает настроенными корнями среды выполнения. |
| `NOVUS_AGENT_VFS_SCOPED_ROOTS` | `/var/lib/novus/volumes/games,/var/lib/novus/volumes/service,/var/lib/novus/volumes/web` | Ограниченные корни, разделенные запятыми, используемые при `NOVUS_AGENT_VFS_POLICY_MODE=scoped_runtime`. Псевдоним совместимости: `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (при активации псевдонима выдается предупреждение об устаревании при запуске). |
| `NOVUS_AGENT_VFS_UPLOAD_DIR` | Каталог загрузок, управляемый Agent | Временное хранилище для возобновляемых загрузок файлов. |
| `NOVUS_AGENT_VFS_WORK_DIR` | Рабочий каталог, управляемый Agent | Временное хранилище для операций с файлами и архивами. |
| `NOVUS_AGENT_SSL_CERT_DIR` | Каталог сертификатов, управляемый Agent | Источник метаданных сертификата веб-сайта только для чтения. |
| `NOVUS_AGENT_BACKUP_DIR` | Каталог резервных копий, управляемый Agent | Локальный рабочий каталог резервного копирования. |
| `NOVUS_AGENT_TELEMETRY_DISK_MOUNT` | `/` | Точка монтирования диска, используемая для телеметрии хоста. |

Среда выполнения разрешает корни VFS с помощью режима политики:
- `host_admin`: корневая область уровня хоста для явных рабочих процессов администратора.
- `scoped_runtime`: базовая изоляция до настроенных корневых томов среды выполнения.

Явно задайте режим в продакшене в соответствии с вашими операционными требованиями.

Примечание о поддержке устаревших версий: если задан только `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (без явного указания `NOVUS_AGENT_VFS_POLICY_MODE`), загрузчик сопоставляет поведение с `scoped_runtime` для обеспечения обратной совместимости.

## Миграция канонических ключей

Используйте канонические ключи во всех новых развертываниях и средствах автоматизации. Устаревшие псевдонимы предназначены исключительно для совместимости и вызывают предупреждения при запуске, если используются в качестве активного источника.

| Устаревший псевдоним | Канонический ключ | Поведение во время выполнения |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_PATH` | `NOVUS_AGENT_STATE_FILE` | Псевдоним считывается только тогда, когда канонический ключ не задан; генерируется предупреждающее событие запуска `config_deprecated_env_alias_used`. |
| `NOVUS_AGENT_VFS_ALLOWED_ROOTS` | `NOVUS_AGENT_VFS_SCOPED_ROOTS` | Псевдоним считывается только тогда, когда канонический ключ не задан; генерируется предупреждающее событие запуска `config_deprecated_env_alias_used`. |

Правило приоритета: канонический ключ имеет приоритет, когда заданы как канонический, так и устаревший псевдоним.

## PTY

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_PTY_SHELL` | `/bin/bash` | Интерактивная оболочка по умолчанию. |
| `NOVUS_AGENT_PTY_CWD` | `/` | Рабочий каталог PTY по умолчанию. |
| `NOVUS_AGENT_PTY_ALLOWED_SHELLS` | Утвержденный список разрешенных оболочек | Пути к оболочкам, разделенные запятыми, разрешенные для сеансов PTY. |

Agent проверяет выбранную оболочку по настроенному списку разрешенных. Клиенты браузера не подключаются к хосту PTY напрямую; сеансы терминала остаются в рамках транспортного контракта между Panel и Agent.

## Совместимость с Panel

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_PANEL_URL` | пусто | Необязательный URL Panel для рабочих процессов совместимости. |
| `NOVUS_AGENT_PANEL_TOKEN` | пусто | Необязательный токен Panel для рабочих процессов совместимости. Предоставляйте его только через утвержденный путь управления секретами. |

## Пример безопасной конфигурации

```ini
NOVUS_AGENT_GRPC_LISTEN=:9443
NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS=15
NOVUS_AGENT_RATE_LIMIT_PER_MINUTE=600
NOVUS_AGENT_RATE_LIMIT_BURST=120
NOVUS_AGENT_AUDIT_LOG_ENABLED=true
NOVUS_AGENT_PTY_SHELL=/bin/bash
NOVUS_AGENT_PTY_ALLOWED_SHELLS=/bin/bash,/bin/sh
```

Не копируйте секретные значения, пути к приватным ключам TLS, токены сопряжения или токены Panel в документацию, систему контроля версий, историю командной строки или аргументы процессов.
