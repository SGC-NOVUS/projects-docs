# NOVUS Agent-Core: Справочник конфигурации

Авторитетным источником конфигурации является `internal/config/config.go`. Все поддерживаемые настройки Agent представляют собой переменные окружения; недокументированные переменные не являются поддерживаемым интерфейсом.

## Прослушиватели и TLS

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_HTTP_LISTEN` | `:8080` | Адрес прослушивателя для совместимости с HTTP/WebSocket. |
| `NOVUS_AGENT_GRPC_LISTEN` | `:9443` | Адрес прослушивателя gRPC с защитой TLS. |
| `NOVUS_AGENT_WS_ALLOWED_ORIGINS` | вычисляется из происхождения `NOVUS_AGENT_PANEL_URL` плюс запасные варианты `http://127.0.0.1,http://localhost` | Список разрешенных источников WebSocket, разделенных запятыми; запросы с источниками (`Origin`), отсутствующими в списке, отклоняются. |
| `NOVUS_AGENT_SSH_LISTEN` | `:2022` | Адрес прослушивателя для совместимости с SSH/SFTP. |
| `NOVUS_AGENT_SSH_HOST_KEY_FILE` | `<dirname(NOVUS_AGENT_STATE_FILE)>/ssh_host_rsa_key` | Путь к постоянному приватному ключу хоста SSH (создается при отсутствии, переиспользуется между перезапусками). |
| `NOVUS_AGENT_TLS_CERT` | Расположение TLS-сертификата, управляемого Agent | TLS-сертификат для прослушивателя gRPC. |
| `NOVUS_AGENT_TLS_KEY` | Расположение TLS-ключа, управляемого Agent | Приватный ключ, сопряженный с TLS-сертификатом. Не размещайте материалы ключа в файлах репозитория или публичных примерах. |
| `NOVUS_AGENT_TLS_AUTOGEN_DIR` | Каталог TLS, управляемый Agent | Расположение, используемое, когда Agent создает или обновляет самоподписанный сертификат. |

TLS является обязательным для gRPC. Если материалы сертификата отсутствуют, Agent может выполнить первоначальную загрузку самоподписанного сертификата; операторам следует использовать утвержденную процедуру развертывания для установления доверия.

Для транспортного уровня совместимости SSH/SFTP Agent сохраняет ключ хоста по настроенному пути и принудительно применяет права доступа к файлу приватного ключа при загрузке.

Для транспорта совместимости консоли WebSocket включите параметры запроса контекста сессии (`session_uuid` или `session_id`) и контекста узла (`node_uuid` или `node_id`), чтобы можно было применить проверки привязки контекста JWT.
Адаптер принимает оба алиаса ключей запроса и проверяет утверждения контекста JWT на соответствие разрешенной привязке узла/контейнера/сессии.
Агент также может синхронизировать находящийся в памяти список разрешенных адресов (allowlist) WebSocket во время выполнения из аутентифицированных метаданных gRPC без перезапуска:
- `x-novus-ws-allowed-origins`: разделенный запятыми список origin.
- `x-novus-panel-url`: URL-адрес панели, используемый для получения origin, а также безопасные локальные резервные origin.

## Состояние и безопасность

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_FILE` | Расположение файла состояния Агента | Зашифрованное локальное состояние сопряжения. Алиас совместимости: `NOVUS_AGENT_STATE_PATH` (при активном алиасе выводится предупреждение об устаревании при запуске). |
| `NOVUS_AGENT_STATE_ENCRYPTION_KEY` | пусто | Необязательный ключ шифрования состояния, предоставляемый безопасной хост-средой. |
| `NOVUS_AGENT_PAIRING_TOKEN_TTL_MINUTES` | `15` | Время жизни токена сопряжения; значения меньше одной минуты сбрасываются на `15`. |
| `NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS` | `15` | Допустимое расхождение часов запроса для подписанных gRPC-запросов. |
| `NOVUS_AGENT_RATE_LIMIT_PER_MINUTE` | `600` | Лимит частоты запросов на одну панель. |
| `NOVUS_AGENT_RATE_LIMIT_BURST` | `120` | Емкость всплеска корзины токенов (token-bucket). |
| `NOVUS_AGENT_AUDIT_LOG_ENABLED` | `true` | Включает структурированные события аудита безопасности Агента. |

## Среда выполнения, файлы и телеметрия

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_DOCKER_SOCKET` | системный сокет Docker | Транспорт Docker, используемый операциями среды выполнения Agent. |
| `NOVUS_AGENT_VFS_POLICY_MODE` | `host_admin` | Режим политики VFS: `host_admin` разрешает корневые каталоги VFS на уровне хоста, `scoped_runtime` ограничивает доступ настроенными корневыми каталогами среды выполнения. |
| `NOVUS_AGENT_VFS_SCOPED_ROOTS` | `/var/lib/novus/volumes/games,/var/lib/novus/volumes/service,/var/lib/novus/volumes/web` | Разделенные запятыми изолированные корневые каталоги, используемые при `NOVUS_AGENT_VFS_POLICY_MODE=scoped_runtime`. Псевдоним совместимости: `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (при активации псевдонима выводится предупреждение об устаревании при запуске). |
| `NOVUS_AGENT_VFS_UPLOAD_DIR` | Управляемый Agent каталог загрузки | Временное хранилище для возобновляемой загрузки файлов. |
| `NOVUS_AGENT_VFS_WORK_DIR` | Управляемый Agent рабочий каталог | Временное хранилище для операций с файлами и архивами. |
| `NOVUS_AGENT_SSL_CERT_DIR` | Управляемый Agent каталог сертификатов | Источник только для чтения для метаданных сертификатов веб-сайтов. |
| `NOVUS_AGENT_BACKUP_DIR` | Управляемый Agent каталог резервного копирования | Локальный рабочий каталог резервного копирования. |
| `NOVUS_AGENT_TELEMETRY_DISK_MOUNT` | `/` | Точка монтирования диска, используемая для телеметрии хоста. |

Среда выполнения разрешает корневые каталоги VFS через режим политики:
- `host_admin`: область корневого каталога на уровне хоста для явных рабочих процессов администратора.
- `scoped_runtime`: базовая изоляция до настроенных корневых томов среды выполнения.

Явно задайте режим в рабочей среде (production) в соответствии с вашими эксплуатационными целями.

Примечание об обратной совместимости: если задан только параметр `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (без явного указания `NOVUS_AGENT_VFS_POLICY_MODE`), загрузчик сопоставляет поведение с `scoped_runtime` для обеспечения обратной совместимости.

## Миграция канонических ключей

Используйте канонические ключи во всех новых развертываниях и средствах автоматизации. Устаревшие псевдонимы предназначены исключительно для обеспечения совместимости и при использовании в качестве активного источника выводят предупреждения при запуске.

| Устаревший псевдоним | Канонический ключ | Поведение во время выполнения |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_PATH` | `NOVUS_AGENT_STATE_FILE` | Псевдоним считывается только тогда, когда канонический ключ не задан; генерируется событие предупреждения при запуске `config_deprecated_env_alias_used`. |
| `NOVUS_AGENT_VFS_ALLOWED_ROOTS` | `NOVUS_AGENT_VFS_SCOPED_ROOTS` | Псевдоним считывается только тогда, когда канонический ключ не задан; генерируется событие предупреждения при запуске `config_deprecated_env_alias_used`. |

Правило приоритета: канонический ключ имеет преимущество, если заданы как канонический ключ, так и устаревший псевдоним.

## PTY

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_PTY_SHELL` | `/bin/bash` | Интерактивная оболочка по умолчанию. |
| `NOVUS_AGENT_PTY_CWD` | `/` | Рабочая директория PTY по умолчанию. |
| `NOVUS_AGENT_PTY_ALLOWED_SHELLS` | Разрешенный список одобренных оболочек | Пути к оболочкам через запятую, разрешенные для сеансов PTY. |

Агент проверяет выбранную оболочку по настроенному разрешенному списку. Клиенты браузера не подключаются к хосту PTY напрямую; сеансы терминала остаются в рамках транспортного контракта между Panel и Agent.

## Совместимость с Panel

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_PANEL_URL` | пусто | Необязательный URL Panel для рабочих процессов совместимости. |
| `NOVUS_AGENT_PANEL_TOKEN` | пусто | Необязательный токен Panel для рабочих процессов совместимости. Передавайте его только через утвержденный путь управления секретами. |

## Пример безопасной конфигурации

```ini
NOVUS_AGENT_GRPC_LISTEN=:9443
NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS=15
NOVUS_AGENT_RATE_LIMIT_PER_MINUTE=600
NOVUS_AGENT_RATE_LIMIT_BURST=120
NOVUS_AGENT_AUDIT_LOG_ENABLED=true
NOVUS_AGENT_PTY_SHELL=/bin/bash
NOVUS_AGENT_PTY_ALLOWED_SHELLS=/bin/bash,/bin/sh
```

Не копируйте значения секретов, пути к закрытым ключам TLS, токены сопряжения или токены Panel в документацию, систему контроля версий, историю оболочки или аргументы процессов.
