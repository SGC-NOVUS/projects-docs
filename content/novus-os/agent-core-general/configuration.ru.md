# NOVUS Agent-Core: Справочник конфигурации

Авторитетным источником конфигурации является `internal/config/config.go`. Все поддерживаемые настройки Agent задаются через переменные окружения; не задокументированные переменные не являются поддерживаемым интерфейсом.

## Прослушиватели и TLS

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_HTTP_LISTEN` | `:8080` | Адрес прослушивателя совместимости HTTP/WebSocket. |
| `NOVUS_AGENT_GRPC_LISTEN` | `:9443` | Адрес прослушивателя gRPC с защитой TLS. |
| `NOVUS_AGENT_WS_ALLOWED_ORIGINS` | вычисляется из происхождения `NOVUS_AGENT_PANEL_URL` плюс запасной вариант `http://127.0.0.1,http://localhost` | Список разрешенных источников (origin) WebSocket через запятую; запросы с источниками, отсутствующими в списке, отклоняются. |
| `NOVUS_AGENT_SSH_LISTEN` | `:2022` | Адрес прослушивателя совместимости SSH/SFTP. |
| `NOVUS_AGENT_SSH_HOST_KEY_FILE` | `<dirname(NOVUS_AGENT_STATE_FILE)>/ssh_host_rsa_key` | Путь к персистентному приватному ключу хоста SSH (создается при отсутствии, переиспользуется при перезапусках). |
| `NOVUS_AGENT_TLS_CERT` | Расположение TLS-сертификата, управляемое Agent | TLS-сертификат для прослушивателя gRPC. |
| `NOVUS_AGENT_TLS_KEY` | Расположение TLS-ключа, управляемое Agent | Приватный ключ, сопряженный с TLS-сертификатом. Не размещайте материал ключа в файлах репозитория или публичных примерах. |
| `NOVUS_AGENT_TLS_AUTOGEN_DIR` | TLS-директория, управляемая Agent | Расположение, используемое Agent при создании или ротации самоподписанного сертификата. |

TLS является обязательным для gRPC. Если материалы сертификата отсутствуют, Agent может выполнить первоначальную загрузку (bootstrap) самоподписанного сертификата; операторы должны использовать утвержденную процедуру развертывания для установления доверия.

Для транспорта совместимости SSH/SFTP Agent сохраняет ключ хоста по настроенному пути и при загрузке принудительно применяет права доступа к файлу приватного ключа.

Для транспорта совместимости консоли WebSocket включите параметры запроса контекста сессии (`session_uuid` или `session_id`) и контекста узла (`node_uuid` или `node_id`), чтобы можно было применять проверки привязки контекста JWT.
Адаптер принимает как псевдонимы ключей запроса, так и проверяет утверждения (claims) контекста JWT по разрешенной привязке узла/контейнера/сессии.
Agent также может синхронизировать белый список WebSocket в памяти во время выполнения на основе аутентифицированных метаданных gRPC без перезапуска:
- `x-novus-ws-allowed-origins`: список источников через запятую.
- `x-novus-panel-url`: URL панели, используемый для вычисления источника плюс безопасные запасные локальные источники.

## Состояние и безопасность

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_FILE` | Расположение файла состояния Agent | Зашифрованное локальное состояние сопряжения. Псевдоним совместимости: `NOVUS_AGENT_STATE_PATH` (при активности псевдонима выдается предупреждение об устаревании при запуске). |
| `NOVUS_AGENT_STATE_ENCRYPTION_KEY` | пусто | Необязательный ключ шифрования состояния, предоставляемый защищенной средой хоста. |
| `NOVUS_AGENT_PAIRING_TOKEN_TTL_MINUTES` | `15` | Время жизни токена сопряжения; значения менее одной минуты заменяются на `15`. |
| `NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS` | `15` | Допустимое расхождение часов запроса для подписанных gRPC-запросов. |
| `NOVUS_AGENT_RATE_LIMIT_PER_MINUTE` | `600` | Лимит запросов в минуту на одну панель. |
| `NOVUS_AGENT_RATE_LIMIT_BURST` | `120` | Емкость всплеска (burst) для алгоритма token-bucket. |
| `NOVUS_AGENT_AUDIT_LOG_ENABLED` | `true` | Включает структурированные события аудита безопасности Agent. |

## Runtime, Files And Telemetry

| Variable | Default | Purpose |
| --- | --- | --- |
| `NOVUS_AGENT_DOCKER_SOCKET` | system Docker socket | Docker-транспорт, используемый операциями среды выполнения Agent. |
| `NOVUS_AGENT_VFS_POLICY_MODE` | `host_admin` | Режим политик VFS: `host_admin` разрешает корни VFS в масштабе всего хоста, `scoped_runtime` ограничивает доступ настроенными корнями среды выполнения. |
| `NOVUS_AGENT_VFS_SCOPED_ROOTS` | `/var/lib/novus/volumes/games,/var/lib/novus/volumes/service,/var/lib/novus/volumes/web` | Ограниченные корни, разделенные запятыми, используемые, когда задано `NOVUS_AGENT_VFS_POLICY_MODE=scoped_runtime`. Псевдоним совместимости: `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (при активности псевдонима выдается предупреждение об устаревании при запуске). |
| `NOVUS_AGENT_VFS_UPLOAD_DIR` | Каталог загрузки, управляемый Agent | Временное хранилище для возобновляемых загрузок файлов. |
| `NOVUS_AGENT_VFS_WORK_DIR` | Рабочий каталог, управляемый Agent | Временное хранилище для операций с файлами и архивами. |
| `NOVUS_AGENT_SSL_CERT_DIR` | Каталог сертификатов, управляемый Agent | Источник метаданных сертификатов веб-сайта только для чтения. |
| `NOVUS_AGENT_BACKUP_DIR` | Каталог резервных копий, управляемый Agent | Локальный рабочий каталог резервного копирования. |
| `NOVUS_AGENT_TELEMETRY_DISK_MOUNT` | `/` | Точка монтирования диска, используемая для телеметрии хоста. |

Среда выполнения разрешает корни VFS с помощью режима политик:
- `host_admin`: область корневого каталога на уровне всего хоста для явных рабочих процессов администратора.
- `scoped_runtime`: базовая изоляция до настроенных корней томов среды выполнения.

Явно задайте режим в production-окружении в соответствии с вашими операционными требованиями.

Примечание о поддержке устаревших версий: если задан только `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (без явного `NOVUS_AGENT_VFS_POLICY_MODE`), загрузчик сопоставляет поведение с `scoped_runtime` для обратной совместимости.

## Canonical Key Migration

Используйте канонические ключи во всех новых развертываниях и системах автоматизации. Устаревшие псевдонимы предназначены только для совместимости и вызывают предупреждения при запуске, если используются в качестве активного источника.

| Deprecated alias | Canonical key | Runtime behavior |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_PATH` | `NOVUS_AGENT_STATE_FILE` | Псевдоним считывается только тогда, когда канонический ключ не задан; генерируется предупреждающее событие запуска `config_deprecated_env_alias_used`. |
| `NOVUS_AGENT_VFS_ALLOWED_ROOTS` | `NOVUS_AGENT_VFS_SCOPED_ROOTS` | Псевдоним считывается только тогда, когда канонический ключ не задан; генерируется предупреждающее событие запуска `config_deprecated_env_alias_used`. |

Правило приоритета: канонический ключ имеет преимущество, когда заданы как канонический, так и устаревший псевдоним.

## PTY

| Variable | Default | Purpose |
| --- | --- | --- |
| `NOVUS_AGENT_PTY_SHELL` | `/bin/bash` | Интерактивная оболочка по умолчанию. |
| `NOVUS_AGENT_PTY_CWD` | `/` | Рабочий каталог PTY по умолчанию. |
| `NOVUS_AGENT_PTY_ALLOWED_SHELLS` | Утвержденный белый список оболочек | Разделенный запятыми список путей к оболочкам, разрешенным для сеансов PTY. |

Agent проверяет выбранную оболочку по настроенному белому списку. Браузерные клиенты не подключаются к хостовому PTY напрямую; сеансы терминала остаются за транспортным контрактом между Panel и Agent.

## Panel Compatibility

| Variable | Default | Purpose |
| --- | --- | --- |
| `NOVUS_AGENT_PANEL_URL` | пусто | Необязательный URL Panel для рабочих процессов совместимости. |
| `NOVUS_AGENT_PANEL_TOKEN` | пусто | Необязательный токен Panel для рабочих процессов совместимости. Предоставляйте его только через утвержденный путь управления секретами. |

## Пример безопасной конфигурации

```ini
NOVUS_AGENT_GRPC_LISTEN=:9443
NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS=15
NOVUS_AGENT_RATE_LIMIT_PER_MINUTE=600
NOVUS_AGENT_RATE_LIMIT_BURST=120
NOVUS_AGENT_AUDIT_LOG_ENABLED=true
NOVUS_AGENT_PTY_SHELL=/bin/bash
NOVUS_AGENT_PTY_ALLOWED_SHELLS=/bin/bash,/bin/sh
```

Не копируйте секретные значения, пути к закрытым ключам TLS, токены сопряжения или токены Panel в документацию, систему контроля версий, историю командной строки или аргументы процессов.
