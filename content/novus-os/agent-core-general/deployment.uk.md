# Розгортання NOVUS Agent

NOVUS Agent розгортається за допомогою затвердженого процесу встановлення NOVUS або робочого процесу керування вузлами. Оператори виконують підключення та моніторинг вузлів через Panel; вони не застосовують конфігурацію хост-сервісу чи облікові дані безпосередньо.

## Життєвий цикл розгортання

1. Переконайтеся, що цільовий хост відповідає вимогам до підтримуваних платформ.
2. Використовуйте затверджений інсталятор або робочий процес вузлів Panel для розгортання релізу.
3. Виконайте підключення вузла через автентифікований робочий процес Panel.
4. Перевірте працездатність вузла та статус транспорту в Panel.
5. Зафіксуйте результати релізу, підключення та валідації в системі керування змінами.

## Модель безпеки

- Транспорт агента використовує автентифікований зашифрований зв'язок.
- Секрети встановлення та ключовий матеріал залишаються в межах захищеної межі конфігурації хоста.
- Процес розгортання перевіряє налаштований реліз перед активацією.
- Оператори використовують сигнали працездатності Panel та робочі процеси інцидентів у разі збоїв.

## Усунення несправностей

Зберігайте ідентифікатор вузла, стан підключення та відображену помилку працездатності. Повторюйте лише безпечну дію, запропоновану Panel або інсталятором. Передавайте непрацюючий транспорт, збої облікових даних або сертифікатів уповноваженій команді платформи.

Процедури збирання, конфігурації сервісу та відновлення обмежені внутрішньою інженерною процедурою.
