# Развертывание NOVUS Agent

NOVUS Agent развертывается с помощью утвержденного процесса установки или управления узлами NOVUS. Операторы выполняют сопряжение и мониторинг узлов через Panel; они не применяют конфигурацию служб хоста или учетные данные напрямую.

## Жизненный цикл развертывания

1. Убедитесь, что целевой хост соответствует требованиям к поддерживаемой платформе.
2. Используйте утвержденный установщик или рабочий процесс узлов в Panel для развертывания релиза.
3. Выполните сопряжение узла с помощью аутентифицированного рабочего процесса Panel.
4. Проверьте состояние работоспособности узла и статус транспорта в Panel.
5. Занесите результаты выпуска, сопряжения и валидации в систему контроля изменений.

## Модель безопасности

- Транспорт Agent использует аутентифицированный зашифрованный обмен данными.
- Секреты установки и ключевой материал остаются в пределах защищенной границы конфигурации хоста.
- Процесс развертывания проверяет настроенный релиз перед активацией.
- Операторы используют сигналы работоспособности Panel и рабочие процессы инцидентов при сбоях.

## Устранение неполадок

Сохраняйте идентификатор узла, состояние сопряжения и отображаемую ошибку работоспособности. Повторяйте только безопасные действия, предлагаемые Panel или установщиком. Передавайте информацию о недоступности транспорта, сбоях учетных данных или сертификатов уполномоченной команде платформы.

Процедуры сборки, настройки служб и восстановления ограничены внутренним техническим регламентом.
