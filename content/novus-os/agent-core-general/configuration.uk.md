# NOVUS Agent-Core: Довідник конфігурації

Авторитетним джерелом конфігурації є `internal/config/config.go`. Усі підтримувані налаштування агента є змінними середовища; не задокументовані змінні не є підтримуваним інтерфейсом.

## Прослуховувач та TLS

| Змінна | За замовчуванням | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_HTTP_LISTEN` | `:8080` | Адреса сумісного прослуховувача HTTP/WebSocket. |
| `NOVUS_AGENT_GRPC_LISTEN` | `:9443` | Адреса захищеного за допомогою TLS прослуховувача gRPC. |
| `NOVUS_AGENT_WS_ALLOWED_ORIGINS` | визначається на основі джерела `NOVUS_AGENT_PANEL_URL` плюс запасний варіант `http://127.0.0.1,http://localhost` | Список дозволених джерел WebSocket через кому; запити з джерелами (`Origin`), яких немає у списку, відхиляються. |
| `NOVUS_AGENT_SSH_LISTEN` | `:2022` | Адреса сумісного прослуховувача SSH/SFTP. |
| `NOVUS_AGENT_SSH_HOST_KEY_FILE` | `<dirname(NOVUS_AGENT_STATE_FILE)>/ssh_host_rsa_key` | Шлях до постійного приватного ключа хоста SSH (створюється у разі відсутності, використовується повторно після перезапусків). |
| `NOVUS_AGENT_TLS_CERT` | Розташування TLS-сертифіката, керованого агентом | TLS-сертифікат для прослуховувача gRPC. |
| `NOVUS_AGENT_TLS_KEY` | Розташування TLS-ключа, керованого агентом | Приватний ключ у парі з TLS-сертифікатом. Не розміщуйте матеріали ключів у файлах репозиторію або публічних прикладах. |
| `NOVUS_AGENT_TLS_AUTOGEN_DIR` | Каталог TLS, керований агентом | Розташування, яке використовується, коли агент створює або оновлює самопідписаний сертифікат. |

TLS є обов'язковим для gRPC. Якщо матеріали сертифіката відсутні, агент може виконати завантаження (bootstrap) самопідписаного сертифіката; оператори повинні використовувати затверджену процедуру розгортання для встановлення довіри.

Для сумісного транспорту SSH/SFTP агент зберігає ключ хоста за налаштованим шляхом і примусово застосовує права доступу до файлу приватного ключа під час завантаження.

Для сумісного транспорту консолі WebSocket додайте параметри запиту контексту сеансу (`session_uuid` або `session_id`) та контексту вузла (`node_uuid` або `node_id`), щоб можна було примусово застосовувати перевірки прив'язки контексту JWT.
Адаптер приймає як псевдоніми ключів запиту, так і перевіряє твердження (claims) контексту JWT щодо визначеної прив'язки вузла/контейнера/сеансу.
Агент також може синхронізувати список дозволених WebSocket у пам'яті під час виконання з автентифікованих метаданих gRPC без перезапуску:
- `x-novus-ws-allowed-origins`: список дозволених джерел через кому.
- `x-novus-panel-url`: URL панелі, який використовується для визначення джерела разом із безпечними локальними резервними джерелами.

## Стан та безпека

| Змінна | За замовчуванням | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_FILE` | Розташування файлу стану агента | Зашифрований локальний стан створення пари. Псевдонім сумісності: `NOVUS_AGENT_STATE_PATH` (під час запуску видається попередження про застарілість, якщо псевдонім активний). |
| `NOVUS_AGENT_STATE_ENCRYPTION_KEY` | порожньо | Необов'язковий ключ шифрування стану, що надається безпечним середовищем хоста. |
| `NOVUS_AGENT_PAIRING_TOKEN_TTL_MINUTES` | `15` | Час життя токена створення пари; значення менше однієї хвилини повертаються до значення `15`. |
| `NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS` | `15` | Припустиме відхилення годинника запиту для підписаних gRPC-запитів. |
| `NOVUS_AGENT_RATE_LIMIT_PER_MINUTE` | `600` | Ліміт частоти запитів на одну панель. |
| `NOVUS_AGENT_RATE_LIMIT_BURST` | `120` | Пікова ємність маркерного букета (token-bucket burst). |
| `NOVUS_AGENT_AUDIT_LOG_ENABLED` | `true` | Усвідомлює структуру подій аудиту безпеки агента. |

## Час виконання, файли та телеметрія

| Змінна | За замовчуванням | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_DOCKER_SOCKET` | системний сокет Docker | Транспорт Docker, який використовується операціями середовища виконання агента. |
| `NOVUS_AGENT_VFS_POLICY_MODE` | `host_admin` | Режим політики VFS: `host_admin` дозволяє кореневі каталоги VFS для всього хоста, `scoped_runtime` обмежує налаштованими кореневими каталогами середовища виконання. |
| `NOVUS_AGENT_VFS_SCOPED_ROOTS` | `/var/lib/novus/volumes/games,/var/lib/novus/volumes/service,/var/lib/novus/volumes/web` | Обмежені кореневі каталоги через кому, які використовуються, коли `NOVUS_AGENT_VFS_POLICY_MODE=scoped_runtime`. Псевдонім сумісності: `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (під час запуску видається попередження про застарілість, якщо псевдонім активний). |
| `NOVUS_AGENT_VFS_UPLOAD_DIR` | Каталог завантаження, керований агентом | Тимчасове сховище для відновлюваних завантажень файлів. |
| `NOVUS_AGENT_VFS_WORK_DIR` | Робочий каталог, керований агентом | Тимчасове сховище для операцій з файлами та архівами. |
| `NOVUS_AGENT_SSL_CERT_DIR` | Каталог сертифікатів, керований агентом | Джерело лише для читання для метаданих сертифікатів вебсайту. |
| `NOVUS_AGENT_BACKUP_DIR` | Каталог резервних копій, керований агентом | Локальний робочий каталог резервного копіювання. |
| `NOVUS_AGENT_TELEMETRY_DISK_MOUNT` | `/` | Монтування диска, яке використовується для телеметрії хоста. |

Середовище виконання визначає кореневі каталоги VFS через режим політики:
- `host_admin`: область кореневого каталогу для всього хоста для явних адміністративних робочих процесів.
- `scoped_runtime`: базова ізоляція до налаштованих кореневих каталогів томів середовища виконання.

Встановіть режим явно у виробничому середовищі відповідно до вашого операційного наміру.

Примітка щодо застарілої сумісності: якщо встановлено лише `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (без явного `NOVUS_AGENT_VFS_POLICY_MODE`), завантажувач зіставляє поведінку з `scoped_runtime` для забезпечення зворотної сумісності.

## Міграція канонічних ключів

Використовуйте канонічні ключі в усіх нових розгортаннях та засобах автоматизації. Застарілі псевдоніми призначені лише для сумісності та створюють попередження під час запуску, якщо використовуються як активне джерело.

| Застарілий псевдонім | Канонічний ключ | Поведінка середовища виконання |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_PATH` | `NOVUS_AGENT_STATE_FILE` | Псевдонім читається лише тоді, коли канонічний ключ не встановлено; генерується подія попередження під час запуску `config_deprecated_env_alias_used`. |
| `NOVUS_AGENT_VFS_ALLOWED_ROOTS` | `NOVUS_AGENT_VFS_SCOPED_ROOTS` | Псевдонім читається лише тоді, коли канонічний ключ не встановлено; генерується подія попередження під час запуску `config_deprecated_env_alias_used`. |

Правило пріоритету: канонічний ключ перемагає, коли встановлено і канонічний, і застарілий псевдонім.

## PTY

| Змінна | За замовчуванням | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_PTY_SHELL` | `/bin/bash` | Інтерактивна оболонка за замовчуванням. |
| `NOVUS_AGENT_PTY_CWD` | `/` | Робочий каталог PTY за замовчуванням. |
| `NOVUS_AGENT_PTY_ALLOWED_SHELLS` | Затверджений список дозволених оболонок | Шляхи до оболонок через кому, дозволені для сеансів PTY. |

Агент перевіряє вибрану оболонку за налаштованим списком дозволених. Клієнти браузера не підключаються до PTY хоста напряму; сеанси термінала залишаються за транспортним контрактом між панеллю та агентом.

## Сумісність з панеллю

| Змінна | За замовчуванням | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_PANEL_URL` | порожньо | Необов'язковий URL панелі для робочих процесів сумісності. |
| `NOVUS_AGENT_PANEL_TOKEN` | порожньо | Необов'язковий токен панелі для робочих процесів сумісності. Надавайте його лише через затверджений шлях керування секретами. |

## Безпечний приклад конфігурації

```ini
NOVUS_AGENT_GRPC_LISTEN=:9443
NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS=15
NOVUS_AGENT_RATE_LIMIT_PER_MINUTE=600
NOVUS_AGENT_RATE_LIMIT_BURST=120
NOVUS_AGENT_AUDIT_LOG_ENABLED=true
NOVUS_AGENT_PTY_SHELL=/bin/bash
NOVUS_AGENT_PTY_ALLOWED_SHELLS=/bin/bash,/bin/sh
```

Не копіюйте секретні значення, розташування приватних ключів TLS, токени створення пари або токени панелі в документацію, систему керування версіями, історію оболонки або аргументи процесів.
