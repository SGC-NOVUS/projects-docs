# NOVUS Agent-Core: Довідник конфігурації

Авторитетним джерелом конфігурації є `internal/config/config.go`. Усі підтримувані налаштування агента є змінними середовища; не задокументовані змінні не є підтримуваним інтерфейсом.

## Прослуховувач та TLS

| Змінна | За замовчуванням | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_HTTP_LISTEN` | `:8080` | Адреса прослуховувача сумісності HTTP/WebSocket. |
| `NOVUS_AGENT_GRPC_LISTEN` | `:9443` | Адреса захищеного за допомогою TLS gRPC-прослуховувача. |
| `NOVUS_AGENT_WS_ALLOWED_ORIGINS` | похідна від джерела `NOVUS_AGENT_PANEL_URL` плюс резервний варіант `http://127.0.0.1,http://localhost` | Список дозволених джерел WebSocket, розділених комами; запити з джерелом (`Origin`), якого немає в списку, відхиляються. |
| `NOVUS_AGENT_SSH_LISTEN` | `:2022` | Адреса прослуховувача сумісності SSH/SFTP. |
| `NOVUS_AGENT_SSH_HOST_KEY_FILE` | `<dirname(NOVUS_AGENT_STATE_FILE)>/ssh_host_rsa_key` | Шлях до постійного приватного ключа хоста SSH (створюється, якщо відсутній, повторно використовується після перезапусків). |
| `NOVUS_AGENT_TLS_CERT` | Розташування TLS-сертифіката, що керується агентом | TLS-сертифікат для gRPC-прослуховувача. |
| `NOVUS_AGENT_TLS_KEY` | Розташування TLS-ключа, що керується агентом | Приватний ключ у парі з TLS-сертифікатом. Не розміщуйте матеріали ключів у файлах репозиторію чи публічних прикладах. |
| `NOVUS_AGENT_TLS_AUTOGEN_DIR` | Директорія TLS, що керується агентом | Розташування, яке використовується, коли агент створює або ротує самопідписаний сертифікат. |

TLS є обов'язковим для gRPC. Якщо матеріали сертифіката відсутні, агент може самостійно ініціалізувати самопідписаний сертифікат; оператори повинні використовувати затверджену процедуру розгортання для встановлення довіри.

Для транспортного протоколу сумісності SSH/SFTP агент зберігає ключ хоста за налаштованим шляхом та примусово застосовує дозволи файлу приватного ключа під час завантаження.

Для сумісності транспортного протоколу WebSocket-консолі додайте параметри запиту контексту сесії (`session_uuid` або `session_id`) та контексту вузла (`node_uuid` або `node_id`), щоб можна було застосувати перевірки прив'язки контексту JWT.
Адаптер приймає псевдоніми ключів запиту та перевіряє claims контексту JWT відносно визначеної прив'язки вузла/контейнера/сесії.
Агент також може синхронізувати білий список (allowlist) WebSocket у пам'яті під час виконання за допомогою автентифікованих метаданих gRPC без перезапуску:
- `x-novus-ws-allowed-origins`: розділений комами список джерел (origins).
- `x-novus-panel-url`: URL-адреса панелі, що використовується для виведення джерела плюс безпечні локальні резервні джерела.

## State And Security

| Variable | Default | Purpose |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_FILE` | Розташування файлу стану Agent | Зашифрований локальний стан створення пари. Псевдонім сумісності: `NOVUS_AGENT_STATE_PATH` (під час запуску видається попередження про застарілість, якщо псевдонім активний). |
| `NOVUS_AGENT_STATE_ENCRYPTION_KEY` | порожньо | Необов'язковий ключ шифрування стану, що надається безпечним середовищем хоста. |
| `NOVUS_AGENT_PAIRING_TOKEN_TTL_MINUTES` | `15` | Час життя токена створення пари; значення менше однієї хвилини повертаються до `15`. |
| `NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS` | `15` | Прийнятне розходження годинника запиту для підписаних запитів gRPC. |
| `NOVUS_AGENT_RATE_LIMIT_PER_MINUTE` | `600` | Ліміт кількості запитів на панель на хвилину. |
| `NOVUS_AGENT_RATE_LIMIT_BURST` | `120` | Ємність пакета (burst) маркерного відра (token-bucket). |
| `NOVUS_AGENT_AUDIT_LOG_ENABLED` | `true` | Увімкнення структурованих подій аудит-безпеки Agent. |

## Runtime, Files And Telemetry

| Variable | Default | Purpose |
| --- | --- | --- |
| `NOVUS_AGENT_DOCKER_SOCKET` | system Docker socket | Docker транспорт, що використовується операціями середовища виконання Agent. |
| `NOVUS_AGENT_VFS_POLICY_MODE` | `host_admin` | Режим політики VFS: `host_admin` дозволяє корені VFS на рівні хоста, `scoped_runtime` обмежує налаштованими коренями середовища виконання. |
| `NOVUS_AGENT_VFS_SCOPED_ROOTS` | `/var/lib/novus/volumes/games,/var/lib/novus/volumes/service,/var/lib/novus/volumes/web` | Розділені комами обмежені корені, що використовуються, коли `NOVUS_AGENT_VFS_POLICY_MODE=scoped_runtime`. Псевдонім сумісності: `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (під час запуску видається попередження про застарілість, якщо псевдонім активний). |
| `NOVUS_AGENT_VFS_UPLOAD_DIR` | Agent-managed upload directory | Тимчасове сховище для завантажень файлів із можливістю відновлення. |
| `NOVUS_AGENT_VFS_WORK_DIR` | Agent-managed work directory | Тимчасове сховище для операцій з файлами та архівами. |
| `NOVUS_AGENT_SSL_CERT_DIR` | Agent-managed certificate directory | Джерело лише для читання для метаданих сертифікатів вебсайтів. |
| `NOVUS_AGENT_BACKUP_DIR` | Agent-managed backup directory | Робочий каталог локального резервного копіювання. |
| `NOVUS_AGENT_TELEMETRY_DISK_MOUNT` | `/` | Монтування диска, що використовується для телеметрії хоста. |

Середовище виконання розв'язує корені VFS за допомогою режиму політики:
- `host_admin`: область кореня на рівні хоста для явних робочих процесів адміністратора.
- `scoped_runtime`: ізоляція базової лінії до налаштованих коренів томів середовища виконання.

Встановіть режим явно у виробничому середовищі відповідно до вашого операційного призначення.

Примітка щодо застарілої сумісності: якщо встановлено лише `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (без явного `NOVUS_AGENT_VFS_POLICY_MODE`), завантажувач зіставляє поведінку з `scoped_runtime` задля зворотної сумісності.

## Canonical Key Migration

Використовуйте канонічні ключі у всіх нових розгортаннях та засобах автоматизації. Застарілі псевдоніми залишено лише для сумісності; при їх використанні як активного джерела генеруються попередження під час запуску.

| Застарілий псевдонім | Канонічний ключ | Поведінка під час виконання |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_PATH` | `NOVUS_AGENT_STATE_FILE` | Псевдонім зчитується лише тоді, коли канонічний ключ не задано; генерується подія попередження про запуск `config_deprecated_env_alias_used`. |
| `NOVUS_AGENT_VFS_ALLOWED_ROOTS` | `NOVUS_AGENT_VFS_SCOPED_ROOTS` | Псевдонім зчитується лише тоді, коли канонічний ключ не задано; генерується подія попередження про запуск `config_deprecated_env_alias_used`. |

Правило пріоритетності: канонічний ключ має перевагу, якщо задано і канонічний ключ, і застарілий псевдонім.

## PTY

| Змінна | За замовчуванням | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_PTY_SHELL` | `/bin/bash` | Інтерактивна оболонка за замовчуванням. |
| `NOVUS_AGENT_PTY_CWD` | `/` | Робочий каталог PTY за замовчуванням. |
| `NOVUS_AGENT_PTY_ALLOWED_SHELLS` | Дозволений список схвалених оболонок | Шляхи до оболонок, розділені комами, які дозволені для сеансів PTY. |

Агент перевіряє вибрану оболонку за налаштованим списком дозволених. Клієнти браузера не підключаються до хостового PTY напряму; сеанси термінала залишаються захищеними транспортним контрактом між Panel та Agent.

## Сумісність з Panel

| Змінна | Замовчування | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_PANEL_URL` | порожньо | Необов'язковий URL Panel для робочих процесів сумісності. |
| `NOVUS_AGENT_PANEL_TOKEN` | порожньо | Необов'язковий токен Panel для робочих процесів сумісності. Надавайте його лише через затверджений шлях керування секретами. |

## Приклад безпечної конфігурації

```ini
NOVUS_AGENT_GRPC_LISTEN=:9443
NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS=15
NOVUS_AGENT_RATE_LIMIT_PER_MINUTE=600
NOVUS_AGENT_RATE_LIMIT_BURST=120
NOVUS_AGENT_AUDIT_LOG_ENABLED=true
NOVUS_AGENT_PTY_SHELL=/bin/bash
NOVUS_AGENT_PTY_ALLOWED_SHELLS=/bin/bash,/bin/sh
```

Не копіюйте значення секретів, розташування приватних ключів TLS, токени створення пари або токени Panel у документацію, систему контролю версій, історію оболонки чи аргументи процесів.
