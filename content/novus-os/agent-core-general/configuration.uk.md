# NOVUS Agent-Core: Довідник з конфігурації

Авторитетним джерелом конфігурації є `internal/config/config.go`. Усі підтримувані налаштування Agent є змінними середовища; не задокументовані змінні не є підтримуваним інтерфейсом.

## Прослуховувач та TLS

| Змінна | За замовчуванням | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_HTTP_LISTEN` | `:8080` | Адреса сумісного HTTP/WebSocket-прослуховувача. |
| `NOVUS_AGENT_GRPC_LISTEN` | `:9443` | Адреса gRPC-прослуховувача із захистом TLS. |
| `NOVUS_AGENT_WS_ALLOWED_ORIGINS` | похідна від джерела `NOVUS_AGENT_PANEL_URL` плюс запасний варіант `http://127.0.0.1,http://localhost` | Список дозволених джерел WebSocket, розділений комами; запити з недозволеними заголовками `Origin` відхиляються. |
| `NOVUS_AGENT_SSH_LISTEN` | `:2022` | Адреса сумісного SSH/SFTP-прослуховувача. |
| `NOVUS_AGENT_SSH_HOST_KEY_FILE` | `<dirname(NOVUS_AGENT_STATE_FILE)>/ssh_host_rsa_key` | Шлях до постійного приватного ключа хоста SSH (створюється, якщо відсутній, використовується повторно після перезапусків). |
| `NOVUS_AGENT_TLS_CERT` | Розташування TLS-сертифіката, що керується Agent | TLS-сертифікат для gRPC-прослуховувача. |
| `NOVUS_AGENT_TLS_KEY` | Розташування TLS-ключа, що керується Agent | Приватний ключ у парі з TLS-сертифікатом. Не розміщуйте матеріали ключів у файлах репозиторію чи публічних прикладах. |
| `NOVUS_AGENT_TLS_AUTOGEN_DIR` | TLS-директорія, що керується Agent | Розташування, яке використовується, коли Agent створює або оновлює самопідписаний сертифікат. |

Протокол TLS є обов'язковим для gRPC. Якщо матеріали сертифікатів відсутні, Agent може самостійно ініціалізувати самопідписаний сертифікат; оператори повинні використовувати затверджену процедуру розгортання для встановлення довіри.

Для сумісного транспорту SSH/SFTP Agent зберігає ключ хоста у налаштованому шляху та примусово застосовує права доступу до файлу приватного ключа під час завантаження.

Для сумісного транспорту консолі WebSocket включіть параметри запиту контексту сеансу (`session_uuid` або `session_id`) і контексту вузла (`node_uuid` або `node_id`), щоб можна було застосовувати перевірки прив'язки контексту JWT.
Адаптер приймає як псевдоніми ключів запиту, так і перевіряє претензії (claims) контексту JWT щодо визначеної прив'язки вузла/контейнера/сеансу.
Agent також може синхронізувати дозволені джерела WebSocket у пам'яті під час виконання з автентифікованих метаданих gRPC без перезапуску:
- `x-novus-ws-allowed-origins`: список джерел, розділених комами.
- `x-novus-panel-url`: URL-адреса панелі, яка використовується для виведення джерела разом із безпечними локальними резервними джерелами.

## Стану та безпека

| Змінна | За замовчуванням | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_FILE` | Розташування файлу стану Agent | Зашифрований локальний стан створення пари. Псевдонім сумісності: `NOVUS_AGENT_STATE_PATH` (попередження про застарілість під час запуску видається, коли активний псевдонім). |
| `NOVUS_AGENT_STATE_ENCRYPTION_KEY` | порожньо | Необов'язковий ключ шифрування стану, що надається безпечним середовищем хоста. |
| `NOVUS_AGENT_PAIRING_TOKEN_TTL_MINUTES` | `15` | Час життя токена створення пари; значення нижче однієї хвилини повертаються до `15`. |
| `NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS` | `15` | Прийнятне розходження годинника запиту для підписаних gRPC-запитів. |
| `NOVUS_AGENT_RATE_LIMIT_PER_MINUTE` | `600` | Ліміт частоти запитів на панель. |
| `NOVUS_AGENT_RATE_LIMIT_BURST` | `120` | Ємність пакетів (burst) для токен-бакета. |
| `NOVUS_AGENT_AUDIT_LOG_ENABLED` | `true` | Усвідомлює структуру подій аудиту безпеки Agent. |

## Середовище виконання, файли та телеметрія

| Змінна | За замовчуванням | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_DOCKER_SOCKET` | системний сокет Docker | Транспорт Docker, який використовується операціями виконання Agent. |
| `NOVUS_AGENT_VFS_POLICY_MODE` | `host_admin` | Режим політики VFS: `host_admin` дозволяє корені VFS на рівні всього хоста, `scoped_runtime` обмежує налаштованими коренями виконання. |
| `NOVUS_AGENT_VFS_SCOPED_ROOTS` | `/var/lib/novus/volumes/games,/var/lib/novus/volumes/service,/var/lib/novus/volumes/web` | Обмежені корені, розділені комами, які використовуються, коли `NOVUS_AGENT_VFS_POLICY_MODE=scoped_runtime`. Псевдонім сумісності: `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (попередження про застарілість під час запуску видається, коли активний псевдонім). |
| `NOVUS_AGENT_VFS_UPLOAD_DIR` | Директорія завантаження, що керується Agent | Тимчасове сховище для відновлюваних завантажень файлів. |
| `NOVUS_AGENT_VFS_WORK_DIR` | Робоча директорія, що керується Agent | Тимчасове сховище для операцій з файлами та архівами. |
| `NOVUS_AGENT_SSL_CERT_DIR` | Директорія сертифікатів, що керується Agent | Джерело лише для читання для метаданих сертифікатів веб-сайту. |
| `NOVUS_AGENT_BACKUP_DIR` | Директорія резервних копій, що керується Agent | Локальна робоча директорія резервних копій. |
| `NOVUS_AGENT_TELEMETRY_DISK_MOUNT` | `/` | Монтування диска, що використовується для телеметрії хоста. |

Середовище виконання визначає корені VFS за допомогою режиму політики:
- `host_admin`: область кореня на рівні хоста для явних робочих процесів адміністратора.
- `scoped_runtime`: базова ізоляція до налаштованих коренів томів виконання.

Встановлюйте режим явно у виробничому середовищі відповідно до ваших операційних намірів.

Примітка щодо застарілої сумісності: якщо встановлено лише `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (без явного `NOVUS_AGENT_VFS_POLICY_MODE`), завантажувач зіставляє поведінку з `scoped_runtime` для забезпечення зворотної сумісності.

## Міграція канонічних ключів

Використовуйте канонічні ключі у всіх нових розгортаннях та засобах автоматизації. Застарілі псевдоніми призначені лише для сумісності та створюють попередження під час запуску, якщо використовуються як активне джерело.

| Застарілий псевдонім | Канонічний ключ | Поведінка середовища виконання |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_PATH` | `NOVUS_AGENT_STATE_FILE` | Псевдонім зчитується лише тоді, коли канонічний ключ не встановлено; виводиться подія попередження про застарілість при запуску `config_deprecated_env_alias_used`. |
| `NOVUS_AGENT_VFS_ALLOWED_ROOTS` | `NOVUS_AGENT_VFS_SCOPED_ROOTS` | Псевдонім зчитується лише тоді, коли канонічний ключ не встановлено; виводиться подія попередження про застарілість при запуску `config_deprecated_env_alias_used`. |

Правило пріоритету: канонічний ключ перемагає, коли встановлено як канонічний, так і застарілий псевдонім.

## PTY

| Змінна | За замовчуванням | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_PTY_SHELL` | `/bin/bash` | Інтерактивна оболонка за замовчуванням. |
| `NOVUS_AGENT_PTY_CWD` | `/` | Робоча директорія PTY за замовчуванням. |
| `NOVUS_AGENT_PTY_ALLOWED_SHELLS` | Затверджений список дозволених оболонок | Шляхи оболонок, розділені комами, дозволені для сеансів PTY. |

Agent перевіряє вибрану оболонку щодо налаштованого списку дозволених. Клієнти браузера не підключаються безпосередньо до PTY хоста; сеанси термінала залишаються поза транспортним контрактом Panel-to-Agent.

## Сумісність з панеллю

| Змінна | За замовчуванням | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_PANEL_URL` | порожньо | Необов'язковий URL-адреса Panel для робочих процесів сумісності. |
| `NOVUS_AGENT_PANEL_TOKEN` | порожньо | Необов'язковий токен Panel для робочих процесів сумісності. Надавайте його лише через затверджений шлях керування секретами. |

## Приклад безпечної конфігурації

```ini
NOVUS_AGENT_GRPC_LISTEN=:9443
NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS=15
NOVUS_AGENT_RATE_LIMIT_PER_MINUTE=600
NOVUS_AGENT_RATE_LIMIT_BURST=120
NOVUS_AGENT_AUDIT_LOG_ENABLED=true
NOVUS_AGENT_PTY_SHELL=/bin/bash
NOVUS_AGENT_PTY_ALLOWED_SHELLS=/bin/bash,/bin/sh
```

Не копіюйте секретні значення, розташування приватних ключів TLS, токени створення пари або токени Panel у документацію, контроль джерел, історію оболонки або аргументи процесів.
