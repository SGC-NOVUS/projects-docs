# NOVUS Agent-Core: Довідник з конфігурації

Авторитетним джерелом конфігурації є `internal/config/config.go`. Усі підтримувані налаштування агента є змінними середовища; не задокументовані змінні не є підтримуваним інтерфейсом.

## Слухач та TLS

| Змінна | За замовчуванням | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_HTTP_LISTEN` | `:8080` | Адреса слухача сумісності HTTP/WebSocket. |
| `NOVUS_AGENT_GRPC_LISTEN` | `:9443` | Адреса захищеного за допомогою TLS слухача gRPC. |
| `NOVUS_AGENT_WS_ALLOWED_ORIGINS` | обчислюється з джерела `NOVUS_AGENT_PANEL_URL` плюс запасний варіант `http://127.0.0.1,http://localhost` | Список дозволених джерел WebSocket через кому; запити з недозволеними заголовками `Origin` відхиляються. |
| `NOVUS_AGENT_SSH_LISTEN` | `:2022` | Адреса слухача сумісності SSH/SFTP. |
| `NOVUS_AGENT_SSH_HOST_KEY_FILE` | `<dirname(NOVUS_AGENT_STATE_FILE)>/ssh_host_rsa_key` | Шлях до постійного приватного ключа хоста SSH (створюється, якщо відсутній, використовується повторно під час перезапусків). |
| `NOVUS_AGENT_TLS_CERT` | Розташування TLS-сертифіката, що керується агентом | TLS-сертифікат для слухача gRPC. |
| `NOVUS_AGENT_TLS_KEY` | Розташування TLS-ключа, що керується агентом | Приватний ключ у парі з TLS-сертифікатом. Не розміщуйте матеріали ключів у файлах репозиторію або публічних прикладах. |
| `NOVUS_AGENT_TLS_AUTOGEN_DIR` | Каталог TLS, що керується агентом | Розташування, яке використовується, коли агент створює або ротує самопідписаний сертифікат. |

TLS є обов'язковим для gRPC. Якщо матеріал сертифіката відсутній, агент може завантажити самопідписаний сертифікат; оператори повинні використовувати затверджену процедуру розгортання для встановлення довіри.

Для транспортного рівня сумісності SSH/SFTP агент зберігає ключ хоста за налаштованим шляхом і застосовує дозволи файлу приватного ключа під час завантаження.

Для забезпечення сумісності транспортного протоколу консолі WebSocket додайте параметри запиту контексту сесії (`session_uuid` або `session_id`) та контексту ноди (`node_uuid` або `node_id`), щоб можна було застосувати перевірки прив'язки контексту JWT.
Адаптер приймає псевдоніми ключів запиту та перевіряє claims контексту JWT щодо визначеної прив'язки ноди/контейнера/сесії.
Agent також може синхронізувати вбудований у пам'ять список дозволених джерел (allowlist) WebSocket під час виконання з автентифікованих метаданих gRPC без перезапуску:
- `x-novus-ws-allowed-origins`: розділений комами список джерел (origins).
- `x-novus-panel-url`: URL панелі, що використовується для виведення джерела, а також безпечні локальні резервні джерела.

## State And Security

| Variable | Default | Purpose |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_FILE` | Розташування файлу стану Agent | Зашифрований стан локального сполучення (pairing). Псевдонім сумісності: `NOVUS_AGENT_STATE_PATH` (під час запуску виводиться попередження про застарілість, якщо псевдонім активний). |
| `NOVUS_AGENT_STATE_ENCRYPTION_KEY` | порожньо | Необов'язковий ключ шифрування стану, що надається безпечним середовищем хоста. |
| `NOVUS_AGENT_PAIRING_TOKEN_TTL_MINUTES` | `15` | Час життя токена сполучення; значення менші за одну хвилину автоматично замінюються на `15`. |
| `NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS` | `15` | Допустиме відхилення годинника запиту для підписаних запитів gRPC. |
| `NOVUS_AGENT_RATE_LIMIT_PER_MINUTE` | `600` | Ліміт кількості запитів на панель за хвилину. |
| `NOVUS_AGENT_RATE_LIMIT_BURST` | `120` | Пікова ємність маркерного буфера (token-bucket burst capacity). |
| `NOVUS_AGENT_AUDIT_LOG_ENABLED` | `true` | Усвідомлює структуру подій безпекового аудиту Agent. |

## Runtime, Files And Telemetry

| Variable | Default | Purpose |
| --- | --- | --- |
| `NOVUS_AGENT_DOCKER_SOCKET` | system Docker socket | Docker-транспорт, що використовується операціями середовища виконання Agent. |
| `NOVUS_AGENT_VFS_POLICY_MODE` | `host_admin` | Режим політики VFS: `host_admin` дозволяє кореневі каталоги VFS для всього хоста, `scoped_runtime` обмежує налаштованими кореневими каталогами середовища виконання. |
| `NOVUS_AGENT_VFS_SCOPED_ROOTS` | `/var/lib/novus/volumes/games,/var/lib/novus/volumes/service,/var/lib/novus/volumes/web` | Розділені комами обмежені кореневі каталоги, що використовуються, коли `NOVUS_AGENT_VFS_POLICY_MODE=scoped_runtime`. Псевдонім сумісності: `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (попередження про застарілість видається під час запуску, якщо псевдонім активний). |
| `NOVUS_AGENT_VFS_UPLOAD_DIR` | Agent-managed upload directory | Тимчасове сховище для відновлюваних завантажень файлів. |
| `NOVUS_AGENT_VFS_WORK_DIR` | Agent-managed work directory | Тимчасове сховище для операцій з файлами та архівами. |
| `NOVUS_AGENT_SSL_CERT_DIR` | Agent-managed certificate directory | Джерело лише для читання для метаданих сертифікатів вебсайтів. |
| `NOVUS_AGENT_BACKUP_DIR` | Agent-managed backup directory | Робочий каталог локального резервного копіювання. |
| `NOVUS_AGENT_TELEMETRY_DISK_MOUNT` | `/` | Точка монтування диска, що використовується для телеметрії хоста. |

Середовище виконання визначає кореневі каталоги VFS через режим політики:
- `host_admin`: область кореневого каталогу для всього хоста для явних робочих процесів адміністратора.
- `scoped_runtime`: базова ізоляція до налаштованих кореневих каталогів томомім середовища виконання.

Встановіть режим явно у виробничому середовищі відповідно до вашого операційного призначення.

Примітка щодо застарілої сумісності: якщо встановлено лише `NOVUS_AGENT_VFS_ALLOWED_ROOTS` (без явного `NOVUS_AGENT_VFS_POLICY_MODE`), завантажувач зіставляє поведінку з `scoped_runtime` заради зворотної сумісності.

## Канонічна міграція ключів

Використовуйте канонічні ключі в усіх нових розгортаннях та засобах автоматизації. Застарілі псевдоніми призначені лише для сумісності та генерують попередження під час запуску, якщо використовуються як активне джерело.

| Застарілий псевдонім | Канонічний ключ | Поведінка під час виконання |
| --- | --- | --- |
| `NOVUS_AGENT_STATE_PATH` | `NOVUS_AGENT_STATE_FILE` | Псевдонім зчитується лише тоді, коли канонічний ключ не задано; генерується подія попередження під час запуску `config_deprecated_env_alias_used`. |
| `NOVUS_AGENT_VFS_ALLOWED_ROOTS` | `NOVUS_AGENT_VFS_SCOPED_ROOTS` | Псевдонім зчитується лише тоді, коли канонічний ключ не задано; генерується подія попередження під час запуску `config_deprecated_env_alias_used`. |

Правило пріоритету: канонічний ключ перемагає, коли встановлено і канонічний, і застарілий псевдонім.

## PTY

| Змінна | За замовчуванням | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_PTY_SHELL` | `/bin/bash` | Інтерактивна оболонка за замовчуванням. |
| `NOVUS_AGENT_PTY_CWD` | `/` | Робочий каталог PTY за замовчуванням. |
| `NOVUS_AGENT_PTY_ALLOWED_SHELLS` | Схвалений білий список оболонок | Шляхи до оболонок, розділені комами, дозволені для сеансів PTY. |

Агент перевіряє вибрану оболонку за налаштованим білим списком. Клієнти браузера не підключаються до хоста PTY безпосередньо; сеанси термінала залишаються поза межами транспортного контракту між панеллю (Panel) та агентом (Agent).

## Сумісність з Panel

| Змінна | Замовчування | Призначення |
| --- | --- | --- |
| `NOVUS_AGENT_PANEL_URL` | порожньо | Необов'язковий URL Panel для робочих процесів сумісності. |
| `NOVUS_AGENT_PANEL_TOKEN` | порожньо | Необов'язковий токен Panel для робочих процесів сумісності. Надавайте його лише через затверджений шлях керування секретами. |

## Приклад безпечної конфігурації

```ini
NOVUS_AGENT_GRPC_LISTEN=:9443
NOVUS_AGENT_ALLOWED_CLOCK_SKEW_SECONDS=15
NOVUS_AGENT_RATE_LIMIT_PER_MINUTE=600
NOVUS_AGENT_RATE_LIMIT_BURST=120
NOVUS_AGENT_AUDIT_LOG_ENABLED=true
NOVUS_AGENT_PTY_SHELL=/bin/bash
NOVUS_AGENT_PTY_ALLOWED_SHELLS=/bin/bash,/bin/sh
```

Не копіюйте значення секретів, розташування приватних ключів TLS, токени створення пари або токени Panel у документацію, систему контролю версій, історію оболонки чи аргументи процесів.
