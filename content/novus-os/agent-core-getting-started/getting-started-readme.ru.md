# Начало работы с NOVUS Agent

NOVUS Agent — это хост-ориентированная служба Data-Plane для NOVUS OS. Она выполняет авторизованные операции во время выполнения и предоставляет типизированный транспорт, используемый Panel; она не является веб-приложением для конечных пользователей.

## Рекомендуемый порядок действий

1. Установите Agent с помощью утвержденного установщика NOVUS Installer или утвержденной процедуры релиза.
2. Подтвердите работоспособность службы с помощью инструкции по развертыванию (deployment runbook).
3. Свяжите (Pair) Agent в рамках рабочего процесса регистрации узла Panel.
4. Управляйте экземплярами, файлами, телеметрией и терминалами через Panel в соответствии с назначенными разрешениями.
