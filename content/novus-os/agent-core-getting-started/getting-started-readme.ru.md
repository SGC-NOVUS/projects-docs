# Начало работы с NOVUS Agent

NOVUS Agent — это хост-ориентированная служба Data-Plane для NOVUS OS. Она выполняет авторизованные операции во время выполнения и предоставляет типизированный транспорт, используемый Panel; она не является ориентированным на пользователя веб-приложением.

## Рекомендуемый порядок действий

1. Установите Agent с помощью утвержденного NOVUS Installer или утвержденной процедуры релиза.
2. Убедитесь, что служба работает корректно, используя руководство по развертыванию (deployment runbook).
3. Выполните сопряжение Agent через рабочий процесс регистрации узла в Panel.
4. Управляйте экземплярами, файлами, телеметрией и терминалами через Panel в соответствии с назначенными разрешениями.
