# Архитектура безопасности и криптографическая модель

**Проект:** Novus Life  
**Разработчик:** SGC-NOVUS (System Generation Core)  
**Уровень защиты:** Клиентское сквозное шифрование с нулевым разглашением (Zero-Knowledge E2EE)

---

## 1. Модель угроз и архитектурные принципы

Архитектура Novus Life исходит из предположения, что центральные серверы, облачные каналы и инфраструктура провайдера могут подвергаться попыткам инспекции или компрометации. Для обеспечения абсолютной конфиденциальности данных платформа реализует архитектуру **Zero-Knowledge**:

1. **Исключительно клиентское шифрование:** Первичные показания счетчиков, наименования объектов, финансовые суммы, балансы карт и заметки никогда не передаются на сервер в открытом виде.
2. **Отсутствие мастер-ключей на сервере:** Центральная база данных PostgreSQL и серверные API не содержат закрытых ключей или секретов, позволяющих восстановить исходные данные.
3. **Аппаратное ускорение криптографии:** Все криптографические операции выполняются через стандартный W3C **Web Crypto API** (`crypto.subtle`) с использованием аппаратных инструкций процессора (AES-NI).

## 2. Криптографические примитивы и спецификации

### 2.1 Симметричное шифрование (AES-GCM-256)
- **Алгоритм:** `AES-GCM` (Advanced Encryption Standard in Galois/Counter Mode).
- **Длина ключа:** 256 бит.
- **Вектор инициализации (IV):** 96-битное криптографически стойкое значение, генерируемое для каждой операции через `crypto.getRandomValues()`.
- **Тег целостности:** 128-битный аутентификационный тег, встроенный в поток GCM для обнаружения модификации шифротекста.

### 2.2 Деривация ключей (PBKDF2)
- **Алгоритм:** `PBKDF2` (Password-Based Key Derivation Function 2).
- **Функция псевдослучайности:** `HMAC-SHA-256`.
- **Количество итераций:** 100 000 циклов.
- **Соль:** Изолированная соль энтропии на уровне локального защищенного хранилища.

## 3. Защита хранилища и изоляция в ОС

### 3.1 Persistent Storage API
Браузерные движки по умолчанию могут удалять IndexedDB при нехватке дискового пространства. Novus Life запрашивает постоянный режим:
```typescript
await navigator.storage.persist();
```
Режим постоянного хранения защищает локальную базу данных от автоматической очистки операционной системой.

### 3.2 Песочница WebAPK
На мобильных устройствах под управлением Android приложение функционирует в изолированной среде WebAPK с выделенным Linux UID, предотвращая доступ сторонних приложений.

## 4. Резервное копирование в Google Drive

При синхронизации с Google Drive:
- Запрашиваемый scope: `https://www.googleapis.com/auth/drive.appdata`.
- Файлы размещаются в изолированном каталоге `appDataFolder`.
- Перед отправкой снапшот (`novus_life_vault.json.enc`) шифруется на клиенте алгоритмом AES-256-GCM.
