# Офіційний портал документації Novus Life

> **Версія:** 1.0.0-beta Enterprise Edition  
> **Екосистема:** Novus Life (Vue 3 PWA, Express REST API, PostgreSQL 18, Dexie.js v4)  
> **Платформи:** Web, Progressive Web App (Android, iOS, Windows, macOS, Linux)  
> **Інтерактивний портал:** [https://novus-life.online/docs](https://novus-life.online/docs)

---

## Ласкаво просимо до центру документації Novus Life

**Novus Life** — це високопродуктивний, орієнтований на приватність **Local-First Progressive Web Application (PWA)** для комплексного персонального та сімейного обліку:
- **Облік комунальних ресурсів та нерухомості:** 24 тарифні моделі, багатотарифні лічильники, соціальні квоти/пільги та оптичне розпізнавання показників (OCR).
- **Управління капіталом та зобов'язаннями:** мультивалютний грошовий потік, розрахунок пільгового періоду, адаптивне бюджетування «4 Конверти» та виявлення боргових пасток («Карусель»).
- **Змінні графіки та розрахунок зарплати:** конструктор ротацій (2/2, 3/3, 1/3, нічні години), коефіцієнти надурочних, табель та чистий розрахунок доходу.
- **Local-First та багатокористувацька синхронізація:** локальне сховище IndexedDB з можливістю наскрізного резервного копіювання до self-hosted PostgreSQL або Supabase з Row Level Security (RLS).
