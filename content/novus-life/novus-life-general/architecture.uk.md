# Архітектурний огляд: Novus Life

**Novus Life** — це приватна утиліта та платформа для керування домашніми витратами, що працює за принципом offline-first, спроєктована та підтримувана компанією **SGC-NOVUS** (System Generation Core). Вона поєднує клієнтську криптографічну ізоляцію з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює за **гібридною моделлю зберігання та пріоритету автономності (Hybrid Storage & Offline-First Model)**:
1. **Основний клієнтський шар (IndexedDB через Dexie.js)**:
   - Усі безпосередні взаємодії, введення показників лічильників, оцінки тарифів та перегляд історії виконуються безпосередньо з локальною IndexedDB.
   - Захищено від очищення кешу на рівні ОС за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% операційну спроможність в автономних середовищах (наприклад, підвалах, шахтах комунікацій, відключених мережах).
2. **Шар синхронізації сервера (Self-Hosted VPS)**:
   - Створено на базі **Node.js 22+ (Express + драйвер pg)** та **PostgreSQL 16**.
   - Доступно через суворо внутрішнє проксіювання за Nginx у межах домену `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних транзакціях SQL (`BEGIN ... COMMIT`), щоб запобігти станам часткової синхронізації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для впорядкованого за часом індексування без фрагментації сторінок B-Tree.
3. **Шар резервного копіювання (Google Drive `appDataFolder`)**:
   - Додаткова синхронізація зашифрованих архівів за допомогою прихованої папки Google Drive `appDataFolder` (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольовано від кореневих файлів користувача, що запобігає випадковому видаленню вручну.

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus Life відповідає всім критеріям WebAPK (дійсний маніфест, автономний режим відображення, масковані та стандартні іконки, зареєстрований service worker).
- Операційна система створює повноцінний пакет Android (`org.chromium.webapk.*`), що надає:
  - Ізольоване середовище sandbox Linux UID, відокремлене від процесів вкладок браузера.
  - Окремий запис програми в **Налаштування Android -> Додатки -> Novus Life**.
  - Перемикачі дозволів системного рівня (камера для фотофіксації лічильників, push-сповіщення для нагадувань про оплату).
  - Звітність про розподіл сховища (кеш IndexedDB точно відображається в налаштуваннях ОС).

### Десктоп (Windows, macOS, Linux)
- Працює в автономному віконному режимі з `window-controls-overlay` та синхронізацією системної теми.

### Apple iOS
- Працює через Safari Web App ("На екран «Додому»") у повноекранному автономному режимі з оптимізацією під сенсорне керування.

## 3. Data Flow & Cryptographic Boundaries

1. **Local Record Creation**:
   - Користувач вводить показники комунальних послуг (наприклад, електроенергія Т1/Т2, холодна вода, газ).
   - Різниця та суми показників розраховуються на льоту з використанням активного тарифного розкладу.
   - Запис зберігається в IndexedDB з унікальним локальним UUIDv7.
2. **Cryptographic Protection (Zero-Knowledge)**:
   - Конфіденційні дані передаються до `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Похідний майстер-ключ зберігається виключно в оперативній пам'яті клієнта під час виконання (PBKDF2 з 100 000 ітерацій).
   - До віддалених кінцевих точок надсилається лише зашифрований шифротекст.
3. **Synchronization**:
   - Служба синхронізації передає пакети записів через `/api/sync`, автентифіковані за допомогою стандартного JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки сутностей із каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Technology Matrix

| Layer | Technology | Role |
|---|---|---|
| **Runtime** | Node.js 26.x Active | Середовище виконання backend API |
| **Database** | PostgreSQL 18 (Docker) | Движок реляційної бази даних |
| **API Framework** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP API |
| **Primary Keys** | UUIDv7 (RFC 9562) | Впорядковані за мілісекундами ідентифікатори без колізій |
| **Frontend Framework** | Vue 3.5+ Composition API | Реактивний веб-інтерфейс |
| **State Management** | Pinia 3.x | Сховище стану клієнта та сесій |
| **Styling Engine** | Tailwind CSS v4 | Utility-first CSS система |
| **Local Database** | Dexie.js 4.x (IndexedDB) | Offline-first сховище даних клієнта |
| **Cryptographic Engine** | Web Crypto API | AES-256-GCM на стороні клієнта |
| **Reverse Proxy** | Nginx 1.24+ | Термінація SSL, зворотне проксіювання, кешування статики |

| **Екосистема** | SGC-NOVUS | Архітектурне володіння та життєвий цикл релізів |
