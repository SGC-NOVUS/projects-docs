# Огляд архітектури: Novus Life

**Novus Life** — це приватна утиліта з пріоритетом автономної роботи (offline-first) та платформа управління домашніми витратами, розроблена та підтримувана **SGC-NOVUS** (System Generation Core). Вона поєднує клієнтську криптографічну ізоляцію з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює за **Гібридною моделлю зберігання та пріоритету автономної роботи (Hybrid Storage & Offline-First Model)**:
1. **Основний клієнтський шар (IndexedDB через Dexie.js)**:
   - Усі безпосередні взаємодії, введення показників лічильників, оцінки тарифів та перегляд історії виконуються безпосередньо з локальною IndexedDB.
   - Захищено від очищення кешу на рівні ОС за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% операційну спроможність в автономних середовищах (наприклад, підвалах, комунікаційних шахтах, відключених мережах).
2. **Шар синхронізації сервера (Self-Hosted VPS)**:
   - Створено на базі **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступно через суворо внутрішнє проксіювання за Nginx у межах домену `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних SQL-транзакціях (`BEGIN ... COMMIT`) для запобігання частковим станам синхронізації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для впорядкованого за часом індексування без фрагментації сторінок B-Tree.
3. **Шар резервного копіювання (Google Drive `appDataFolder`)**:
   - Опціональна синхронізація зашифрованих архівів за допомогою прихованої папки `appDataFolder` на Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольовано від кореневих файлів користувача, що запобігає випадковому видаленню вручну.

```
+-------------------------------------------------------------------------+
|                              CLIENT DEVICE                              |
|                                                                         |

|  +--------------------+     +----------------------------------------+  |
|  |    Шар UI Vue 3    | <-> |       Web Crypto API (AES-256-GCM)     |  |
|  +--------------------+     +----------------------------------------+  |
|            |                                     |                      |
|  +--------------------+             +--------------------------+        |
|  | Dexie.js (IndexedDB|             |   Зашифрований пейлоад   |        |
|  |  Постійне сховище  |             +--------------------------+        |
|  +--------------------+                          |                      |
+------------|-------------------------------------|----------------------+
             | (HTTPS POST/GET /api/sync)          | (HTTPS OAuth2/appData)
             v                                     v
+-----------------------------+       +-----------------------------------+
|     NOVUS LIFE VPS API      |       |       GOOGLE DRIVE APPDATA        |
|  Node.js 26 + PostgreSQL 18 |       |  Прихований ізольований контейнер |
| Ключі UUIDv7 + Bcrypt / JWT |       |  novus_life_vault.json.enc        |
+-----------------------------+       +-----------------------------------+
```

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus Life відповідає всім критеріям WebAPK (дійсний маніфест, режим відображення standalone, масковані та стандартні іконки, зареєстрований service worker).
- Операційна система генерує повноцінний пакет Android (`org.chromium.webapk.*`), що надає:
  - Ізольовану пісочницю Linux UID, відокремлену від процесів вкладок браузера.
  - Окремий запис програми в **Android Settings -> Apps -> Novus Life**.
  - Перемикачі дозволів на системному рівні (Камера для фотофіксації показників лічильників, Push-сповіщення для нагадувань про оплату).
  - Звітність про використання сховища (кеш IndexedDB коректно відображається в налаштуваннях ОС).

### Desktop (Windows, macOS, Linux)
- Працює в автономному віконному режимі (standalone) з `window-controls-overlay` та синхронізацією із системною темою.

### Apple iOS
- Працює через Safari Web App ("Add to Home Screen") у повноекранному режимі standalone з оптимізацією під сенсорне керування.

## 3. Data Flow & Cryptographic Boundaries

1. **Створення локального запису**:
   - Користувач вводить показники лічильників (наприклад, електроенергія T1/T2, холодна вода, газ).
   - Різниця показників та суми обчислюються на льоту з використанням активної тарифної сітки.
   - Запис зберігається в IndexedDB з унікальним локальним UUIDv7.
2. **Криптографічний захист (Zero-Knowledge)**:
   - Конфіденційні корисні навантаження передаються до `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Похідний майстер-ключ зберігається виключно в пам'яті середовища виконання клієнта (PBKDF2 зі 100 000 ітерацій).
   - До віддалених кінцевих точок надсилається лише зашифрований шифротекст.
3. **Синхронізація**:
   - Служба синхронізації передає пакети записів через `/api/sync`, автентифіковані стандартним JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки сутностей із каскадним видаленням (`ON DELETE CASCADE`), прив’язаним до `user_id`.

## 4. Technology Matrix

| Рівень | Технологія | Роль |
|---|---|---|
| **Runtime** | Node.js 26.x Active | Середовище виконання бекенд-API |
| **База даних** | PostgreSQL 18 (Docker) | Рушій реляційної бази даних |
| **Фреймворк API** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP API |
| **Первинні ключі** | UUIDv7 (RFC 9562) | Впорядковані за мілісекундами ідентифікатори без колізій |
| **Фронтенд-фреймворк** | Vue 3.5+ Composition API | Реактивний вебінтерфейс |
| **Управління станом** | Pinia 3.x | Сховище стану клієнта та сесій |
| **Рушій стилів** | Tailwind CSS v4 | CSS-система за принципом utility-first |
| **Локальна база даних** | Dexie.js 4.x (IndexedDB) | Клієнтське сховище даних за принципом offline-first |
| **Криптографічний рушій** | Web Crypto API | Клієнтський AES-256-GCM |
| **Зворотний проксі** | Nginx 1.24+ | Термінація SSL, зворотне проксіювання, кешування статики |

| **Екосистема** | SGC-NOVUS | Архітектурне володіння та життєвий цикл релізів |
