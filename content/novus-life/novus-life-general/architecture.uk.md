# Огляд архітектури: Novus Life

**Novus Life** — це приватна платформа для управління комунальними та домашніми витратами за принципом offline-first, розроблена та підтримувана **SGC-NOVUS** (System Generation Core). Вона поєднує криптографічну ізоляцію на стороні клієнта з автономною серверною інфраструктурою.

---

## 1. Архітектура високого рівня

Система працює на основі **моделі гібридного збереження даних та Offline-First**:
1. **Основний клієнтський рівень (IndexedDB через Dexie.js)**:
   - Усі оперативні взаємодії, введення показників лічильників, розрахунок тарифів та перегляд історії виконуються безпосередньо в локальній IndexedDB.
   - Захищено від очищення кешу на рівні ОС за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% працездатність в автономних умовах (наприклад, у підвалах, комунікаційних шахтах, мережах без доступу до Інтернету).
2. **Рівень серверної синхронізації (Self-Hosted VPS)**:
   - Побудовано з використанням **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступ здійснюється суворо через внутрішнє проксіювання за Nginx під доменом `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних SQL-транзакціях (`BEGIN ... COMMIT`) для запобігання станам часткової синхронізації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для індексування з впорядкуванням за часовою міткою без фрагментації сторінок B-Tree.
3. **Рівень резервного копіювання (Google Drive `appDataFolder`)**:
   - Опціональна синхронізація зашифрованого архіву з використанням прихованої папки Google Drive `appDataFolder` (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольована від кореневих файлів користувача, що запобігає випадковому ручному видаленню.

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus Life відповідає всім критеріям WebAPK (дійсний маніфест, автономний режим відображення standalone, масковані та стандартні піктограми, зареєстрований service worker).
- Операційна система генерує повноцінний пакет Android (`org.chromium.webapk.*`), що забезпечує:
  - Ізольовану пісочницю Linux UID, відокремлену від процесів вкладок браузера.
  - Окремий запис програми в **Android Settings -> Apps -> Novus Life**.
  - Перемикачі дозволів системного рівня (Камера для фотофіксації показників лічильників, Push-сповіщення для нагадувань про оплату).
  - Звітність щодо виділення сховища (кеш IndexedDB коректно відображається в налаштуваннях ОС).

### Desktop (Windows, macOS, Linux)
- Працює в автономному віконному режимі з `window-controls-overlay` та синхронізацією із системною темою.

### Apple iOS
- Працює через Safari Web App ("Add to Home Screen") у повноекранному автономному режимі з оптимізацією для сенсорного керування.

## 3. Data Flow & Cryptographic Boundaries

1. **Local Record Creation**:
   - Користувач вводить показники комунальних послуг (наприклад, електроенергія T1/T2, холодна вода, газ).
   - Різниця показників та суми розраховуються на льоту з використанням чинного тарифного розкладу.
   - Запис зберігається в IndexedDB з унікальним локальним UUIDv7.
2. **Cryptographic Protection (Zero-Knowledge)**:
   - Конфіденційні корисні навантаження передаються до `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Отриманий майстер-ключ зберігається виключно в пам'яті середовища виконання клієнта (PBKDF2 зі 100 000 ітерацій).
   - На віддалені кінцеві точки передається лише зашифрований шифротекст.
3. **Synchronization**:
   - Сервіс синхронізації передає пакети записів через `/api/sync`, автентифіковані за допомогою стандартного JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки сутностей із каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Technology Matrix

| Layer | Technology | Role |
|---|---|---|
| **Runtime** | Node.js 26.x Active | Середовище виконання бекенд-API |
| **Database** | PostgreSQL 18 (Docker) | Рушій реляційної бази даних |
| **API Framework** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP API |
| **Primary Keys** | UUIDv7 (RFC 9562) | Впорядковані за мілісекундами ідентифікатори без колізій |
| **Frontend Framework** | Vue 3.5+ Composition API | Реактивний веб-інтерфейс |
| **State Management** | Pinia 3.x | Сховище стану клієнта та сесій |
| **Styling Engine** | Tailwind CSS v4 | Utility-first CSS-система |
| **Local Database** | Dexie.js 4.x (IndexedDB) | Offline-first клієнтське сховище даних |
| **Cryptographic Engine** | Web Crypto API | Клієнтська реалізація AES-256-GCM |
| **Reverse Proxy** | Nginx 1.24+ | Термінація SSL, зворотне проксіювання, кешування статики |

| **Екосистема** | SGC-NOVUS | Архітектурна власність та життєвий цикл релізів |
