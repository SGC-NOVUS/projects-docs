# Архітектурний огляд: Novus Life

**Novus Life** — це приватна утиліта режиму offline-first для керування побутовими витратами, розроблена та підтримувана компанією **SGC-NOVUS** (System Generation Core). Вона поєднує клієнтську криптографічну ізоляцію з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює на основі **моделі гібридного сховища та пріоритету автономності (Offline-First)**:
1. **Основний клієнтський шар (IndexedDB через Dexie.js)**:
   - Усі безпосередні взаємодії, введення показників лічильників, оцінки тарифів та перегляд історії виконуються безпосередньо в локальній IndexedDB.
   - Захищено від очищення кешу на рівні ОС за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% працездатність в автономних середовищах (наприклад, підвалах, шахтах комунікацій, відключених мережах).
2. **Шар серверної синхронизації (Self-Hosted VPS)**:
   - Створено на базі **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступно через суворо внутрішнє проксіювання за Nginx у домені `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних транзакціях SQL (`BEGIN ... COMMIT`) для запобігання частковим станам синхронізації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для індексування впорядкованого за часом без фрагментації сторінок B-Tree.
3. **Шар резервного копіювання (Google Drive `appDataFolder`)**:
   - Опціональна синхронізація зашифрованих архівів за допомогою прихованої папки `appDataFolder` на Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольовано від кореневих файлів користувача, що запобігає випадковому ручному видаленню.

```
+-------------------------------------------------------------------------+
|                              CLIENT DEVICE                              |
|                                                                         |

|  +--------------------+     +----------------------------------------+  |
|  |    Шар UI Vue 3    | <-> |       Web Crypto API (AES-256-GCM)     |  |
|  +--------------------+     +----------------------------------------+  |
|            |                                     |                      |
|  +--------------------+             +--------------------------+        |
|  | Dexie.js (IndexedDB|             | Зашифроване навантаження |        |
|  |  Постійне сховище  |             +--------------------------+        |
|  +--------------------+                          |                      |
+------------|-------------------------------------|----------------------+
             | (HTTPS POST/GET /api/sync)          | (HTTPS OAuth2/appData)
             v                                     v
+-----------------------------+       +-----------------------------------+
|     NOVUS LIFE VPS API      |       |       GOOGLE DRIVE APPDATA        |

|  Node.js 26 + PostgreSQL 18 |       |  Прихований ізольований контейнер   |
|  Ключі UUIDv7 + Bcrypt / JWT |       |  novus_life_vault.json.enc        |
+-----------------------------+       +-----------------------------------+
```

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus-Life відповідає всім критеріям WebAPK (дійсний маніфест, автономний режим відображення (standalone), масковані та стандартні іконки, зареєстрований service worker).
- Операційна система створює справжній пакет Android (`org.chromium.webapk.*`), що забезпечує:
  - Ізольовану пісочницю Linux UID, відмінну від процесів вкладки браузера.
  - Незалежний запис додатку в **Android Settings -> Apps -> Novus-Life**.
  - Перемикачі дозволів на системному рівні (Камера для зйомки фото лічильників, Push-повідомлення для нагадувань про оплату).
  - Звіт про виділення сховища (кеш IndexedDB коректно відображається в налаштуваннях ОС).

### Настільні ПК (Windows, macOS, Linux)
- Працює в автономному віконному режимі з `window-controls-overlay` та синхронізацією системної теми.

### Apple iOS
- Працює через Safari Web App («Додати на екран „Додому“») у повноноекранному автономному режимі з оптимізацією під сенсорне введення.

## 3. Потоки даних та криптографічні межі

1. **Створення локального запису**:
   - Користувач вводить показники лічильників (наприклад, електроенергія T1/T2, холодна вода, газ).
   - Різниці та суми показників обчислюються «на льоту» за допомогою активного тарифного розкладу.
   - Запис зберігається в IndexedDB з унікальним локальним UUIDv7.
2. **Криптографічний захист (Zero-Knowledge)**:
   - Конфіденційні корисні дані передаються до `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Похідний майстер-ключ зберігається виключно в пам'яті клієнтського середовища виконання (PBKDF2 з 100 000 ітерацій).
   - На віддалені ендпоінти надсилається лише зашифрований шифротекст.
3. **Синхронізація**:
   - Служба синхронізації передає пакети записів через `/api/sync`, автентифіковані за допомогою стандартного JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки сутності з каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Технологічна матриця

| Рівень | Технологія | Роль |
|---|---|---|
| **Середовище виконання** | Node.js 26.x Active | Середовище виконання бекенд-API |
| **База даних** | PostgreSQL 18 (Docker) | Рушій реляційної бази даних |
| **Фреймворк API** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP-API |
| **Первинні ключі** | UUIDv7 (RFC 9562) | Ідентифікатори з упорядкуванням за мілісекундами, без колізій |
| **Фреймворк інтерфейсу** | Vue 3.5+ Composition API | Реактивний веб-інтерфейс |
| **Керування станом** | Pinia 3.x | Сховище стану клієнта та сесії |
| **Рушій стилів** | Tailwind CSS v4 | CSS-система на основі утиліт |
| **Локальна база даних** | Dexie.js 4.x (IndexedDB) | Клієнтське сховище даних з пріоритетом офлайн-роботи |
| **Криптографічний рушій** | Web Crypto API | Клієнтський AES-256-GCM |
| **Зворотний проксі** | Nginx 1.24+ | SSL-термінація, зворотне проксіювання, статичне кешування |

| **Ecosystem** | SGC-NOVUS | Архітектурне володіння та життєвий цикл релізів |
