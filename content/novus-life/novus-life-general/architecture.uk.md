# Огляд архітектури: Novus Life

**Novus Life** — це приватна утиліта з підходом offline-first для керування побутовими витратами, розроблена та підтримувана компанією **SGC-NOVUS** (System Generation Core). Вона поєднує клієнтську криптографічну ізоляцію з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює за **моделлю гібридного сховища та пріоритету автономної роботи (Offline-First)**:
1. **Основний клієнтський шар (IndexedDB через Dexie.js)**:
   - Усі безпосередні взаємодії, введення показників лічильників, оцінки тарифів та перегляд історії виконуються безпосередньо проти локальної IndexedDB.
   - Захищено від очищення кешу на рівні ОС за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% операційну спроможність в автономних середовищах (наприклад, підвалах, шахтах комунікацій, відключених мережах).
2. **Шар серверної синхронізації (Self-Hosted VPS)**:
   - Створено на базі **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступно через суворо внутрішнє проксіювання за Nginx у домені `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних транзакціях SQL (`BEGIN ... COMMIT`), щоб запобігти станам часткової синхронізації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для індексації з упорядкуванням за часом без фрагментації сторінок B-Tree.
3. **Шар резервного копіювання (Google Drive `appDataFolder`)**:
   - Опціональна синхронізація зашифрованих архівів за допомогою прихованої папки `appDataFolder` у Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольовано від кореневих файлів користувача, що запобігає випадковому видаленню вручну.

```
+-------------------------------------------------------------------------+
|                              CLIENT DEVICE                              |
|                                                                         |

|  +--------------------+     +----------------------------------------+  |
|  |  Рівень UI Vue 3   | <-> |       Web Crypto API (AES-256-GCM)     |  |
|  +--------------------+     +----------------------------------------+  |
|            |                                     |                      |
|  +--------------------+             +--------------------------+        |
|  | Dexie.js (IndexedDB|             | Зашифроване навантаження |        |
|  |  Постійне сховище  |             +--------------------------+        |
|  +--------------------+                          |                      |
+------------|-------------------------------------|----------------------+
             | (HTTPS POST/GET /api/sync)          | (HTTPS OAuth2/appData)
             v                                     v
+-----------------------------+       +-----------------------------------+
|     NOVUS LIFE VPS API      |       |       GOOGLE DRIVE APPDATA        |
|  Node.js 26 + PostgreSQL 18 |       | Прихований ізольований контейнер  |
| Ключі UUIDv7 + Bcrypt / JWT |       |  novus_life_vault.json.enc        |
+-----------------------------+       +-----------------------------------+
```

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus Life відповідає всім критеріям WebAPK (дійсний маніфест, автономний режим відображення standalone, маскувальні та стандартні піктограми, зареєстрований service worker).
- Операційна система створює повноцінний пакет Android (`org.chromium.webapk.*`), що надає:
  - Ізольовану пісочницю Linux UID, окрему від процесів вкладок браузера.
  - Окремий запис програми в **Налаштування Android -> Програми -> Novus Life**.
  - Перемикачі дозволів системного рівня (Камера для фотофіксації лічильників, Push-сповіщення для нагадувань про оплату).
  - Звітність про розподіл сховища (кеш IndexedDB точно відображається в налаштуваннях ОС).

### Desktop (Windows, macOS, Linux)
- Працює в автономному віконному режимі з `window-controls-overlay` та синхронізацією із системною темою.

### Apple iOS
- Працює через Safari Web App («На початковий екран») у повноекранному автономному режимі з оптимізацією для сенсорного керування.

## 3. Data Flow & Cryptographic Boundaries

1. **Local Record Creation**:
   - Користувач вводить показники лічильників (наприклад, електроенергія T1/T2, холодна вода, газ).
   - Різниці та суми показників обчислюються "на льоту" з використанням активного тарифного розкладу.
   - Запис зберігається в IndexedDB з унікальним локальним ідентифікатором UUIDv7.
2. **Cryptographic Protection (Zero-Knowledge)**:
   - Конфіденційні корисні дані передаються до `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Похідний майстер-ключ зберігається виключно в пам'яті клієнтського середовища виконання (PBKDF2 з 100 000 ітерацій).
   - На віддалені кінцеві точки надсилається лише зашифрований шифротекст.
3. **Synchronization**:
   - Служба синхронізації передає пакети записів через `/api/sync`, автентифіковані за допомогою стандартного JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки сутністей із каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Technology Matrix

| Layer | Technology | Role |
|---|---|---|
| **Runtime** | Node.js 26.x Active | Середовище виконання бекенд-API |
| **Database** | PostgreSQL 18 (Docker) | Реляційна система управління базами даних |
| **API Framework** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP API |
| **Primary Keys** | UUIDv7 (RFC 9562) | Ідентифікатори без колізій, впорядковані за мілісекундами |
| **Frontend Framework** | Vue 3.5+ Composition API | Реактивний веб-інтерфейс |
| **State Management** | Pinia 3.x | Клієнтський стан та сховище сеансів |
| **Styling Engine** | Tailwind CSS v4 | CSS-система на основі утиліт |
| **Local Database** | Dexie.js 4.x (IndexedDB) | Клієнтське сховище даних з пріоритетом офлайн-режиму |
| **Cryptographic Engine** | Web Crypto API | Клієнтський AES-256-GCM |
| **Reverse Proxy** | Nginx 1.24+ | SSL-термінація, зворотне проксіювання, статичне кешування |

| **Екосистема** | SGC-NOVUS | Архітектурне володіння та життєвий цикл релізів |
