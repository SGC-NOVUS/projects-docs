# Architecture Overview: Novus Life

**Novus Life** — це приватна утиліта з пріоритетом автономної роботи (offline-first) та платформа для керування домашніми витратами, розроблена та підтримувана компанією **SGC-NOVUS** (System Generation Core). Вона поєднує клієнтську криптографічну ізоляцію з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює за **гібридною моделлю зберігання та пріоритету автономної роботи (Hybrid Storage & Offline-First Model)**:
1. **Первинний клієнтський шар (IndexedDB через Dexie.js)**:
   - Усі негайні взаємодії, введення показників лічильників, оцінки тарифів та перегляд історії виконуються безпосередньо в локальній IndexedDB.
   - Захищено від очищення кешу на рівні ОС за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% операційну спроможність в автономних середовищах (наприклад, підвалах, шахтах комунікацій, відключених мережах).
2. **Шар синхронізації сервера (Self-Hosted VPS)**:
   - Створено на базі **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступно через суворо внутрішнє проксіювання за Nginx у межах домену `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних SQL-транзакціях (`BEGIN ... COMMIT`), щоб запобігти станам часткової синхронизації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для індексування впорядкованого за часом без фрагментації сторінок B-Tree.
3. **Шар резервного копіювання (Google Drive `appDataFolder`)**:
   - Опціональна синхронізація зашифрованих архівів за допомогою прихованої папки Google Drive `appDataFolder` (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольовано від кореневих файлів користувача, що запобігає випадковому видаленню вручну.

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus Life відповідає всім критеріям WebAPK (дійсний маніфест, автономний режим відображення, масковані та стандартні іконки, зареєстрований service worker).
- Операційна система створює справжній пакет Android (`org.chromium.webapk.*`), що надає:
  - Ізольовану пісочницю Linux UID, окрему від процесів вкладок браузера.
  - Незалежний запис програми у **Налаштування Android -> Додатки -> Novus Life**.
  - Перемикачі дозволів на системному рівні (Камера для фотофіксації показників лічильників, Push-сповіщення для нагадувань про оплату).
  - Звітування про виділення сховища (кеш IndexedDB точно відображається в налаштуваннях ОС).

### Desktop (Windows, macOS, Linux)
- Працює в автономному віконному режимі з `window-controls-overlay` та синхронізацією з системною темою.

### Apple iOS
- Працює через Safari Web App («Додати на початковий екран») у повноекранному автономному режимі з оптимізацією під сенсорне керування.

## 3. Потоки даних та криптографічні межі

1. **Створення локальних записів**:
   - Користувач вводить показання лічильників (наприклад, електроенергія T1/T2, холодна вода, газ).
   - Різниця та суми показань розраховуються на льоту з використанням активної тарифної сітки.
   - Запис зберігається в IndexedDB з унікальним локальним UUIDv7.
2. **Криптографічний захист (Zero-Knowledge)**:
   - Чутливі корисні навантаження передаються в `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Похідний майстер-ключ зберігається виключно в оперативній пам'яті клієнта (PBKDF2 зі 100 000 ітерацій).
   - На віддалені кінцеві точки відправляється лише зашифрований шифротекст.
3. **Синхронізація**:
   - Служба синхронізації передає пакети записів через `/api/sync`, автентифіковані за допомогою стандартного JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки сутностей із каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Матриця технологій

| Рівень | Технологія | Роль |
|---|---|---|
| **Середовище виконання** | Node.js 26.x Active | Середовище виконання Backend API |
| **База даних** | PostgreSQL 18 (Docker) | Реляційний рушій бази даних |
| **API Framework** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP API |
| **Первинні ключі** | UUIDv7 (RFC 9562) | Ідентифікатори без колізій, упорядковані за мілісекундами |
| **Frontend Framework** | Vue 3.5+ Composition API | Реактивний вебінтерфейс |
| **Управління станом** | Pinia 3.x | Сховище стану клієнта та сесій |
| **Рушій стилізації** | Tailwind CSS v4 | CSS-система класу utility-first |
| **Локальна база даних** | Dexie.js 4.x (IndexedDB) | Клієнтське сховище даних offline-first |
| **Криптографічний рушій** | Web Crypto API | AES-256-GCM на стороні клієнта |
| **Зворотний проксі** | Nginx 1.24+ | Термінація SSL, зворотне проксіювання, кешування статики |

| **Екосистема** | SGC-NOVUS | Архітектурне володіння та життєвий цикл релізів |
