# Огляд архітектури: Novus Life

**Novus Life** — це приватна платформа з підтримкою автономної роботи (offline-first) для управління комунальними та побутовими витратами, розроблена та підтримувана **SGC-NOVUS** (System Generation Core). Вона поєднує криптографічну ізоляцію на стороні клієнта з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює на основі **моделі гібридного збереження даних та першочергової автономності (Offline-First)**:
1. **Основний клієнтський шар (IndexedDB через Dexie.js)**:
   - Усі миттєві взаємодії, введення показників лічильників, розрахунки тарифів та перегляд історії виконуються безпосередньо у локальній IndexedDB.
   - Захищений від очищення кешу на рівні операційної системи за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% працездатність в офлайн-середовищах (наприклад, підвали, технічні шахти, мережі без підключення до Інтернету).
2. **Серверний шар синхронізації (Self-Hosted VPS)**:
   - Побудований на **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступний виключно через внутрішнє проксіювання за Nginx за доменом `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних SQL-транзакціях (`BEGIN ... COMMIT`) для запобігання станам часткової синхронізації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для індексування з впорядкуванням за часовими мітками без фрагментації сторінок B-Tree.
3. **Шар резервного копіювання (Google Drive `appDataFolder`)**:
   - Опціональна синхронізація зашифрованих архівів з використанням прихованої папки `appDataFolder` в Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольований від кореневих файлів користувача, що запобігає випадковому ручному видаленню.

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus Life відповідає всім критеріям WebAPK (дійсний маніфест, автономний режим відображення standalone, масковані та стандартні іконки, зареєстрований service worker).
- Операційна система створює справжній пакет Android (`org.chromium.webapk.*`), що надає:
  - Ізольоване середовище (sandbox) Linux UID, відокремлене від процесів вкладок браузера.
  - Окремий пункт програми в **Налаштування Android -> Додатки -> Novus Life**.
  - Перемикачі дозволів системного рівня (Камера для фотофіксації показників лічильників, Push-сповіщення для нагадувань про оплату).
  - Звітність про виділене сховище (кеш IndexedDB точно відображається в налаштуваннях ОС).

### Desktop (Windows, macOS, Linux)
- Працює в автономному віконному режимі з `window-controls-overlay` та синхронізацією системної теми.

### Apple iOS
- Працює через веб-додаток Safari («На початковий екран») у повноекранному автономному режимі з оптимізацією під сенсорне керування.

## 3. Потік даних та криптографічні межі

1. **Створення локального запису**:
   - Користувач вводить показники комунальних послуг (наприклад, електроенергія T1/T2, холодна вода, газ).
   - Різниці та суми показників обчислюються «на льоту» з використанням активного тарифного розкладу.
   - Запис зберігається в IndexedDB з унікальним локальним UUIDv7.
2. **Криптографічний захист (Zero-Knowledge)**:
   - Чутливі корисні навантаження передаються в `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Сформований майстер-ключ зберігається виключно в оперативній пам'яті клієнта (PBKDF2 з 100 000 ітерацій).
   - На віддалені кінцеві точки надсилається лише зашифрований шифротекст.
3. **Синхронізація**:
   - Сервіс синхронізації передає пакетні записи через `/api/sync`, автентифіковані за допомогою стандартного JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки сутностей з каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Матриця технологій

| Рівень | Технологія | Роль |
|---|---|---|
| **Середовище виконання** | Node.js 26.x Active | Середовище виконання Backend API |
| **База даних** | PostgreSQL 18 (Docker) | Рушій реляційної бази даних |
| **Фреймворк API** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP API |
| **Первинні ключі** | UUIDv7 (RFC 9562) | Ідентифікатори, впорядковані за мілісекундами, без колізій |
| **Frontend-фреймворк** | Vue 3.5+ Composition API | Реактивний веб-інтерфейс |
| **Управління станом** | Pinia 3.x | Сховище стану клієнта та сесії |
| **Рушій стилізації** | Tailwind CSS v4 | Utility-first CSS-система |
| **Локальна база даних** | Dexie.js 4.x (IndexedDB) | Клієнтське сховище даних (offline-first) |
| **Криптографічний рушій** | Web Crypto API | Клієнтський AES-256-GCM |
| **Зворотний проксі** | Nginx 1.24+ | Термінація SSL, зворотне проксіювання, кешування статики |

| **Екосистема** | SGC-NOVUS | Архітектурне володіння та життєвий цикл релізів |
