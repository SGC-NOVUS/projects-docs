# Архітектурний огляд: Novus Life

**Novus Life** — це приватна утиліта режиму "offline-first" та платформа управління домашніми витратами, розроблена та підтримувана **SGC-NOVUS** (System Generation Core). Вона поєднує клієнтську криптографічну ізоляцію з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює за **Гібридною моделлю зберігання та Offline-First**:
1. **Первинний клієнтський шар (IndexedDB через Dexie.js)**:
   - Усі безпосередні взаємодії, введення показників лічильників, оцінки тарифів та перегляд історії виконуються безпосередньо проти локальної IndexedDB.
   - Захищено від очищення кешу на рівні ОС за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% операційну спроможність в автономних середовищах (наприклад, підвали, шахти комунікацій, відключені мережі).
2. **Шар серверної синхронізації (Self-Hosted VPS)**:
   - Створено на базі **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступно через суворо внутрішнє проксіювання за Nginx під доменом `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних транзакціях SQL (`BEGIN ... COMMIT`) для запобігання станам часткової синхронизації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для індексації за часовою міткою без фрагментації сторінок B-Tree.
3. **Шар резервного копіювання (Google Drive `appDataFolder`)**:
   - Опціональна синхронізація зашифрованих архівів за допомогою прихованої папки `appDataFolder` у Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольовано від кореневих файлів користувача, що запобігає випадковому ручному видаленню.

```
+-------------------------------------------------------------------------+
|                              CLIENT DEVICE                              |
|                                                                         |

|  +--------------------+     +----------------------------------------+  |
|  |   Рівень UI Vue 3  | <-> |       Web Crypto API (AES-256-GCM)     |  |
|  +--------------------+     +----------------------------------------+  |
|            |                                     |                      |
|  +--------------------+             +--------------------------+        |
|  | Dexie.js (IndexedDB|             |   Зашифрований пейлоад   |        |
|  |  Постійне сховище  |             +--------------------------+        |
|  +--------------------+                          |                      |
+------------|-------------------------------------|----------------------+
             | (HTTPS POST/GET /api/sync)          | (HTTPS OAuth2/appData)
             v                                     v
+-----------------------------+       +-----------------------------------+
|     NOVUS LIFE VPS API      |       |       GOOGLE DRIVE APPDATA        |
|  Node.js 26 + PostgreSQL 18 |       | Прихований ізольований контейнер  |
|  Ключі UUIDv7 + Bcrypt / JWT|       |  novus_life_vault.json.enc        |
+-----------------------------+       +-----------------------------------+
```

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus Life відповідає всім критеріям WebAPK (дійсний маніфест, режим відображення standalone, maskable та стандартні піктограми, зареєстрований service worker).
- Операційна система генерує справжній пакет Android (`org.chromium.webapk.*`), що надає:
  - Ізольовану пісочницю Linux UID, відокремлену від процесів вкладок браузера.
  - Окремий запис застосунку в **Налаштування Android -> Програми -> Novus Life**.
  - Перемикачі дозволів системного рівня (Камера для фотофіксації лічильників, Push-сповіщення для нагадувань про оплату).
  - Звітність про виділення сховища (кеш IndexedDB коректно відображається в налаштуваннях ОС).

### Desktop (Windows, macOS, Linux)
- Працює в окремому віконному режимі з `window-controls-overlay` та синхронізацією із системною темою.

### Apple iOS
- Працює через Safari Web App («Додати на початковий екран») у повноекранному режимі standalone з оптимізацією під сенсорне керування.

## 3. Data Flow & Cryptographic Boundaries

1. **Створення локального запису**:
   - Користувач вводить показники комунальних послуг (наприклад, електроенергія T1/T2, холодна вода, газ).
   - Різниця показників та суми розраховуються «на льоту» з використанням активної тарифної сітки.
   - Запис зберігається в IndexedDB з унікальним локальним UUIDv7.
2. **Криптографічний захист (Zero-Knowledge)**:
   - Конфіденційні корисні навантаження (payloads) передаються до `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Отриманий майстер-ключ зберігається виключно в оперативній пам'яті клієнта під час виконання (PBKDF2 зі 100 000 ітерацій).
   - До віддалених ендпоінтів надсилається лише зашифрований шифротекст.
3. **Синхронізація**:
   - Сервіс синхронізації передає пакети записів через `/api/sync`, автентифіковані за допомогою стандартного JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки сутностей із каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Technology Matrix

| Рівень | Технологія | Роль |
|---|---|---|
| **Runtime** | Node.js 26.x Active | Середовище виконання бекенд-API |
| **Database** | PostgreSQL 18 (Docker) | Рушій реляційної бази даних |
| **API Framework** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP API |
| **Primary Keys** | UUIDv7 (RFC 9562) | Впорядковані за мілісекундами безколізійні ідентифікатори |
| **Frontend Framework** | Vue 3.5+ Composition API | Реактивний веб-інтерфейс |
| **State Management** | Pinia 3.x | Сховище стану клієнта та сесій |
| **Styling Engine** | Tailwind CSS v4 | Utility-first CSS-система |
| **Local Database** | Dexie.js 4.x (IndexedDB) | Клієнтське сховище даних з концепцією offline-first |
| **Cryptographic Engine** | Web Crypto API | Клієнтський AES-256-GCM |
| **Reverse Proxy** | Nginx 1.24+ | Термінація SSL, зворотне проксі-серверування, кешування статики |

| **Екосистема** | SGC-NOVUS | Архітектурне володіння та життєвий цикл релізів |
