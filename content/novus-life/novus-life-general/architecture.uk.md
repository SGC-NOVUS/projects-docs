# Огляд архітектури: Novus Life

**Novus Life** — це приватна утиліта з підходом offline-first для керування побутовими витратами, розроблена та підтримувана компанією **SGC-NOVUS** (System Generation Core). Вона поєднує клієнтську криптографічну ізоляцію з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює за **гібридною моделлю зберігання та підходом Offline-First**:
1. **Первинний клієнтський шар (IndexedDB через Dexie.js)**:
   - Усі безпосередні взаємодії, введення показників лічильників, оцінки тарифів та перегляд історії виконуються безпосередньо проти локальної IndexedDB.
   - Захищено від очищення кешу на рівні ОС за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% операційну спроможність в автономних середовищах (наприклад, підвалах, шахтах комунікацій, відключених мережах).
2. **Шар серверної синхронізації (Self-Hosted VPS)**:
   - Створено на базі **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступно через суворо внутрішнє проксіювання за Nginx у межах домену `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних транзакціях SQL (`BEGIN ... COMMIT`), щоб запобігти станам часткової синхронізації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для індексації за часовою міткою без фрагментації сторінок B-Tree.
3. **Шар резервного копіювання (Google Drive `appDataFolder`)**:
   - Опціональна синхронізація зашифрованих архівів через приховану папку `appDataFolder` в Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольовано від кореневих файлів користувача, що запобігає випадковому ручному видаленню.

```
+-------------------------------------------------------------------------+
|                              CLIENT DEVICE                              |
|                                                                         |

|  +--------------------+     +----------------------------------------+  |
|  |   Рівень UI Vue 3  | <-> |       Web Crypto API (AES-256-GCM)     |  |
|  +--------------------+     +----------------------------------------+  |
|            |                                     |                      |
|  +--------------------+             +--------------------------+        |
|  | Dexie.js (IndexedDB|             | Зашифроване навантаження |        |
|  | Постійне сховище   |             +--------------------------+        |
|  +--------------------+                          |                      |
+------------|-------------------------------------|----------------------+
             | (HTTPS POST/GET /api/sync)          | (HTTPS OAuth2/appData)
             v                                     v
+-----------------------------+       +-----------------------------------+
|     NOVUS LIFE VPS API      |       |       GOOGLE DRIVE APPDATA        |
|  Node.js 26 + PostgreSQL 18 |       |  Прихований ізольований контейнер |
| Ключі UUIDv7 + Bcrypt / JWT |       |  novus_life_vault.json.enc        |
+-----------------------------+       +-----------------------------------+
```

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus-Life відповідає всім критеріям WebAPK (дійсний маніфест, автономний режим відображення, масковані та стандартні іконки, зареєстрований service worker).
- Операційна система створює справжній пакет Android (`org.chromium.webapk.*`), що забезпечує:
  - Ізольовану пісочницю Linux UID, відокремлену від процесів вкладок браузера.
  - Незалежний запис додатку в **Android Settings -> Apps -> Novus-Life**.
  - Перемикачі дозволів на рівні системи (камера для зйомки лічильників, push-повідомлення для нагадувань про оплату).
  - Звіт про виділення сховища (кеш IndexedDB коректно відображається в налаштуваннях ОС).

### Десктоп (Windows, macOS, Linux)
- Працює в режимі автономного вікна з `window-controls-overlay` та синхронізацією системної теми.

### Apple iOS
- Працює через Safari Web App («Додати на екран «Додому»») у повноноекранному автономному режимі з оптимізацією під сенсорне введення.

## 3. Data Flow & Cryptographic Boundaries

1. **Local Record Creation**:
   - Користувач вводить показники лічильників (наприклад, електроенергія Т1/Т2, холодна вода, газ).
   - Різниця показників та суми обчислюються на льоту з використанням активної тарифної сітки.
   - Запис зберігається в IndexedDB з унікальним локальним UUIDv7.
2. **Cryptographic Protection (Zero-Knowledge)**:
   - Чутливі корисні дані передаються до `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Отриманий майстер-ключ зберігається виключно в пам'яті середовища виконання клієнта (PBKDF2 зі 100 000 ітерацій).
   - До віддалених кінцевих точок надсилається лише зашифрований шифротекст.
3. **Synchronization**:
   - Сервіс синхронізації передає пакети записів через `/api/sync`, автентифіковані стандартним JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки сутностей із каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Technology Matrix

| Layer | Technology | Role |
|---|---|---|
| **Runtime** | Node.js 26.x Active | Середовище виконання бекенд-API |
| **Database** | PostgreSQL 18 (Docker) | Рушій реляційної бази даних |
| **API Framework** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP API |
| **Primary Keys** | UUIDv7 (RFC 9562) | Впорядковані за мілісекундами ідентифікатори без колізій |
| **Frontend Framework** | Vue 3.5+ Composition API | Реактивний веб-інтерфейс |
| **State Management** | Pinia 3.x | Сховище стану клієнта та сесій |
| **Styling Engine** | Tailwind CSS v4 | Utility-first CSS-система |
| **Local Database** | Dexie.js 4.x (IndexedDB) | Offline-first клієнтське сховище даних |
| **Cryptographic Engine** | Web Crypto API | Клієнтський AES-256-GCM |
| **Reverse Proxy** | Nginx 1.24+ | Термінація SSL, зворотне проксіювання, статичне кешування |

| **Ecosystem** | SGC-NOVUS | Архітектурне володіння та життєвий цикл релізів |
