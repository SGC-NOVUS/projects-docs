# Архітектурний огляд: Novus Life

**Novus Life** — це приватна утиліта режиму "offline-first" та платформа управління домашніми витратами, розроблена та підтримувана **SGC-NOVUS** (System Generation Core). Вона поєднує клієнтську криптографічну ізоляцію з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює за **Гібридною моделлю зберігання та Offline-First**:
1. **Первинний клієнтський шар (IndexedDB через Dexie.js)**:
   - Усі негайні взаємодії, введення показників лічильників, оцінки тарифів та перегляд історії виконуються безпосередньо в локальній IndexedDB.
   - Захищено від очищення кешу на рівні ОС за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% працездатність в офлайн-середовищах (наприклад, підвалах, шахтах комунікацій, відключених мережах).
2. **Шар серверної синхронізації (Self-Hosted VPS)**:
   - Створено на базі **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступно через суворо внутрішнє проксіювання за Nginx у межах домену `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних SQL-транзакціях (`BEGIN ... COMMIT`) для запобігання станам часткової синхронізації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для впорядкованого за часом індексування без фрагментації сторінок B-Tree.
3. **Шар резервного копіювання (Google Drive `appDataFolder`)**:
   - Опціональна синхронізація зашифрованих архівів за допомогою прихованої папки Google Drive `appDataFolder` (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольовано від кореневих файлів користувача, що запобігає випадковому ручному видаленню.

```

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus Life відповідає всім критеріям WebAPK (дійсний маніфест, автономний режим відображення standalone, масковані та стандартні іконки, зареєстрований service worker).
- Операційна система створює повноцінний пакет Android (`org.chromium.webapk.*`), що надає:
  - Ізольовану пісочницю Linux UID, відокремлену від процесів вкладок браузера.
  - Окремий запис програми в **Налаштування Android -> Додатки -> Novus Life**.
  - Перемикачі дозволів системного рівня (Камера для фотофіксації лічильників, Push-сповіщення для нагадувань про оплату).
  - Звітність про розподіл сховища (кеш IndexedDB точно відображається в налаштуваннях ОС).

### Desktop (Windows, macOS, Linux)
- Працює в автономному віконному режимі з `window-controls-overlay` та синхронізацією із системною темою.

### Apple iOS
- Працює через Safari Web App («На початковий екран») у повноекранному автономному режимі з оптимізацією для сенсорного керування.

## 3. Data Flow & Cryptographic Boundaries

1. **Створення локального запису**:
   - Користувач вводить показання лічильників (наприклад, електроенергія T1/T2, холодна вода, газ).
   - Різниця показань та суми розраховуються «на льоту» з використанням активного тарифного розкладу.
   - Запис зберігається в IndexedDB із унікальним локальним UUIDv7.
2. **Криптографічний захист (Zero-Knowledge)**:
   - Чутливі корисні дані передаються до `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Похідний майстер-ключ зберігається виключно в пам'яті середовища виконання клієнта (PBKDF2 із 100 000 ітерацій).
   - На віддалені кінцеві точки передається лише зашифрований шифротекст.
3. **Синхронізація**:
   - Сервіс синхронізації передає пакети записів через `/api/sync`, автентифіковані за допомогою стандартного JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки сутностей із каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Technology Matrix

| Рівень | Технологія | Роль |
|---|---|---|
| **Середовище виконання** | Node.js 26.x Active | Середовище виконання backend API |

| **Первинні ключі** | UUIDv7 (RFC 9562) | Ідентифікатори з мілісекундним впорядкуванням та без колізій |
