# Огляд архітектури: Novus Life

**Novus Life** — це приватна платформа з орієнтацією на локальну роботу (offline-first) для управління комунальними та побутовими витратами, розроблена та підтримувана **SGC-NOVUS** (System Generation Core). Вона поєднує криптографічну ізоляцію на стороні клієнта з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює на основі **моделі гібридного збереження даних та Offline-First**:
1. **Основний клієнтський шар (IndexedDB через Dexie.js)**:
   - Усі оперативні взаємодії, введення показників лічильників, розрахунки тарифів та перегляд історії виконуються безпосередньо в локальній IndexedDB.
   - Захищена від видалення кешу на рівні операційної системи за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% працездатність в офлайн-середовищах (наприклад, у підвалах, технічних шахтах, відключених мережах).
2. **Серверний шар синхронізації (Self-Hosted VPS)**:
   - Побудований на **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступний виключно через внутрішнє проксіювання за Nginx за доменом `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних SQL-транзакціях (`BEGIN ... COMMIT`), щоб запобігти частковим станам синхронізації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для індексування із сортуванням за часовою міткою без фрагментації сторінок B-Tree.
3. **Шар резервного копіювання (Google Drive `appDataFolder`)**:
   - Опціональна синхронізація зашифрованих архівів з використанням прихованої папки Google Drive `appDataFolder` (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольована від кореневих файлів користувача, що запобігає випадковому ручному видаленню.

```

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus Life відповідає всім критеріям WebAPK (дійсний маніфест, автономний режим відображення standalone, масковані та стандартні іконки, зареєстрований service worker).
- Операційна система створює повноцінний пакет Android (`org.chromium.webapk.*`), що надає:
  - Ізольовану пісочницю Linux UID, відокремлену від процесів вкладок браузера.
  - Окремий запис програми в **Налаштування Android -> Додатки -> Novus Life**.
  - Перемикачі дозволів на рівні системи (Камера для фотофіксації лічильників, Push-сповіщення для нагадувань про оплату).
  - Звітність про розподіл пам'яті (кеш IndexedDB точно відображається в налаштуваннях ОС).

### Десктоп (Windows, macOS, Linux)
- Працює в автономному віконному режимі з `window-controls-overlay` та синхронізацією із системною темою.

### Apple iOS
- Працює через веб-додаток Safari («На початковий екран») у повноекранному автономному режимі з оптимізацією під сенсорне керування.

## 3. Data Flow & Cryptographic Boundaries

1. **Створення локального запису**:
   - Користувач вводить показники комунальних послуг (наприклад, електроенергія T1/T2, холодна вода, газ).
   - Різниця та суми показників обчислюються «на льоту» з використанням активної тарифної сітки.
   - Запис зберігається в IndexedDB з унікальним локальним UUIDv7.
2. **Криптографічний захист (Zero-Knowledge)**:
   - Конфіденційні дані передаються до `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Похідний майстер-ключ зберігається виключно в пам'яті середовища виконання клієнта (PBKDF2 з 100 000 ітерацій).
   - На віддалені кінцеві точки надсилається лише зашифрований шифротекст.
3. **Синхронізація**:
   - Служба синхронізації передає пакети записів через `/api/sync`, автентифіковані за допомогою стандартного JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки сутностей із каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Technology Matrix

| Рівень | Технологія | Роль |
|---|---|---|
| **Середовище виконання** | Node.js 26.x Active | Середовище виконання API бекенду |
| **База даних** | PostgreSQL 18 (Docker) | Двигун реляційної бази даних |
| **Фреймворк API** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP API |
| **Первинні ключі** | UUIDv7 (RFC 9562) | Упорядковані за мілісекундами ідентифікатори без колізій |
| **Фронтенд-фреймворк** | Vue 3.5+ Composition API | Реактивний веб-інтерфейс |
| **Управління станом** | Pinia 3.x | Сховище стану клієнта та сесій |
| **Движок стилізації** | Tailwind CSS v4 | Utility-first CSS-система |
| **Локальна база даних** | Dexie.js 4.x (IndexedDB) | Клієнтське сховище даних з підтримкою offline-first |
| **Криптографічний движок** | Web Crypto API | Клієнтський AES-256-GCM |
| **Зворотний проксі** | Nginx 1.24+ | Термінація SSL, зворотне проксіювання, кешування статики |
