# Огляд архітектури: Novus Life

**Novus Life** — це приватна утиліта з підходом offline-first для керування хатніми витратами, розроблена та суτώвана компанією **SGC-NOVUS** (System Generation Core). Вона поєднує клієнтську криптографічну ізоляцію з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює за **гібридною моделлю зберігання та підходом offline-first**:
1. **Первинний клієнтський шар (IndexedDB через Dexie.js)**:
   - Усі безпосередні взаємодії, введення показників лічильників, оцінки тарифів та перегляд історії виконуються безпосередньо в локальній IndexedDB.
   - Захищено від видалення кешу на рівні ОС за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% операційну спроможність в автономних середовищах (наприклад, підвалах, шахтах комунікацій, відключених мережах).
2. **Шар серверної синхронізації (Self-Hosted VPS)**:
   - Створено на базі **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступно через суворо внутрішнє проксіювання за Nginx у межах домену `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних SQL-транзакціях (`BEGIN ... COMMIT`) для запобігання станам часткової синхронізації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для індексації з упорядкуванням за мітками часу без фрагментації сторінок B-Tree.
3. **Шар резервного копіювання (Google Drive `appDataFolder`)**:
   - Опціональна синхронізація зашифрованих архівів за допомогою прихованої папки `appDataFolder` в Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольовано від кореневих файлів користувача, що запобігає випадковому видаленню вручну.

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus-Life відповідає всім критеріям WebAPK (дійсний маніфест, автономний режим відображення, масковані та стандартні іконки, зареєстрований service worker).
- Операційна система створює справжній пакет Android (`org.chromium.webapk.*`), що забезпечує:
  - Ізольовану пісочницю Linux UID, відокремлену від процесів вкладки браузера.
  - Незалежний запис додатку в меню **Android Settings -> Apps -> Novus-Life**.
  - Системні перемикачі дозволів (Камера для зйомки фото лічильників, Push-повідомлення для нагадувань про оплату).
  - Звіт про виділення сховища (кеш IndexedDB коректно відображається в системних налаштуваннях).

### Десктоп (Windows, macOS, Linux)
- Працює в режимі автономного вікна з `window-controls-overlay` та синхронізацією системної теми.

### Apple iOS
- Працює через Safari Web App («Додати на екран “Додому”») у повноноекранному автономному режимі з оптимізацією під сенсорні екрани.

## 3. Потік даних та криптографічні межі

1. **Створення локального запису**:
   - Користувач вводить показники лічильників (наприклад, електроенергія T1/T2, холодна вода, газ).
   - Різниці та суми показників обчислюються "на льоту" за допомогою активного тарифного розкладу.
   - Запис зберігається в IndexedDB з унікальним локальним UUIDv7.
2. **Криптографічний захист (Zero-Knowledge)**:
   - Конфіденційні корисні дані передаються до `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Похідний головний ключ зберігається виключно в пам'яті клієнтського середовища виконання (PBKDF2 з 100 000 ітерацій).
   - На віддалені кінцеві точки надсилається лише зашифрований шифротекст.
3. **Синхронізація**:
   - Служба синхронізації передає пакети записів через `/api/sync`, автентифіковані за допомогою стандартного JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки сутнісних об'єктів із каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Технологічна матриця

| Рівень | Технологія | Роль |
|---|---|---|
| **Runtime** | Node.js 26.x Active | Середовище виконання бекенд API |
| **Database** | PostgreSQL 18 (Docker) | Рушій реляційної бази даних |
| **API Framework** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP API |
| **Primary Keys** | UUIDv7 (RFC 9562) | Ідентифікатори без колізій, впорядковані за мілісекундами |
| **Frontend Framework** | Vue 3.5+ Composition API | Реактивний веб-інтерфейс |
| **State Management** | Pinia 3.x | Сховище стану клієнта та сесії |
| **Styling Engine** | Tailwind CSS v4 | CSS-система на основі утиліт |
| **Local Database** | Dexie.js 4.x (IndexedDB) | Клієнтське сховище даних з пріоритетом офлайн-роботи |
| **Cryptographic Engine** | Web Crypto API | Клієнтський AES-256-GCM |
| **Reverse Proxy** | Nginx 1.24+ | SSL-термінація, зворотне проксіювання, статичне кешування |

| **Ecosystem** | SGC-NOVUS | Архітектурне володіння та життєвий цикл релізів |
