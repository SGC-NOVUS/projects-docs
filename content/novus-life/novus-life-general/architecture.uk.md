# Архітектурний огляд: Novus Life

**Novus Life** — це приватна утиліта з пріоритетом офлайн-роботи (offline-first) та платформа для керування домашніми витратами, розроблена та підтримувана **SGC-NOVUS** (System Generation Core). Вона поєднує клієнтську криптографічну ізоляцію з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює за **гібридною моделлю зберігання та пріоритету офлайн-роботи (Hybrid Storage & Offline-First Model)**:
1. **Первинний клієнтський шар (IndexedDB через Dexie.js)**:
   - Усі безпосередні взаємодії, введення показників лічильників, оцінки тарифів та перегляд історії виконуються безпосередньо проти локальної IndexedDB.
   - Захищено від очищення кешу на рівні ОС за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% операційну спроможність в офлайн-середовищах (наприклад, підвалах, шахтах комунікацій, відключених мережах).
2. **Серверний шар синхронизації (Self-Hosted VPS)**:
   - Створено на базі **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступно через суворо внутрішнє проксіювання за Nginx у домені `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних транзакціях SQL (`BEGIN ... COMMIT`) для запобігання станам часткової синхронізації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для впорядкованого за часом індексування без фрагментації сторінок B-Tree.
3. **Шар резервного копіювання (Google Drive `appDataFolder`)**:
   - Опціональна синхронізація зашифрованих архівів за допомогою прихованої папки `appDataFolder` у Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольовано від кореневих файлів користувача, що запобігає випадковому видаленню вручну.

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus-Life відповідає всім критеріям WebAPK (дійсний маніфест, автономний режим відображення, масковані та стандартні іконки, зареєстрований service worker).
- Операційна система створює справжній Android-пакет (`org.chromium.webapk.*`), що забезпечує:
  - Ізольовану пісочницю Linux UID, відмінну від процесів вкладок браузера.
  - Незалежний запис додатку в меню **Android Settings -> Apps -> Novus-Life**.
  - Перемикачі дозволів на рівні системи (Камера для зйомки фото лічильників, Push-повідомлення для нагадувань про оплату).
  - Звітність про виділення сховища (кеш IndexedDB коректно відображається в налаштуваннях ОС).

### Десктоп (Windows, macOS, Linux)
- Працює в режимі автономного вікна з `window-controls-overlay` та синхронізацією системної теми.

### Apple iOS
- Працює через Safari Web App («Додати на екран „Початковий екрана“») у повноноекранному автономному режимі з оптимізацією під сенсорне введення.

## 3. Потік даних та криптографічні межі

1. **Створення локального запису**:
   - Користувач вводить показники лічильників (наприклад, електроенергія T1/T2, холодна вода, газ).
   - Різниці та суми показників обчислюються "на льоту" за допомогою активного тарифного розкладу.
   - Запис зберігається в IndexedDB з унікальним локальним UUIDv7.
2. **Криптографічний захист (Zero-Knowledge)**:
   - Чутливі корисні дані (payloads) передаються до `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Похідний майстер-ключ зберігається виключно в пам'яті клієнтського середовища виконання (PBKDF2 з 100 000 ітерацій).
   - На віддалені кінцеві точки (endpoints) надсилається лише зашифрований шифротекст.
3. **Синхронізація**:
   - Служба синхронізації передає пакетні записи через `/api/sync`, автентифіковані за допомогою стандартного JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки суткістей з каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Технологічна матриця

| Рівень | Технологія | Роль |
|---|---|---|
| **Середовище виконання** | Node.js 26.x Active | Середовище виконання бекенд-API |
| **База даних** | PostgreSQL 18 (Docker) | Рушій реляційної бази даних |
| **API-фреймворк** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP-API |
| **Первинні ключі** | UUIDv7 (RFC 9562) | Ідентифікатори без колізій, впорядковані за мілісекундами |

| **Керування станом** | Pinia 3.x | Клієнтський стан та сховище сесій |
| **Рушій стилів** | Tailwind CSS v4 | CSS-система на основі утиліт |

| **Криптографічний рушій** | Web Crypto API | Клієнтський AES-256-GCM |
