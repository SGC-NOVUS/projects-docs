# Архітектурний огляд: Novus Life

**Novus Life** — це приватна утиліта режиму "offline-first" та платформа управління домашніми витратами, розроблена та підтримувана **SGC-NOVUS** (System Generation Core). Вона поєднує клієнтську криптографічну ізоляцію з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює на основі **Гібридної моделі зберігання та режиму Offline-First**:
1. **Основний клієнтський шар (IndexedDB через Dexie.js)**:
   - Усі безпосередні взаємодії, введення показників лічильників, оцінки тарифів та перегляд історії виконуються безпосередньо в локальній IndexedDB.
   - Захищено від очищення кешу на рівні ОС за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% оперативну працездатність в автономних середовищах (наприклад, підвалах, комунікаційних шахтах, відключених мережах).
2. **Шар серверної синхронізації (Self-Hosted VPS)**:
   - Створено на базі **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступно через суворо внутрішнє проксіювання за Nginx у домені `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних транзакціях SQL (`BEGIN ... COMMIT`), щоб запобігти станам часткової синхронізації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для індексування з упорядкуванням за часом без фрагментації сторінок B-Tree.
3. **Шар резервного копіювання (Google Drive `appDataFolder`)**:
   - Необов'язкова синхронізація зашифрованих архівів із використанням прихованої папки `appDataFolder` в Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольовано від кореневих файлів користувача, що запобігає випадковому видаленню вручну.

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus Life відповідає всім критеріям WebAPK (дійсний маніфест, автономний режим відображення standalone, масковані та стандартні іконки, зареєстрований service worker).
- Операційна система генерує справжній пакет Android (`org.chromium.webapk.*`), що надає:
  - Ізольовану пісочницю Linux UID, відокремлену від процесів вкладок браузера.
  - Окремий запис програми в **Налаштування Android -> Додатки -> Novus Life**.
  - Перемикачі дозволів системного рівня (камера для фотофіксації лічильників, push-сповіщення для нагадувань про оплату).
  - Звітність про розподіл сховища (кеш IndexedDB точно відображається в налаштуваннях ОС).

### Desktop (Windows, macOS, Linux)
- Працює в автономному віконному режимі з `window-controls-overlay` та синхронізацією із системною темою.

### Apple iOS
- Працює через вебдодаток Safari ("На початковий екран") у повноекранному автономному режимі з оптимізацією для сенсорного керування.

## 3. Потік даних та криптографічні межі

1. **Створення локального запису**:
   - Користувач вводить показники комунальних послуг (наприклад, електроенергія T1/T2, холодна вода, газ).
   - Різниця та суми показників розраховуються на льоту з використанням активної сітки тарифів.
   - Запис зберігається в IndexedDB з унікальним локальним UUIDv7.
2. **Криптографічний захист (Zero-Knowledge)**:
   - Чутливі дані передаються в `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Похідний майстер-ключ зберігається виключно в оперативній пам'яті клієнта (PBKDF2 з 100 000 ітерацій).
   - На віддалені кінцеві точки надсилається лише зашифрований шифротекст.
3. **Синхронізація**:
   - Служба синхронізації передає пакети записів через `/api/sync`, автентифіковані за допомогою стандартного JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки сутностей із каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Матриця технологій

| Рівень | Технологія | Роль |
|---|---|---|
| **Середовище виконання** | Node.js 26.x Active | Середовище виконання API бекенду |
| **База даних** | PostgreSQL 18 (Docker) | Рушій реляційної бази даних |
| **Фреймворк API** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP API |
| **Первинні ключі** | UUIDv7 (RFC 9562) | Ідентифікатори, впорядковані за мілісекундами, без колізій |
| **Фреймворк фронтенду** | Vue 3.5+ Composition API | Реактивний веб-інтерфейс |
| **Управління станом** | Pinia 3.x | Сховище стану клієнта та сесій |
| **Рушій стилів** | Tailwind CSS v4 | Utility-first CSS-система |
| **Локальна база даних** | Dexie.js 4.x (IndexedDB) | Клієнтське сховище даних (offline-first) |
| **Криптографічний рушій** | Web Crypto API | AES-256-GCM на стороні клієнта |
| **Зворотний проксі** | Nginx 1.24+ | Термінація SSL, зворотне проксіювання, кешування статики |

| **Екосистема** | SGC-NOVUS | Архітектурне володіння та життєвий цикл релізів |
