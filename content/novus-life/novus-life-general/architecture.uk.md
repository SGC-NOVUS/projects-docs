# Архітектурний огляд: Novus Life

**Novus Life** — це приватна утиліта режиму "offline-first" та платформа управління домашніми витратами, розроблена та підтримувана **SGC-NOVUS** (System Generation Core). Вона поєднує клієнтську криптографічну ізоляцію з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює за **Гібридною моделлю зберігання та підходом Offline-First**:
1. **Первинний клієнтський шар (IndexedDB через Dexie.js)**:
   - Усі безпосередні взаємодії, введення показників лічильників, оцінки тарифів та перегляд історії виконуються безпосередньо в локальній IndexedDB.
   - Захищено від очищення кешу на рівні ОС за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% операційну спроможність в автономних середовищах (наприклад, підвалах, шахтах комунікацій, відключених мережах).
2. **Шар серверної синхронізації (Self-Hosted VPS)**:
   - Створено на базі **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступно через суворо внутрішнє проксіювання за Nginx у межах домену `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних транзакціях SQL (`BEGIN ... COMMIT`) для запобігання станам часткової синхронізації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для впорядкованого за міткою часу індексування без фрагментації сторінок B-Tree.
3. **Шар резервного копіювання (Google Drive `appDataFolder`)**:
   - Опціональна синхронізація зашифрованих архівов за допомогою прихованої папки `appDataFolder` в Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольовано від кореневих файлів користувача, що запобігає випадковому ручному видаленню.

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus Life відповідає всім критеріям WebAPK (валідний маніфест, режим відображення standalone, maskable- та стандартні іконки, зареєстрований service worker).
- Операційна система генерує повноцінний Android-пакет (`org.chromium.webapk.*`), що надає:
  - Ізольовану пісочницю Linux UID, відокремлену від процесів вкладок браузера.
  - Незалежний запис програми в **Налаштування Android -> Програми -> Novus Life**.
  - Перемикачі дозволів системного рівня (Камера для фотофіксації показників лічильників, Push-сповіщення для нагадувань про оплату).
  - Звітність про розподіл сховища (кеш IndexedDB коректно передається в налаштування ОС).

### Desktop (Windows, macOS, Linux)
- Працює в автономному віконному режимі з `window-controls-overlay` та синхронізацією із системною темою.

### Apple iOS
- Працює через Safari Web App («На початковий екран») у повноекранному режимі standalone з оптимізацією під сенсорне керування.

## 3. Потік даних та криптографічні межі

1. **Створення локального запису**:
   - Користувач вводить показання лічильників (наприклад, електроенергія T1/T2, холодна вода, газ).
   - Різниця та суми показань розраховуються «на льоту» з використанням активного розкладу тарифів.
   - Запис зберігається в IndexedDB із унікальним локальним UUIDv7.
2. **Криптографічний захист (Zero-Knowledge)**:
   - Конфіденційні дані передаються в `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Отриманий майстер-ключ зберігається виключно в оперативній пам'яті клієнта (PBKDF2 з 100 000 ітерацій).
   - На віддалені кінцеві точки передається лише зашифрований шифротекст.
3. **Синхронізація**:
   - Служба синхронізації передає пакети записів через `/api/sync`, автентифіковані за допомогою стандартного JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки сутностей з каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Матриця технологій

| Рівень | Технологія | Роль |
|---|---|---|
| **Середовище виконання** | Node.js 26.x Active | Середовище виконання Backend API |
| **База даних** | PostgreSQL 18 (Docker) | Реляційний рушій бази даних |
| **Фреймворк API** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP API |
| **Первинні ключі** | UUIDv7 (RFC 9562) | Ідентифікатори, впорядковані за мілісекундами, без колізій |
| **Frontend-фреймворк** | Vue 3.5+ Composition API | Реактивний веб-інтерфейс |
| **Управління станом** | Pinia 3.x | Сховище стану клієнта та сесій |
| **Рушій стилів** | Tailwind CSS v4 | Utility-first CSS-система |
| **Локальна база даних** | Dexie.js 4.x (IndexedDB) | Клієнтське сховище даних з підтримкою offline-first |
| **Криптографічний рушій** | Web Crypto API | AES-256-GCM на стороні клієнта |
| **Зворотний проксі** | Nginx 1.24+ | Термінація SSL, зворотне проксіювання, кешування статики |

| **Екосистема** | SGC-NOVUS | Архітектурна власність та життєвий цикл релізів |
