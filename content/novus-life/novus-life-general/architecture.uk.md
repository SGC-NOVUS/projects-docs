# Огляд архітектури: Novus Life

**Novus Life** — це приватна утиліта з підходом offline-first для керування побутовими витратами, розроблена та підтримувана компанією **SGC-NOVUS** (System Generation Core). Вона поєднує клієнтську криптографічну ізоляцію з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює за **гібридною моделлю зберігання та підходом Offline-First**:
1. **Первинний клієнтський шар (IndexedDB через Dexie.js)**:
   - Усі безпосередні взаємодії, введення показників лічильників, оцінки тарифів та перегляд історії виконуються безпосередньо в локальній IndexedDB.
   - Захищено від очищення кешу на рівні ОС за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% оперативну спроможність в офлайн-середовищах (наприклад, підвалах, шахтах комунікацій, відключених мережах).
2. **Шар синхронізації сервера (Self-Hosted VPS)**:
   - Створено на базі **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступно через суворо внутрішнє проксіювання за Nginx у межах домену `https://novus-life.online/api/*`.
   - Дані фіксуються в атомарних SQL-транзакціях (`BEGIN ... COMMIT`) для запобігання станам часткової синхронізації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для індексації за часовою міткою без фрагментації сторінок B-Tree.
3. **Шар резервного копіювання (Google Drive `appDataFolder`)**:
   - Опціональна синхронізація зашифрованих архівів за допомогою прихованої папки Google Drive `appDataFolder` (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольовано від кореневих файлів користувача, що запобігає випадковому видаленню вручну.

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus Life відповідає всім критеріям WebAPK (дійсний маніфест, режим відображення standalone, масковані та стандартні іконки, зареєстрований service worker).
- Операційна система створює повноцінний пакет Android (`org.chromium.webapk.*`), який надає:
  - Ізольовану пісочницю Linux UID, окрему від процесів вкладок браузера.
  - Окремий запис програми в **Налаштування Android -> Програми -> Novus Life**.
  - Перемикачі дозволів на системному рівні (Камера для фотофіксації лічильників, Push-сповіщення для нагадувань про оплату).
  - Звітність про розподіл сховища (кеш IndexedDB точно відображається в налаштуваннях ОС).

### Desktop (Windows, macOS, Linux)
- Працює в автономному віконному режимі з `window-controls-overlay` та синхронізацією з системною темою.

### Apple iOS
- Працює через Safari Web App («На початковий екран») у повноекранному режимі standalone з оптимізацією під сенсорне керування.

## 3. Потік даних та криптографічні межі

1. **Створення локального запису**:
   - Користувач вводить показники лічильників (наприклад, електроенергія T1/T2, холодна вода, газ).
   - Різниці та суми показників обчислюються "на льоту" за допомогою активного розкладу тарифів.
   - Запис зберігається в IndexedDB з унікальним локальним UUIDv7.
2. **Криптографічний захист (Zero-Knowledge)**:
   - Конфіденційні дані передаються до `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Похідний майстер-ключ зберігається виключно в пам'яті клієнтського середовища виконання (PBKDF2 з 100 000 ітерацій).
   - На віддалені кінцеві точки надсилається лише зашифрований шифротекст.
3. **Синхронізація**:
   - Служба синхронізації передає пакети записів через `/api/sync`, автентифіковані за допомогою стандартного JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки суностей з каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Технологічна матриця

| Рівень | Технологія | Роль |
|---|---|---|
| **Середовище виконання** | Node.js 26.x Active | Середовище виконання бекенд API |
| **База даних** | PostgreSQL 18 (Docker) | Реляційна система управління базами даних |
| **Фреймворк API** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP API |
| **Первинні ключі** | UUIDv7 (RFC 9562) | Ідентифікатори з упорядкуванням за мілісекундами та захистом від колізій |
| **Фреймворк фронтенду** | Vue 3.5+ Composition API | Реактивний веб-інтерфейс |
| **Керування станом** | Pinia 3.x | Сховище стану клієнта та сесії |
| **Рушій стилізації** | Tailwind CSS v4 | CSS-система на основі утиліт |
| **Локальна база даних** | Dexie.js 4.x (IndexedDB) | Клієнтське сховище даних з пріоритетом офлайн-роботи |
| **Криптографічний рушій** | Web Crypto API | Клієнтський AES-256-GCM |
| **Зворотний проксі** | Nginx 1.24+ | SSL-термінація, зворотне проксіювання, статичне кешування |

| **Ecosystem** | SGC-NOVUS | Архітектурне володіння та життєвий цикл релізів |
