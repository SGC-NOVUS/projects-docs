# Огляд архітектури: Novus Life

**Novus Life** — це приватна платформа для управління комунальними послугами та домашніми витратами, що працює за принципом offline-first, розроблена та підтримувана **SGC-NOVUS** (System Generation Core). Вона поєднує криптографічну ізоляцію на стороні клієнта з автономною серверною інфраструктурою.

---

## 1. Високорівнева архітектура

Система працює на основі **гібридної моделі зберігання та принципу offline-first**:
1. **Основний клієнтський рівень (IndexedDB через Dexie.js)**:
   - Усі безпосередні взаємодії, введення показань лічильників, розрахунок тарифів та перегляд історії виконуються безпосередньо в локальній IndexedDB.
   - Захищено від витіснення кешу на рівні ОС за допомогою **Persistent Storage API** (`navigator.storage.persist()`).
   - Забезпечує 100% працездатність в офлайн-середовищах (наприклад, підвалах, комунікаційних шахтах, відключених мережах).
2. **Серверний рівень синхронізації (Self-Hosted VPS)**:
   - Побудований на базі **Node.js 22+ (Express + pg driver)** та **PostgreSQL 16**.
   - Доступний через суворо внутрішнє проксіювання за Nginx під доменом `https://novus-life.online/api/*`.
   - Дані записуються в атомарних SQL-транзакціях (`BEGIN ... COMMIT`) для запобігання станам часткової синхронізації.
   - Усі реляційні сутності використовують первинні ключі **UUIDv7** (RFC 9562) для індексації, впорядкованої за часовою міткою, без фрагментації сторінок B-Tree.
3. **Рівень резервного копіювання (Google Drive `appDataFolder`)**:
   - Опціональна синхронізація зашифрованих архівів за допомогою прихованої папки Google Drive `appDataFolder` (`https://www.googleapis.com/auth/drive.appdata`).
   - Ізольовано від кореневих файлів користувача, що запобігає випадковому ручному видаленню.

## 2. Життєвий цикл PWA та WebAPK

### Android (WebAPK)
- На сучасних пристроях Android (Chrome, Edge, Samsung Internet) Novus Life відповідає всім критеріям WebAPK (дійсний маніфест, автономний режим відображення standalone, масковані та стандартні іконки, зареєстрований service worker).
- Операційна система генерує справжній пакет Android (`org.chromium.webapk.*`), що надає:
  - Ізольовану пісочницю Linux UID, окрему від процесів вкладок браузера.
  - Незалежний запис програми у **Налаштування Android -> Додатки -> Novus Life**.
  - Перемикачі дозволів на системному рівні (Камера для фотофіксації показань лічильників, Push-сповіщення для нагадувань про оплату).
  - Звітність про виділення пам'яті (кеш IndexedDB точно відображається в налаштуваннях ОС).

### Десктоп (Windows, macOS, Linux)
- Працює в автономному віконному режимі з `window-controls-overlay` та синхронізацією системної теми.

### Apple iOS
- Запускається через Safari Web App («Додати на початковий екран») у повноекранному автономному режимі з оптимізацією під сенсорне керування.

## 3. Потік даних та криптографічні межі

1. **Створення локального запису**:
   - Користувач вводить показники лічильників (наприклад, електроенергія T1/T2, холодна вода, газ).
   - Різниці та суми показників обчислюються "на льоту" за допомогою активного розкладу тарифів.
   - Запис зберігається в IndexedDB з унікальним локальним UUIDv7.
2. **Криптографічний захист (Zero-Knowledge)**:
   - Конфіденційні дані передаються до `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Похідний майстер-ключ зберігається виключно в оперативній пам'яті кліентського середовища виконання (PBKDF2 з 100 000 ітерацій).
   - На віддалені ендпоінти надсилається лише зашифрований ciphertext.
3. **Синхронізація**:
   - Служба синхронізації передає пакети записів через `/api/sync`, автентифіковані стандартним JSON Web Token (JWT).
   - База даних PostgreSQL зберігає рядки суткістей із каскадним видаленням (`ON DELETE CASCADE`), прив'язаним до `user_id`.

## 4. Технологічна матриця

| Рівень | Технологія | Роль |
|---|---|---|
| **Середовище виконання** | Node.js 26.x Active | Середовище виконання бекенд-API |
| **База даних** | PostgreSQL 18 (Docker) | Рушій реляційної бази даних |
| **API-фреймворк** | Express 5.0.x+ / TypeScript | Маршрутизація та валідація HTTP API |
| **Первинні ключі** | UUIDv7 (RFC 9562) | Ідентифікатори, впорядковані за мілісекундами, без колізій |
| **Фронтенд-фреймворк** | Vue 3.5+ Composition API | Реактивний веб-інтерфейс |
| **Керування станом** | Pinia 3.x | Сховище стану клієнта та сесії |
| **Рушій стилів** | Tailwind CSS v4 | CSS-система на основі утиліт |
| **Локальна база даних** | Dexie.js 4.x (IndexedDB) | Клієнтське сховище даних з пріоритетом офлайн-роботи |
| **Криптографічний рушій** | Web Crypto API | Клієнтський AES-256-GCM |
| **Зворотний проксі-сервер** | Nginx 1.24+ | SSL-термінація, зворотне проксіювання, статичне кешування |

| **Ecosystem** | SGC-NOVUS | Архітектурне володіння та життєвий цикл релізів |
