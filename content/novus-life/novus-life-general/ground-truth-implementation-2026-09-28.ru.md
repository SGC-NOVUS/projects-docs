# Фактическое состояние: реализация Novus Life

**Статус:** внутренний статический аудит checkout от 28.09.2026.
**Область анализа:** маршруты Vue/PWA, бэкенд Express, PostgreSQL, интеграции Google, электронная почта, хранилище браузера и конфигурация окружения.

## Текущая архитектура

Репозиторий не является React-шаблоном, описанным в корневом файле README. Отслеживаемая реализация:

| Уровень | Фактическая реализация |
| --- | --- |
| Браузер | Vue 3, Vite, Vue Router, Pinia, i18n и ресурсы PWA |
| Локальные данные клиента | Службы хранилища браузера / возможностей устройства и доменные хранилища для адресов, услуг, тарифов, показаний счетчиков, платежей и напоминаний |
| API | Express на `0.0.0.0`, `PORT` по умолчанию `3001`; CORS origin задан как `*`; размер тела запроса JSON/urlencoded ограничен 15 MiB |
| Хранение данных | PostgreSQL через пул `pg`; сервер отказывается от прослушивания портов после 10 неудачных попыток подключения с интервалом в 2 секунды |
| Идентификация | JWT по email/паролю плюс Google OAuth; время жизни bearer JWT составляет 60 дней |
| Облачный бэкап | Google Drive `appDataFolder`, получающий непрозрачные зашифрованные данные от клиента |
| Почта | Resend; при отсутствии API-ключа отправка почты переключается на логгирующую заглушку (mock), возвращающую успешный результат |

## Навигация в браузере и модули

| Область маршрута | Реализованные модули |
| --- | --- |
| Публичная | Лендинг, конфиденциальность, условия использования, о нас, аутентификация |
| `/app` | Дашборд, профиль, коммунальные услуги, тарифы, адреса, сервисы, платежи, напоминания, аналитика, настройки |
| Совместимость | Устаревшие короткие URL перенаправляются на `/app/*`; неизвестные пути перенаправляются на `/` |
| Поведение PWA | Лендинг перенаправляет на `/app` при запуске из автономного контекста / контекста PWA |

API-клиент фронтенда использует относительные вызовы к тому же домену (same-origin), добавляет bearer-токен из `localStorage` и выбрасывает исключение при ответах, отличных от 2xx (`src/core/services/api-client.ts`).

## Каталог API

| Префикс | Операции | Аутентификация | Назначение |
| --- | --- | --- | --- |
| `/api/health` | `GET` | Нет | Состояние процесса API |
| `/api/auth` | `POST /register`, `POST /login`, `GET /me`, `PUT /profile`, `POST /password/set`, `POST /password/change`, `POST /verify-email/request`, `GET /verify-email/confirm`, `GET /google/url`, `GET /google/callback`, `POST /google/exchange` | Смешанная; запросы профиля/пароля/подтверждения требуют bearer-токен | Идентификация, профиль, подтверждение email и Google OAuth |
| `/api/sync` | `GET /`, `POST /` | Bearer-токен | Восстановление и транзакционное создание/обновление (upsert) адресов пользователя, сервисов, тарифов, коммунальных услуг, регулярных платежей и напоминаний |
| `/api/drive` | `GET /status`, `POST /backup`, `GET /restore` | Bearer-токен | Сохранение/получение зашифрованной на стороне клиента резервной копии в appDataFolder в Google Drive |

Сервер монтирует эти группы в `server/src/index.ts`. В репозитории отсутствует спецификация OpenAPI.

## Персистентность и поведение при сбоях

`checkDbConnection()` выполняет 10 повторных попыток вызова `SELECT NOW()` и после успешного подключения запускает аддитивные миграции `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`. Неуспешная проверка базы данных завершает процесс до вызова `listen()`.

`POST /api/sync` оборачивает все upsert-операции таблиц в транзакцию PostgreSQL. В случае ошибки выполняется `ROLLBACK`, возвращается статус `500` и в любом случае освобождается клиент пула соединений. API принимает локальные ID на стороне клиента в качестве входных данных, сопоставляет их со значениями UUIDv7 и задает значения по умолчанию для отсутствующих доменных полей при импорте.

Резервное копирование в Google Drive сохраняет переданный `encryptedPayload` под именем `novus_life_vault.json.enc` в скрытой папке пользователя `appDataFolder`; сервер не расшифровывает эти данные. Отсутствие refresh-токена возвращает обычный ответ "not connected" или статус `400` в зависимости от эндпоинта. Ошибки OAuth приводят к ответу `500` при обмене (exchange) и выполняют перенаправления с query-параметрами ошибки в процессе обратного вызова (callback flow).

Запросы браузера на использование постоянного хранилища (persistent-storage) выполняются по принципу best effort. Отклоненный запрос `navigator.storage.persist()` возвращается пользователю как результат об отсутствии постоянного хранения; это не блокирует работу приложения (`src/core/services/storage-manager.ts`).

## Реестр переменных окружения

| Переменная | Тип/по умолчанию | Где используется | Критичность |
| --- | --- | --- | --- |
| `PORT` | integer; `3001` | `server/src/index.ts` | Граница запуска |
| `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` | `db`, `5432`, `novus_life`, `novus_user`, `novus_secret_pass_2026` | `server/src/db.ts` | **Критично** для сохранения данных в продакшене; резервный пароль небезопасен |
| `JWT_SECRET` | secret; `novus_life_default_jwt_secret_dev` | `server/src/auth.ts` | **Критично** для идентификации в продакшене; при отсутствии переменной используется небезопасный резервный вариант |
| `APP_URL` | URL; `https://novus-life.online` | Перенаправления аутентификации и ссылки в email | Критично для работы OAuth/ссылок в email |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | строки; пусто | Сценарии Google OAuth и обновления токенов Drive | Критично только для функций Google |
| `RESEND_API_KEY` | secret; пусто | Инициализация Resend | Критично для фактической доставки email; отсутствие ключа включает мок с логированием |
| `EMAIL_FROM_AUTH`, `EMAIL_FROM_NOTIFY`, `EMAIL_REPLY_TO` | строки отправителя со значениями продукта по умолчанию | `server/src/services/email.ts` | Критично только для брендинга/доставки email |
| `VITE_APP_NAME`, `VITE_APP_URL` | шаблонные значения фронтенда | `.env.example` | В `src` не найдено текущих потребителей `import.meta.env` |
| `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` | шаблонные значения фронтенда | `.env.example` | В `src` не найдено текущих потребителей `import.meta.env`; они не свидетельствуют об активном использовании Supabase в runtime |

`server/.env.example` существует и описывает параметры базы данных сервера, JWT, Google и электронной почты. Корневой `.env.example` описывает только Vite/Supabase/Google/email и опускает бэкенд-переменные `PORT`, `DB_*`, `JWT_SECRET` и `APP_URL`; документация для оператора должна указывать на шаблон сервера для развертывания бэкенда.
