# Політика конфіденційності

**Дата набрання чинності**: 8 вересня 2026 року  
**Застосунок**: Novus-Life (`https://novus-life.online`)  
**Екосистема**: SGC-NOVUS (System Generation Core)  
**Відповідність**: Політика щодо даних користувачів сервісів Google API, Загальний регламент про захист даних (GDPR)

---

## 1. Архітектура з нульовим розголошенням та суверенітет даних

Novus-Life побудовано на фундаментальному принципі, згідно з яким комунальні послуги та особисті фінансові записи належать виключно окремому користувачу. Ми реалізуємо модель безпеки з **Zero-Knowledge**:
- Усі чутливі записи, зокрема показання лічильників, суми до сплати, адреси нерухомості та нотатки, шифруються на боці клієнта за допомогою **AES-256-GCM** через апаратно прискорений **Web Crypto API** браузера.
- На сервері зберігається лише непрозорий криптографічний шифротекст. Адміністратори сервера та неавторизовані треті сторони не можуть розшифрувати чи прочитати дані користувача.
- Розшифрування відбувається суворо всередині оперативної пам'яті пристрою за допомогою ключа, похідного на клієнті (**PBKDF2** з 100 000 ітерацій).

---

## 2. Google API Services User Data Policy Compliance

Novus-Life суворо дотримується [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), включаючи вимоги щодо обмеженого використання (Limited Use).

### 2.1 Identity Scopes (`openid`, `userinfo.email`, `userinfo.profile`)
- **Призначення**: Автентифікація облікового запису користувача та встановлення захищеного сеансу на `novus-life.online`.
- **Збирані дані**: Адреса електронної пошти, ім'я для відображення та URL зображення аватара.
- **Обмеження використання**: Ми ніколи не продаємо, не здаємо в оренду та не передаємо адреси електронної пошти третім особам, брокерам даних чи рекламним мережам.

### 2.2 Application Data Scope (`https://www.googleapis.com/auth/drive.appdata`)
- **Призначення**: Необов'язкове зашифроване резервне копіювання бази даних та відновлення між пристроями.
- **Сувора ізоляція**: Доступ суворо обмежений спеціальною прихованою директорією програми (`appDataFolder`).
- **Гарантія безпеки**: Novus-Life **не може отримувати доступ, читати, переглядати, змінювати чи видаляти** будь-які особисті файли, документи, електронні таблиці, фотографії чи папки за межами свого виділеного файлу резервної копії `novus_life_vault.json.enc`.

## 3. Локальне сховище та системні дозволи

### 3.1 Постійне сховище (`navigator.storage.persist()`)
Додаток запитує статус постійного сховища для захисту клієнтської бази даних IndexedDB від процедур автоматичного очищення кешу, які ініціюються обмеженнями дискового простору операційної системи.

### 3.2 Доступ до камери
Дозволи на використання камери запитуються виключно за запитом для зйомки циферблатів фізичних лічильників комунальних послуг з метою оптичного довідкового порівняння. Захоплені зображення стискаються локально та ніколи не завантажуються до публічних хмарних API комп'ютерного зору.

### 3.3 Системні сповіщення
Сповіщення використовуються виключно на пристрої для інформування користувача про наближення термінів оплати рахунків та графіків подачі показників лічильників.

## 4. Права користувача та видалення даних (Право на забуття)

Користувачі зберігають повне право власності на свої дані впродовж усього часу:
- **Локальні дані**: Можуть бути негайно видалені через налаштування додатку.
- **Видалення облікового запису на сервері**: Користувачі можуть запросити або ініціювати постійне видалення облікового запису. Це негайно запускає каскадне видалення в базі даних (`ON DELETE CASCADE`), видаляючи всі записи користувача, облікові дані аутентифікації та стан синхронізації без створення архівних копій.
- **Запити**: З питань захисту даних або офіційних запитів на видалення звертайтеся за адресою: `support@novus-life.online`.
