# Політика конфіденційності

**Дата набрання чинності**: 8 вересня 2026  
**Додаток**: Novus Life (`https://novus-life.online`)  
**Екосистема**: SGC-NOVUS (System Generation Core)  
**Відповідність вимогам**: Google API Services User Data Policy, General Data Protection Regulation (GDPR)

---

## 1. Архітектура Zero-Knowledge та суверенітет даних

Novus Life побудовано на фундаментальному принципі, що комунальні та особисті фінансові записи належать виключно конкретному користувачу. Ми впроваджуємо модель безпеки **Zero-Knowledge**:
- Усі чутливі записи — включно з показаннями лічильників, сумами рахунків, адресами нерухомості та нотатками — шифруються на стороні клієнта за допомогою **AES-256-GCM** через апаратно прискорений **Web Crypto API** браузера.
- Сервер зберігає лише непрозорий криптографічний шифротекст. Адміністратори сервера та сторонні неавторизовані особи не можуть розшифрувати або прочитати дані користувача.
- Розшифрування відбувається виключно в оперативній пам'яті пристрою за допомогою ключа, створеного на клієнті (PBKDF2 зі 100 000 раундів).

---

## 2. Google API Services User Data Policy Compliance

Novus-Life суворо дотримується [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), включаючи вимоги щодо обмеженого використання (Limited Use).

### 2.1 Identity Scopes (`openid`, `userinfo.email`, `userinfo.profile`)
- **Призначення**: Аутентифікація облікового запису користувача та встановлення захищеного сеансу на `novus-life.online`.
- **Збирані дані**: Адреса електронної пошти, відображуване ім'я та URL-адреса зображення аватара.
- **Обмеження використання**: Ми ніколи не продаємо, не здаємо в оренду та не передаємо адреси електронної пошти третім особам, брокерам даних чи рекламним мережам.

### 2.2 Application Data Scope (`https://www.googleapis.com/auth/drive.appdata`)
- **Призначення**: Необов'язкове зашифроване резервне копіювання бази даних та відновлення між пристроями.
- **Сувора ізоляція**: Доступ суворо обмежено прихованою директорією, специфічною для додатка (`appDataFolder`).
- **Гарантія безпеки**: Novus-Life **не має доступу, не може читати, переглядати, змінювати чи видаляти** будь-які особисті файли, документи, електронні таблиці, фотографії чи папки поза межами свого спеціального файлу резервної копії `novus_life_vault.json.enc`.

## 3. Локальне сховище та системні дозволи

### 3.1 Постійне сховище (`navigator.storage.persist()`)
Додаток запитує статус постійного сховища для захисту клієнтської бази даних IndexedDB від процедур автоматичного очищення кешу, які ініціюються обмеженнями дискового простору операційної системи.

### 3.2 Доступ до камери
Дозволи на використання камери запитуються виключно на вимогу для зйомки циферблатів фізичних лічильників комунальних послуг з метою оптичного довідкового порівняння. Зроблені зображення стискаються локально та ніколи не завантажуються в публічні хмарні API комп'ютерного зору.

### 3.3 Системні сповіщення
Сповіщення використовуються виключно на пристрої для інформування користувача про наближення термінів оплати та графіків подачі показників лічильників.

## 4. Права користувача та видалення даних (Право на забуття)

Користувачі завжди зберігають повне право власності на свої дані:
- **Локальні дані**: Можуть бути негайно видалені через налаштування додатку.
- **Видалення облікового запису на сервері**: Користувачі можуть надіслати запит або ініціювати постійне видалення облікового запису. Це негайно запускає каскадне видалення в базі даних (`ON DELETE CASCADE`), видаляючи всі записи користувача, облікові дані аутентифікації та стан синхронізації без створення архівних копій.
- **Запити**: З питань захисту даних або офіційних запитів на видалення звертайтеся за адресою: `support@novus-life.online`.
