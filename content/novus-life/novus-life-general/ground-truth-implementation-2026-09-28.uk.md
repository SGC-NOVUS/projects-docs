# Джерело істини: реалізація Novus Life

**Статус:** внутрішній статичний аудит checkout від 28.09.2026.
**Область дії:** маршрути Vue/PWA, бекенд Express, PostgreSQL, інтеграції з Google, email, сховище браузера та конфігурація середовища.

## Поточна архітектура

Репозиторій не є шаблоном React, описаним у його кореневому файлі README. Відстежувана реалізація:

| Рівень | Фактична реалізація |
| --- | --- |
| Браузер | Vue 3, Vite, Vue Router, Pinia, i18n та ресурси PWA |
| Локальні дані клієнта | Сховище браузера/служби можливостей пристрою та доменні сховища для адрес, послуг, тарифів, показань лічильників, платежів та нагадувань |
| API | Express на `0.0.0.0`, `PORT` за замовчуванням `3001`; CORS origin — `*`; JSON/urlencoded тіла запитів обмежені 15 MiB |
| Збереження даних | PostgreSQL через пул `pg`; сервер відмовляється прослуховувати порт після 10 невдалих спроб підключення з інтервалом у 2 секунди |
| Ідентифікація | JWT з email/паролем плюс Google OAuth; час життя bearer JWT становить 60 днів |
| Хмарне резервне копіювання | Google Drive `appDataFolder`, що отримує непрозоре зашифроване корисне навантаження від клієнта |
| Пошта | Resend; відсутність API-ключа перемикає пошту на заглушку для логування, яка повертає успішний результат |

## Навігація в браузері та модулі

| Область маршруту | Реалізовані модулі |
| --- | --- |
| Public | Лендинг, приватність, умови, про нас, авторизація |
| `/app` | Панель керування, профіль, комунальні послуги, тарифи, адреси, послуги, платежі, нагадування, аналітика, налаштування |
| Сумісність | Застарілі короткі URL-адреси перенаправляють на `/app/*`; невідомі шляхи перенаправляють на `/` |
| Поведінка PWA | Лендинг перенаправляє на `/app` при запуску в контексті standalone/PWA |

Клієнт API фронтенду використовує відносні виклики same-origin, додає bearer-токен з `localStorage` та викидає виняток у разі відповідей, відмінних від 2xx (`src/core/services/api-client.ts`).

## Каталог API

| Префікс | Операції | Автентифікація | Призначення |
| --- | --- | --- | --- |
| `/api/health` | `GET` | Ні | Дані про стан працездатності процесу API |
| `/api/auth` | `POST /register`, `POST /login`, `GET /me`, `PUT /profile`, `POST /password/set`, `POST /password/change`, `POST /verify-email/request`, `GET /verify-email/confirm`, `GET /google/url`, `GET /google/callback`, `POST /google/exchange` | Змішана; запити profile/password/verify потребують bearer-токен | Ідентифікація, профіль, підтвердження електронної пошти та Google OAuth |
| `/api/sync` | `GET /`, `POST /` | Bearer-токен | Відновлення та транзакційне оновлення або створення (upsert) адрес користувачів, послуг, тарифів, комунальних послуг, регулярних платежів та нагадувань |
| `/api/drive` | `GET /status`, `POST /backup`, `GET /restore` | Bearer-токен | Збереження/отримання зашифрованої на стороні клієнта резервної копії в Google Drive appDataFolder |

Сервер монтує ці групи в `server/src/index.ts`. У репозиторії немає специфікації OpenAPI.

## Персистентність та поведінка при збоях

`checkDbConnection()` повторює спробу `SELECT NOW()` десять разів і запускає адитивні міграції `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` після успішного підключення. Невдала перевірка бази даних завершує процес перед `listen()`.

`POST /api/sync` обгортає всі операції upsert для таблиць у транзакцію PostgreSQL. У разі помилки виконується `ROLLBACK`, повертається `500` і завжди вивільняється клієнт пулу. API розглядає локальні ID на стороні клієнта як вхідні дані, відображає їх на значення UUIDv7 та підставляє значення за замовчуванням для відсутніх доменних полів під час імпорту.

Резервне копіювання в Google Drive зберігає наданий `encryptedPayload` як `novus_life_vault.json.enc` у прихованій папці користувача `appDataFolder`; сервер не розшифровує корисне навантаження. Відсутність refresh token повертає звичайну відповідь "not connected"/`400` залежно від ендпоінту. Помилки OAuth відображаються як `500` під час обміну та як перенаправлення з параметрами запиту помилки у callback-процесі.

Запити до персистентного сховища браузера виконуються за принципом найкращих зусиль (best effort). Відхилений запит `navigator.storage.persist()` повертається як результат без персистентного збереження для користувача; він не блокує роботу застосунку (`src/core/services/storage-manager.ts`).

## Реєстр змінних оточення

| Змінна | Тип/значення за замовчуванням | Де використовується | Критичність |
| --- | --- | --- | --- |
| `PORT` | integer; `3001` | `server/src/index.ts` | Межа запуску |
| `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` | `db`, `5432`, `novus_life`, `novus_user`, `novus_secret_pass_2026` | `server/src/db.ts` | **Критично** для збереження даних у продакшені; резервний пароль є небезпечним |
| `JWT_SECRET` | secret; `novus_life_default_jwt_secret_dev` | `server/src/auth.ts` | **Критично** для ідентифікації у продакшені; якщо опущено, активується небезпечний резервний варіант |
| `APP_URL` | URL; `https://novus-life.online` | Перенаправлення автентифікації та посилання в листах | Критично для роботи функцій OAuth та посилань у листах |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | strings; порожньо | Процеси оновлення Google OAuth та Drive | Критично лише для функцій Google |
| `RESEND_API_KEY` | secret; порожньо | Ініціалізація Resend | Критично для фактичної доставки листів; відсутність ключа вмикає заглушку з логуванням |
| `EMAIL_FROM_AUTH`, `EMAIL_FROM_NOTIFY`, `EMAIL_REPLY_TO` | рядки відправника зі значеннями за замовчуванням для продукту | `server/src/services/email.ts` | Критично лише для брендування та доставки листів |
| `VITE_APP_NAME`, `VITE_APP_URL` | шаблонні значення фронтенду | `.env.example` | У `src` не знайдено поточних споживачів `import.meta.env` |
| `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` | шаблонні значення фронтенду | `.env.example` | У `src` не знайдено поточних споживачів `import.meta.env`; вони не є свідченням активного використання Supabase під час виконання |

`server/.env.example` існує та містить документацію щодо бази даних сервера, JWT, Google та параметрів електронної пошти. Кореневий `.env.example` містить документацію лише для Vite/Supabase/Google/email і не містить бекенд-параметрів `PORT`, `DB_*`, `JWT_SECRET` та `APP_URL`; документація для оператора повинна вказувати на шаблон сервера для розгортання бекенду.

## Підтверджені прогалини в документації

1. Замінити README кореневого React-шаблону документацією для Vue + Express + PostgreSQL.
2. Додати довідник API, згенерований на основі трьох підключених роутерів Express.
3. Видалити небезпечні значення за замовчуванням для JWT та пароля бази даних у продакшені або налаштувати запуск так, щоб він відхиляв їх за межами середовища розробки.
4. Уточнити, що поточна синхронізація клієнта спрямована на self-hosted Express API; значення Supabase у кореневому шаблоні наразі не використовуються кодом браузера.
