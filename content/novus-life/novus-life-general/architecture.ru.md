# Обзор архитектуры: Novus Life

**Novus Life** — это приватная офлайн-платформа для управления коммунальными и домашними расходами, спроектированная и поддерживаемая **SGC-NOVUS** (System Generation Core). Она сочетает в себе клиентскую криптографическую изоляцию и автономную серверную инфраструктуру.

---

## 1. Высокоуровневая архитектура

Система работает на базе **гибридной модели хранения и приоритизации офлайн-режима (Hybrid Storage & Offline-First Model)**:
1. **Первичный уровень клиента (IndexedDB через Dexie.js)**:
   - Все непосредственные взаимодействия, ввод показаний счетчиков, расчет тарифов и просмотр истории выполняются напрямую с локальной IndexedDB.
   - Защита от вытеснения кэша на уровне ОС реализована с помощью **Persistent Storage API** (`navigator.storage.persist()`).
   - Обеспечивает 100% работоспособность в офлайн-среде (например, в подвалах, шахтах коммуникаций, при отключенной сети).
2. **Уровень серверной синхронизации (Self-Hosted VPS)**:
   - Построен на базе **Node.js 22+ (Express + драйвер pg)** и **PostgreSQL 16**.
   - Доступен через строго внутреннее проксирование за Nginx по домену `https://novus-life.online/api/*`.
   - Данные фиксируются в атомарных SQL-транзакциях (`BEGIN ... COMMIT`) для предотвращения состояний частичной синхронизации.
   - Все реляционные сущности используют первичные ключи **UUIDv7** (RFC 9562) для индексации с упорядочиванием по временной метке без фрагментации страниц B-Tree.
3. **Уровень резервного копирования (Google Drive `appDataFolder`)**:
   - Опциональная синхронизация зашифрованных архивов с использованием скрытой папки `appDataFolder` в Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Изолирована от корневых файлов пользователя, что предотвращает случайное удаление вручную.

## 2. Жизненный цикл PWA и WebAPK

### Android (WebAPK)
- На современных устройствах Android (Chrome, Edge, Samsung Internet) Novus-Life соответствует всем критериям WebAPK (валидный манифест, режим отображения standalone, маскируемые и стандартные иконки, зарегистрированный service worker).
- Операционная система создает полноценный пакет Android (`org.chromium.webapk.*`), предоставляя:
  - Изолированную песочницу Linux UID, отличную от процессов вкладок браузера.
  - Независимую запись приложения в **Android Settings -> Apps -> Novus-Life**.
  - Системные переключатели разрешений (Камера для съемки показаний счетчиков, Push-уведомления для напоминаний об оплате).
  - Отчет о выделении хранилища (кэш IndexedDB корректно отображается в системных настройках).

### Desktop (Windows, macOS, Linux)
- Работает в режиме отдельного окна с `window-controls-overlay` и синхронизацией системной темы.

### Apple iOS
- Работает через Safari Web App («Добавить на экран “Домой”») в полноэкранном режиме standalone с оптимизацией для сенсорного ввода.

## 3. Поток данных и криптографические границы

1. **Создание локальной записи**:
   - Пользователь вводит показания приборов учета (например, электричество T1/T2, холодная вода, газ).
   - Разности показаний и суммы вычисляются «на лету» с использованием активного тарифного расписания.
   - Запись сохраняется в IndexedDB с уникальным локальным идентификатором UUIDv7.
2. **Криптографическая защита (Zero-Knowledge)**:
   - Конфиденциальные полезные данные передаются в `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Производный мастер-ключ хранится исключительно в памяти клиентской среды выполнения (PBKDF2 с 100 000 итераций).
   - На удаленные конечные точки отправляется только зашифрованный шифротекст.
3. **Синхронизация**:
   - Служба синхронизации передает пакеты записей через `/api/sync` с аутентификацией по стандартному JSON Web Token (JWT).
   - База данных PostgreSQL сохраняет строки сущностей с каскадным удалением (`ON DELETE CASCADE`), привязанным к `user_id`.

## 4. Технологическая матрица

| Уровень | Технология | Роль |
|---|---|---|
| **Среда выполнения** | Node.js 26.x Active | Среда выполнения бэкенд-API |
