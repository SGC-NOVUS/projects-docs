# Обзор архитектуры: Novus Life

**Novus Life** — это приватная платформа для учета коммунальных услуг и домашних расходов, работающая по принципу offline-first, разработанная и поддерживаемая **SGC-NOVUS** (System Generation Core). Она сочетает в себе клиентскую криптографическую изоляцию и автономную серверную инфраструктуру.

---

## 1. Высокоуровневая архитектура

Система работает на основе **модели гибридного хранения и приоритета автономной работы (Hybrid Storage & Offline-First Model)**:
1. **Первичный клиентский уровень (IndexedDB через Dexie.js)**:
   - Все непосредственные взаимодействия, ввод показаний счетчиков, расчет тарифов и просмотр истории выполняются напрямую с локальной базой данных IndexedDB.
   - Защита от вытеснения кэша на уровне ОС реализована с помощью **Persistent Storage API** (`navigator.storage.persist()`).
   - Обеспечивает 100% оперативность работы в автономных средах (например, в подвалах, шахтах коммуникаций, при отключенной сети).
2. **Уровень синхронизации сервера (Саморазворачиваемый VPS)**:
   - Построен на базе **Node.js 22+ (Express + драйвер pg)** и **PostgreSQL 16**.
   - Доступен через строго внутреннее проксирование за Nginx по домену `https://novus-life.online/api/*`.
   - Данные фиксируются в атомарных транзакциях SQL (`BEGIN ... COMMIT`) для предотвращения состояний неполной синхронизации.
   - Все реляционные сущности используют первичные ключи **UUIDv7** (RFC 9562) для индексации с упорядочением по временной метке без фрагментации страниц B-Tree.
3. **Уровень резервного копирования (`appDataFolder` в Google Drive)**:
   - Опциональная синхронизация зашифрованных архивов с использованием скрытой папки `appDataFolder` в Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Изолирована от корневых файлов пользователя, что предотвращает случайное ручное удаление.

## 2. Жизненный цикл PWA и WebAPK

### Android (WebAPK)
- На современных устройствах Android (Chrome, Edge, Samsung Internet) Novus-Life соответствует всем критериям WebAPK (корректный манифест, режим отображения standalone, маскируемые и стандартные иконки, зарегистрированный service worker).
- Операционная система создает подлинный пакет Android (`org.chromium.webapk.*`), предоставляя:
  - Изолированную песочницу Linux UID, отличную от процессов вкладок браузера.
  - Независимую запись приложения в меню **Android Settings -> Apps -> Novus Life**.
  - Системные переключатели разрешений (Камера для съемки показаний счетчиков, Push-уведомления для напоминаний об оплате).
  - Отчет о выделении хранилища (кэш IndexedDB корректно отображается в системных настройках).

### Desktop (Windows, macOS, Linux)
- Работает в режиме отдельного окна с поддержкой `window-controls-overlay` и синхронизацией системной темы.

### Apple iOS
- Работает через Safari Web App («Добавить на экран “Домой”») в полноэкранном режиме standalone с оптимизацией для сенсорного ввода.

## 3. Потоки данных и криптографические границы

1. **Создание локальной записи**:
   - Пользователь вводит показания приборов учета (например, электричество T1/T2, холодная вода, газ).
   - Разности показаний и суммы рассчитываются "на лету" с использованием активного тарифного расписания.
   - Запись сохраняется в IndexedDB с уникальным локальным UUIDv7.
2. **Криптографическая защита (Zero-Knowledge)**:
   - Конфиденциальные полезные данные передаются в `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Производный мастер-ключ хранится исключительно в памяти клиентской среды выполнения (PBKDF2 с 100 000 итерациями).
   - На удаленные эндпоинты отправляется только зашифрованный шифротекст.
3. **Синхронизация**:
   - Служба синхронизации передает пакетные записи через `/api/sync`, аутентифицируемые с помощью стандартного JSON Web Token (JWT).
   - База данных PostgreSQL сохраняет строки сущностей с каскадным удалением (`ON DELETE CASCADE`), привязанным к `user_id`.

## 4. Технологическая матрица

| Уровень | Технология | Роль |
|---|---|---|
| **Среда выполнения** | Node.js 26.x Active | Среда выполнения бэкенд-API |
| **База данных** | PostgreSQL 18 (Docker) | Реляционный движок базы данных |
| **API-фреймворк** | Express 5.0.x+ / TypeScript | Маршрутизация и валидация HTTP API |
| **Первичные ключи** | UUIDv7 (RFC 9562) | Идентификаторы, упорядоченные по миллисекундам и защищенные от коллизий |
| **Фронтенд-фреймворк** | Vue 3.5+ Composition API | Реактивный веб-интерфейс |
| **Управление состоянием** | Pinia 3.x | Хранилище клиентского состояния и сессий |
| **Движок стилей** | Tailwind CSS v4 | CSS-система на основе утилит |
| **Локальная база данных** | Dexie.js 4.x (IndexedDB) | Клиентское хранилище данных с приоритетом оффлайн-режима |
| **Криптографический движок** | Web Crypto API | Клиентский AES-256-GCM |
| **Обратный прокси** | Nginx 1.24+ | SSL-терминация, обратное проксирование, статическое кэширование |

| **Ecosystem** | SGC-NOVUS | Архитектурное владение и жизненный цикл релизов |
