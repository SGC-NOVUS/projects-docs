# Обзор архитектуры: Novus Life

**Novus Life** — это приватная offline-first платформа для управления коммунальными и домашними расходами, разработанная и поддерживаемая **SGC-NOVUS** (System Generation Core). Она сочетает криптографическую изоляцию на стороне клиента с автономной серверной инфраструктурой.

---

## 1. Высокоуровневая архитектура

Система функционирует на основе **модели гибридного хранения и Offline-First**:
1. **Основной клиентский слой (IndexedDB через Dexie.js)**:
   - Все текущие взаимодействия, ввод показаний счетчиков, расчет тарифов и просмотр истории выполняются напрямую в локальной IndexedDB.
   - Защищен от удаления кэша на уровне ОС с помощью **Persistent Storage API** (`navigator.storage.persist()`).
   - Обеспечивает 100% работоспособность в автономном режиме (например, в подвалах, технических шахтах, изолированных сетях).
2. **Слой серверной синхронизации (Self-Hosted VPS)**:
   - Построен на базе **Node.js 22+ (Express + драйвер pg)** и **PostgreSQL 16**.
   - Доступен строго через внутреннее проксирование за Nginx по домену `https://novus-life.online/api/*`.
   - Данные фиксируются в атомарных SQL-транзакциях (`BEGIN ... COMMIT`) для предотвращения состояний частичной синхронизации.
   - Все реляционные сущности используют первичные ключи **UUIDv7** (RFC 9562) для индексации с упорядочиванием по метке времени без фрагментации страниц B-Tree.
3. **Слой резервного копирования (Google Drive `appDataFolder`)**:
   - Опциональная синхронизация зашифрованных архивов с использованием скрытой папки Google Drive `appDataFolder` (`https://www.googleapis.com/auth/drive.appdata`).
   - Изолирован от корневых файлов пользователя, что предотвращает случайное ручное удаление.

## 2. Жизненный цикл PWA и WebAPK

### Android (WebAPK)
- На современных устройствах Android (Chrome, Edge, Samsung Internet) Novus Life соответствует всем критериям WebAPK (валидный манифест, автономный режим отображения standalone, адаптивные и стандартные иконки, зарегистрированный service worker).
- Операционная система создает полноценный пакет Android (`org.chromium.webapk.*`), предоставляющий:
  - Изолированную песочницу Linux UID, отделенную от процессов вкладок браузера.
  - Отдельную запись приложения в **Настройки Android -> Приложения -> Novus Life**.
  - Переключатели разрешений на системном уровне (Камера для фотофиксации счетчиков, Push-уведомления для напоминаний об оплате).
  - Отчетность об использовании хранилища (кэш IndexedDB корректно отображается в настройках ОС).

### Desktop (Windows, macOS, Linux)
- Работает в автономном оконном режиме с поддержкой `window-controls-overlay` и синхронизацией с системной темой.

### Apple iOS
- Работает через Safari Web App («На экран "Домой"») в полноэкранном автономном режиме с оптимизацией под сенсорный ввод.

## 3. Потоки данных и криптографические границы

1. **Создание локальной записи**:
   - Пользователь вводит показания приборов учёта (например, электричество Т1/Т2, холодная вода, газ).
   - Разница показаний и итоговые суммы рассчитываются на лету с использованием активного тарифного расписания.
   - Запись сохраняется в IndexedDB с уникальным локальным UUIDv7.
2. **Криптографическая защита (Zero-Knowledge)**:
   - Конфиденциальная полезная нагрузка передаётся в `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Производный мастер-ключ хранится исключительно в оперативной памяти клиента (PBKDF2 с 100 000 итераций).
   - На удалённые конечные точки отправляется только зашифрованный шифротекст.
3. **Синхронизация**:
   - Служба синхронизации передаёт пакеты записей через `/api/sync` с аутентификацией с помощью стандартного JSON Web Token (JWT).
   - База данных PostgreSQL сохраняет строки сущностей с каскадным удалением (`ON DELETE CASCADE`), привязанным к `user_id`.

## 4. Матрица технологий

| Уровень | Технология | Роль |
|---|---|---|
| **Среда выполнения** | Node.js 26.x Active | Среда выполнения бэкенд-API |
| **База данных** | PostgreSQL 18 (Docker) | Реляционная СУБД |
| **Фреймворк API** | Express 5.0.x+ / TypeScript | Маршрутизация и валидация HTTP API |
| **Первичные ключи** | UUIDv7 (RFC 9562) | Идентификаторы, упорядоченные по миллисекундам и защищённые от коллизий |
| **Фронтенд-фреймворк** | Vue 3.5+ Composition API | Реактивный веб-интерфейс |
| **Управление состоянием** | Pinia 3.x | Хранилище состояния клиента и сессий |
| **Движок стилей** | Tailwind CSS v4 | Utility-first CSS-система |
| **Локальная база данных** | Dexie.js 4.x (IndexedDB) | Клиентское хранилище данных (offline-first) |
| **Криптографический движок** | Web Crypto API | AES-256-GCM на стороне клиента |
| **Обратный прокси** | Nginx 1.24+ | Терминация SSL, обратное проксирование, кэширование статики |

| **Экосистема** | SGC-NOVUS | Архитектурное владение и жизненный цикл релизов |
