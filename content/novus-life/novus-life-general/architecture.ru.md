# Обзор архитектуры: Novus Life

**Novus Life** — это приватная автономная платформа для управления коммунальными и домашними расходами (offline-first), спроектированная и поддерживаемая **SGC-NOVUS** (System Generation Core). Она сочетает в себе клиентскую криптографическую изоляцию и автономную серверную инфраструктуру.

---

## 1. Высокоуровневая архитектура

Система работает на базе **гибридной модели хранения и приоритета автономной работы (Hybrid Storage & Offline-First Model)**:
1. **Основной клиентский уровень (IndexedDB через Dexie.js)**:
   - Все непосредственные взаимодействия, ввод показаний счетчиков, расчет тарифов и просмотр истории выполняются напрямую с локальной базой данных IndexedDB.
   - Защита от вытеснения кэша на уровне ОС реализована с помощью **Persistent Storage API** (`navigator.storage.persist()`).
   - Гарантирует 100% работоспособность в автономных условиях (например, в подвалах, шахтах коммуникаций, при отсутствии сети).
2. **Уровень синхронизации сервера (Self-Hosted VPS)**:
   - Построен на базе **Node.js 22+ (Express + драйвер pg)** и **PostgreSQL 16**.
   - Доступен через строго внутреннее проксирование за Nginx по домену `https://novus-life.online/api/*`.
   - Данные фиксируются в атомарных транзакциях SQL (`BEGIN ... COMMIT`) для предотвращения состояний неполной синхронизации.
   - Все реляционные сущности используют первичные ключи **UUIDv7** (RFC 9562) для индексации с упорядочиванием по временным меткам без фрагментации страниц B-Tree.
3. **Уровень резервного копирования (Google Drive `appDataFolder`)**:
   - Опциональная синхронизация зашифрованных архивов с использованием скрытой папки `appDataFolder` в Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Изолирована от корневых файлов пользователя, что предотвращает случайное ручное удаление.

## 2. Жизненный цикл PWA и WebAPK

### Android (WebAPK)
- На современных устройствах Android (Chrome, Edge, Samsung Internet) Novus Life соответствует всем критериям WebAPK (валидный манифест, режим отображения standalone, маскируемые и стандартные иконки, зарегистрированный service worker).
- Операционная система создает полноценный Android-пакет (`org.chromium.webapk.*`), предоставляющий:
  - Изолированную песочницу Linux UID, отделенную от процессов вкладок браузера.
  - Отдельную запись приложения в **Настройки Android -> Приложения -> Novus Life**.
  - Системные переключатели разрешений (Камера для фотофиксации показаний счетчиков, Push-уведомления для напоминаний об оплате).
  - Отчетность о выделении памяти (кэш IndexedDB корректно отображается в настройках ОС).

### Desktop (Windows, macOS, Linux)
- Работает в автономном оконном режиме с `window-controls-overlay` и синхронизацией с системной темой.

### Apple iOS
- Работает через Safari Web App («На экран "Домой"») в полноэкранном режиме standalone с оптимизацией для сенсорного ввода.

## 3. Data Flow & Cryptographic Boundaries

1. **Создание локальной записи**:
   - Пользователь вводит показания приборов учета (например, электричество T1/T2, холодная вода, газ).
   - Разница показаний и итоговые суммы рассчитываются «на лету» с использованием действующей тарифной сетки.
   - Запись сохраняется в IndexedDB с уникальным локальным UUIDv7.
2. **Криптографическая защита (Zero-Knowledge)**:
   - Конфиденциальные полезные нагрузки передаются в `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Производный мастер-ключ хранится исключительно в оперативной памяти клиента (PBKDF2 с 100 000 итераций).
   - На удаленные эндпоинты отправляется только зашифрованный шифротекст.
3. **Синхронизация**:
   - Сервис синхронизации передает пакеты записей через `/api/sync` с аутентификацией по стандартному JSON Web Token (JWT).
   - База данных PostgreSQL сохраняет строки сущностей с каскадным удалением (`ON DELETE CASCADE`), привязанным к `user_id`.

## 4. Technology Matrix

| Слой | Технология | Роль |
|---|---|---|
| **Среда выполнения** | Node.js 26.x Active | Среда выполнения Backend API |
| **База данных** | PostgreSQL 18 (Docker) | Реляционная СУБД |
| **Фреймворк API** | Express 5.0.x+ / TypeScript | Маршрутизация и валидация HTTP API |
| **Первичные ключи** | UUIDv7 (RFC 9562) | Упорядоченные по миллисекундам идентификаторы без коллизий |
| **Фреймворк фронтенда** | Vue 3.5+ Composition API | Реактивный веб-интерфейс |
| **Управление состоянием** | Pinia 3.x | Хранилище состояния клиента и сессий |
| **Движок стилей** | Tailwind CSS v4 | Utility-first CSS-система |
| **Локальная база данных** | Dexie.js 4.x (IndexedDB) | Клиентское хранилище данных (Offline-first) |
| **Криптографический движок** | Web Crypto API | AES-256-GCM на стороне клиента |
| **Обратный прокси** | Nginx 1.24+ | Терминация SSL, обратное проксирование, кэширование статики |

| **Экосистема** | SGC-NOVUS | Архитектурное владение и жизненный цикл релизов |
