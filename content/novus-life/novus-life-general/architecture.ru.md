# Обзор архитектуры: Novus Life

**Novus Life** — это приватная офлайн-платформа для управления коммунальными и домашними расходами, спроектированная и поддерживаемая **SGC-NOVUS** (System Generation Core). Она сочетает в себе клиентскую криптографическую изоляцию и автономную серверную инфраструктуру.

---

## 1. Высокоуровневая архитектура

Система работает на базе **гибридной модели хранения с приоритетом офлайн-режима (Hybrid Storage & Offline-First Model)**:
1. **Первичный клиентский слой (IndexedDB через Dexie.js)**:
   - Все непосредственные взаимодействия, ввод показаний счетчиков, расчет тарифов и просмотр истории выполняются напрямую с локальной базой данных IndexedDB.
   - Защита от удаления кэша на уровне ОС реализована с помощью **Persistent Storage API** (`navigator.storage.persist()`).
   - Обеспечивает 100% работоспособность в автономных условиях (например, в подвалах, шахтах коммуникаций, при отсутствии сети).
2. **Слой синхронизации с сервером (Self-Hosted VPS)**:
   - Построен на базе **Node.js 22+ (Express + драйвер pg)** и **PostgreSQL 16**.
   - Доступен через строго внутреннее проксирование за Nginx по домену `https://novus-life.online/api/*`.
   - Данные фиксируются в атомарных SQL-транзакциях (`BEGIN ... COMMIT`) во избежание состояний неполной синхронизации.
   - Все реляционные сущности используют первичные ключи **UUIDv7** (RFC 9562) для индексации с упорядочиванием по временным меткам без фрагментации страниц B-Tree.
3. **Слой резервного копирования (Google Drive `appDataFolder`)**:
   - Опциональная синхронизация зашифрованных архивов с использованием скрытой папки `appDataFolder` в Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Изолирована от корневых файлов пользователя во избежание случайного удаления вручную.

## 2. Жизненный цикл PWA и WebAPK

### Android (WebAPK)
- На современных устройствах Android (Chrome, Edge, Samsung Internet) Novus Life соответствует всем критериям WebAPK (валидный манифест, режим отображения standalone, маскируемые и стандартные иконки, зарегистрированный service worker).
- Операционная система генерирует подлинный пакет Android (`org.chromium.webapk.*`), предоставляющий:
  - Изолированную песочницу Linux UID, отделенную от процессов вкладок браузера.
  - Независимую запись приложения в **Настройки Android -> Приложения -> Novus Life**.
  - Переключатели разрешений системного уровня (камера для фотофиксации показаний счетчиков, push-уведомления для напоминаний об оплате).
  - Учет выделенной памяти (кэш IndexedDB корректно отображается в настройках ОС).

### Desktop (Windows, macOS, Linux)
- Работает в режиме отдельного окна (standalone) с `window-controls-overlay` и синхронизацией с системной темой.

### Apple iOS
- Запускается через Safari Web App («На экран „Домой“») в полноэкранном режиме standalone с оптимизацией под сенсорный ввод.

## 3. Data Flow & Cryptographic Boundaries

1. **Создание локальной записи**:
   - Пользователь вводит показания приборов учета (например, электроэнергия T1/T2, холодная вода, газ).
   - Разница показаний и суммы рассчитываются на лету с использованием активной тарифной сетки.
   - Запись сохраняется в IndexedDB с уникальным локальным UUIDv7.
2. **Криптографическая защита (Zero-Knowledge)**:
   - Конфиденциальные полезные данные передаются в `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Производный мастер-ключ хранится исключительно в оперативной памяти клиента (PBKDF2 со 100 000 итераций).
   - На удаленные эндпоинты отправляется только зашифрованный шифротекст.
3. **Синхронизация**:
   - Служба синхронизации передает пакетные записи через `/api/sync` с аутентификацией с помощью стандартного JSON Web Token (JWT).
   - База данных PostgreSQL сохраняет строки сущностей с каскадным удалением (`ON DELETE CASCADE`), привязанным к `user_id`.

## 4. Technology Matrix

|---|---|---|
| **Среда выполнения** | Node.js 26.x Active | Среда выполнения Backend API |
