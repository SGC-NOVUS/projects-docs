# Обзор архитектуры: Novus Life

**Novus Life** — это приватная offline-first платформа для управления коммунальными и домашними расходами, разработанная и поддерживаемая **SGC-NOVUS** (System Generation Core). Она сочетает в себе криптографическую изоляцию на стороне клиента с автономной серверной инфраструктурой.

---

## 1. Высокоуровневая архитектура

Система работает на основе **модели гибридного хранения и offline-first**:
1. **Основной клиентский слой (IndexedDB через Dexie.js)**:
   - Все текущие операции, ввод показаний счетчиков, расчет тарифов и просмотр истории выполняются напрямую с использованием локальной IndexedDB.
   - Защищен от удаления кэша на уровне ОС с помощью **Persistent Storage API** (`navigator.storage.persist()`).
   - Обеспечивает 100% работоспособность в условиях отсутствия сети (например, в подвалах, технических шахтах, изолированных сетях).
2. **Серверный слой синхронизации (Self-Hosted VPS)**:
   - Построен на базе **Node.js 22+ (Express + драйвер pg)** и **PostgreSQL 16**.
   - Доступен через строго внутреннее проксирование за Nginx по домену `https://novus-life.online/api/*`.
   - Данные фиксируются в атомарных SQL-транзакциях (`BEGIN ... COMMIT`) для предотвращения состояний частичной синхронизации.
   - Все реляционные сущности используют первичные ключи **UUIDv7** (RFC 9562) для индексации с упорядочиванием по метке времени без фрагментации страниц B-Tree.
3. **Слой резервного копирования (Google Drive `appDataFolder`)**:
   - Опциональная синхронизация зашифрованных архивов с использованием скрытой папки Google Drive `appDataFolder` (`https://www.googleapis.com/auth/drive.appdata`).
   - Изолирован от корневых файлов пользователя, что предотвращает случайное удаление вручную.

## 2. Жизненный цикл PWA и WebAPK

### Android (WebAPK)
- На современных устройствах Android (Chrome, Edge, Samsung Internet) Novus-Life соответствует всем критериям WebAPK (валидный манифест, режим отображения standalone, маскируемые и стандартные иконки, зарегистрированный service worker).
- Операционная система создает полноценный пакет Android (`org.chromium.webapk.*`), предоставляя:
  - Изолированную песочницу Linux UID, отличную от процессов вкладок браузера.
  - Независимую запись приложения в **Android Settings -> Apps -> Novus-Life**.
  - Системные переключатели разрешений (Камера для съемки показаний приборов, Push-уведомления для напоминаний об оплате).
  - Отчет о выделении хранилища (кэш IndexedDB корректно отображается в системных настройках).

### Desktop (Windows, macOS, Linux)
- Работает в режиме отдельного окна с поддержкой `window-controls-overlay` и синхронизацией системной темы.

### Apple iOS
- Работает через Safari Web App («Добавить на экран “Домой”») в полноэкранном режиме standalone с оптимизацией под касания.

## 3. Потоки данных и криптографические границы

1. **Создание локальной записи**:
   - Пользователь вводит показания приборов учета (например, электроэнергия T1/T2, холодная вода, газ).
   - Разницы показаний и суммы вычисляются «на лету» с использованием активного тарифного расписания.
   - Запись сохраняется в IndexedDB с уникальным локальным UUIDv7.
2. **Криптографическая защита (с нулевым разглашением)**:
   - Конфиденциальные полезные данные передаются в `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Производный мастер-ключ хранится исключительно в памяти клиентской среды выполнения (PBKDF2 с 100 000 итераций).
   - На удаленные эндпоинты отправляется только зашифрованный шифротекст.
3. **Синхронизация**:
   - Служба синхронизации передает пакетные записи через `/api/sync` с аутентификацией по стандартному JSON Web Token (JWT).
   - База данных PostgreSQL сохраняет строки сущностей с каскадным удалением (`ON DELETE CASCADE`), привязанным к `user_id`.

## 4. Технологическая матрица

| Уровень | Технология | Роль |
|---|---|---|
| **Среда выполнения** | Node.js 26.x Active | Среда выполнения бэкенд-API |
| **База данных** | PostgreSQL 18 (Docker) | Реляционный движок базы данных |
| **API-фреймворк** | Express 5.0.x+ / TypeScript | Маршрутизация и валидация HTTP API |
| **Первичные ключи** | UUIDv7 (RFC 9562) | Идентификаторы с упорядочиванием по миллисекундам и защитой от коллизий |
| **Фронтенд-фреймворк** | Vue 3.5+ Composition API | Реактивный веб-интерфейс |
| **Управление состоянием** | Pinia 3.x | Хранилище клиентского состояния и сессий |
| **Движок стилей** | Tailwind CSS v4 | CSS-система на основе утилит |
| **Локальная база данных** | Dexie.js 4.x (IndexedDB) | Клиентское хранилище данных с приоритетом оффлайн-режима |
| **Криптографический движок** | Web Crypto API | Клиентский AES-256-GCM |
| **Обратный прокси** | Nginx 1.24+ | Терминация SSL, обратное проксирование, статическое кэширование |

| **Ecosystem** | SGC-NOVUS | Архитектурная принадлежность и жизненный цикл релиза |
