# Обзор архитектуры: Novus Life

**Novus Life** — это приватная офлайн-платформа для управления коммунальными и домашними расходами, спроектированная и поддерживаемая **SGC-NOVUS** (System Generation Core). Она сочетает в себе клиентскую криптографическую изоляцию и автономную серверную инфраструктуру.

---

## 1. Высокоуровневая архитектура

Система работает на базе **гибридной модели хранения и подхода Offline-First**:
1. **Первичный клиентский уровень (IndexedDB через Dexie.js)**:
   - Все непосредственные взаимодействия, ввод показаний счетчиков, расчет тарифов и просмотр истории выполняются напрямую с локальной IndexedDB.
   - Защита от вытеснения кэша на уровне ОС реализована с помощью **Persistent Storage API** (`navigator.storage.persist()`).
   - Обеспечивает 100% операционную работоспособность в офлайн-среде (например, в подвалах, шахтах коммуникаций, при отключенной сети).
2. **Уровень серверной синхронизации (Self-Hosted VPS)**:
   - Построен на базе **Node.js 22+ (Express + драйвер pg)** и **PostgreSQL 16**.
   - Доступен через строго внутреннее проксирование за Nginx по домену `https://novus-life.online/api/*`.
   - Данные фиксируются в атомарных SQL-транзакциях (`BEGIN ... COMMIT`) для предотвращения состояний неполной синхронизации.
   - Все реляционные сущности используют первичные ключи **UUIDv7** (RFC 9562) для индексации с упорядочиванием по временной метке без фрагментации страниц B-Tree.
3. **Уровень резервного копирования (Google Drive `appDataFolder`)**:
   - Опциональная синхронизация зашифрованных архивов с использованием скрытой папки `appDataFolder` в Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Изолирована от корневых файлов пользователя, что предотвращает случайное ручное удаление.

## 2. Жизненный цикл PWA и WebAPK

### Android (WebAPK)
- На современных Android-устройствах (Chrome, Edge, Samsung Internet) Novus Life соответствует всем критериям WebAPK (валидный манифест, режим отображения standalone, маскируемые и стандартные иконки, зарегистрированный service worker).
- Операционная система генерирует подлинный Android-пакет (`org.chromium.webapk.*`), предоставляющий:
  - Изолированную песочницу Linux UID, отделенную от процессов вкладок браузера.
  - Независимую запись приложения в **Настройки Android -> Приложения -> Novus Life**.
  - Переключатели разрешений на системном уровне (камера для фотофиксации счетчиков, push-уведомления для напоминаний об оплате).
  - Отчетность об использовании хранилища (кэш IndexedDB точно отображается в настройках ОС).

### Desktop (Windows, macOS, Linux)
- Работает в автономном оконном режиме с `window-controls-overlay` и синхронизацией с системной темой.

### Apple iOS
- Работает через веб-приложение Safari («На экран "Домой"») в полноэкранном режиме standalone с оптимизацией для сенсорного ввода.

## 3. Поток данных и криптографические границы

1. **Создание локальной записи**:
   - Пользователь вводит показания приборов учета (например, электричество T1/T2, холодная вода, газ).
   - Разности показаний и суммы вычисляются «на лету» с использованием активного тарифного расписания.
   - Запись сохраняется в IndexedDB с уникальным локальным идентификатором UUIDv7.
2. **Криптографическая защита (Zero-Knowledge)**:
   - Конфиденциальные полезные данные передаются в `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Производный мастер-ключ хранится исключительно в оперативной памяти клиентской среды выполнения (PBKDF2 с 100 000 итераций).
   - На удаленные эндпоинты отправляется только зашифрованный шифротекст.
3. **Синхронизация**:
   - Служба синхронизации передает пакетные записи через `/api/sync`, аутентифицируемые с помощью стандартного JSON Web Token (JWT).
   - База данных PostgreSQL сохраняет строки сущностей с каскадным удалением (`ON DELETE CASCADE`), привязанным к `user_id`.

## 4. Технологическая матрица

| Уровень | Технология | Роль |
|---|---|---|
| **Среда выполнения** | Node.js 26.x Active | Среда выполнения бэкенд-API |
| **База данных** | PostgreSQL 18 (Docker) | Реляционный движок базы данных |
| **Фреймворк API** | Express 5.0.x+ / TypeScript | Маршрутизация и валидация HTTP-API |
| **Первичные ключи** | UUIDv7 (RFC 9562) | Идентификаторы с упорядочиванием по миллисекундам и защитой от коллизий |
| **Фреймворк фронтенда** | Vue 3.5+ Composition API | Реактивный веб-интерфейс |
| **Управление состоянием** | Pinia 3.x | Хранилище клиентского состояния и сессий |
| **Движок стилей** | Tailwind CSS v4 | Утилитарная CSS-система |
| **Локальная база данных** | Dexie.js 4.x (IndexedDB) | Клиентское хранилище данных с приоритетом оффлайн-режима |
| **Криптографический движок** | Web Crypto API | Клиентский AES-256-GCM |
| **Обратный прокси-сервер** | Nginx 1.24+ | SSL-терминация, обратное проксирование, статическое кэширование |

| **Ecosystem** | SGC-NOVUS | Архитектурная принадлежность и жизненный цикл релиза |
