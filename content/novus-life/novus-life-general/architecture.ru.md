# Архитектурный обзор: Novus Life

**Novus Life** — это закрытая платформа для управления коммунальными и домашними расходами, работающая по принципу offline-first, спроектированная и поддерживаемая **SGC-NOVUS** (System Generation Core). Она сочетает в себе клиентскую криптографическую изоляцию и автономную серверную инфраструктуру.

---

## 1. Высокоуровневая архитектура

Система функционирует на базе **гибридной модели хранения и приоритета автономной работы (Hybrid Storage & Offline-First Model)**:
1. **Первичный клиентский уровень (IndexedDB через Dexie.js)**:
   - Все непосредственные взаимодействия, ввод показаний счетчиков, расчет тарифов и просмотр истории выполняются напрямую с локальной IndexedDB.
   - Защита от удаления кэша на уровне ОС реализована с помощью **Persistent Storage API** (`navigator.storage.persist()`).
   - Обеспечивает 100% работоспособность в автономных условиях (например, в подвалах, шахтах коммуникаций, при отключенной сети).
2. **Уровень синхронизации сервера (Self-Hosted VPS)**:
   - Разработан на **Node.js 22+ (Express + pg driver)** и **PostgreSQL 16**.
   - Доступен через строго внутреннее проксирование за Nginx по домену `https://novus-life.online/api/*`.
   - Данные фиксируются в атомарных SQL-транзакциях (`BEGIN ... COMMIT`) для предотвращения состояний частичной синхронизации.
   - Все реляционные сущности используют первичные ключи **UUIDv7** (RFC 9562) для индексации с упорядочиванием по временной метке без фрагментации страниц B-Tree.
3. **Уровень резервного копирования (Google Drive `appDataFolder`)**:
   - Опциональная синхронизация зашифрованных архивов с использованием скрытой папки `appDataFolder` в Google Drive (`https://www.googleapis.com/auth/drive.appdata`).
   - Изолирована от корневых файлов пользователя, что предотвращает случайное удаление вручную.

## 2. Жизненный цикл PWA и WebAPK

### Android (WebAPK)
- На современных устройствах Android (Chrome, Edge, Samsung Internet) Novus-Life соответствует всем критериям WebAPK (корректный манифест, автономный режим отображения, маскируемые и стандартные иконки, зарегистрированный service worker).
- Операционная система создает подлинный Android-пакет (`org.chromium.webapk.*`), предоставляя:
  - Изолированную песочницу Linux UID, отличную от процессов вкладок браузера.
  - Независимую запись приложения в меню **Настройки Android -> Приложения -> Novus-Life**.
  - Переключатели разрешений на уровне системы (камера для съемки показаний счетчиков, push-уведомления для напоминаний об оплате).
  - Отчетность о выделении хранилища (кэш IndexedDB корректно отображается в настройках ОС).

### Десктоп (Windows, macOS, Linux)
- Запускается в автономном оконном режиме (`standalone`) с использованием `window-controls-overlay` и синхронизацией с системной темой.

### Apple iOS
- Запускается через Safari Web App («На экран „Домой“») в полноэкранном автономном режиме с оптимизацией для сенсорного ввода.

## 3. Потоки данных и криптографические границы

1. **Создание локальной записи**:
   - Пользователь вводит показания приборов учета (например, электричество T1/T2, холодная вода, газ).
   - Разности показаний и суммы рассчитываются «на лету» с использованием активного тарифного расписания.
   - Запись сохраняется в IndexedDB с уникальным локальным UUIDv7.
2. **Криптографическая защита (Zero-Knowledge)**:
   - Конфиденциальные полезные данные передаются в `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Производный мастер-ключ хранится исключительно в памяти клиентской среды выполнения (PBKDF2 с 100 000 итераций).
   - На удаленные эндпоинты отправляется только зашифрованный шифротекст.
3. **Синхронизация**:
   - Служба синхронизации передает пакеты записей через `/api/sync`, аутентифицируемые с помощью стандартного JSON Web Token (JWT).
   - База данных PostgreSQL сохраняет строки сущностей с каскадным удалением (`ON DELETE CASCADE`), привязанным к `user_id`.

## 4. Технологическая матрица

| Уровень | Технология | Роль |
|---|---|---|
| **Runtime** | Node.js 26.x Active | Среда выполнения бэкенд-API |
| **Database** | PostgreSQL 18 (Docker) | Реляционная СУБД |
| **API Framework** | Express 5.0.x+ / TypeScript | Маршрутизация и валидация HTTP-API |
| **Primary Keys** | UUIDv7 (RFC 9562) | Идентификаторы с упорядочиванием по миллисекундам и защитой от коллизий |
| **Frontend Framework** | Vue 3.5+ Composition API | Реактивный веб-интерфейс |
| **State Management** | Pinia 3.x | Хранилище клиентского состояния и сессий |
| **Styling Engine** | Tailwind CSS v4 | CSS-система на основе утилит |
| **Local Database** | Dexie.js 4.x (IndexedDB) | Клиентское хранилище данных с приоритетом оффлайн-режима |
| **Cryptographic Engine** | Web Crypto API | Клиентский AES-256-GCM |
| **Reverse Proxy** | Nginx 1.24+ | SSL-терминация, обратное проксирование, статическое кэширование |

| **Ecosystem** | SGC-NOVUS | Архитектурное владение и жизненный цикл релизов |
