# Обзор архитектуры: Novus Life

**Novus Life** — это приватная платформа для управления коммунальными услугами и домашними расходами, работающая по принципу offline-first, разработанная и поддерживаемая **SGC-NOVUS** (System Generation Core). Она сочетает в себе криптографическую изоляцию на стороне клиента с автономной серверной инфраструктурой.

---

## 1. Высокоуровневая архитектура

Система работает на базе **гибридной модели хранения и принципа offline-first (Hybrid Storage & Offline-First Model)**:
1. **Основной клиентский уровень (IndexedDB через Dexie.js)**:
   - Все непосредственные взаимодействия, ввод показаний счетчиков, расчет тарифов и просмотр истории выполняются напрямую в локальной IndexedDB.
   - Защищен от очистки кэша на уровне ОС с помощью **Persistent Storage API** (`navigator.storage.persist()`).
   - Обеспечивает 100% работоспособность в автономном режиме (например, в подвалах, кабельных шахтах, отключенных сетях).
2. **Серверный уровень синхронизации (Self-Hosted VPS)**:
   - Построен на базе **Node.js 22+ (Express + pg driver)** и **PostgreSQL 16**.
   - Доступен через строго внутреннее проксирование за Nginx по домену `https://novus-life.online/api/*`.
   - Данные фиксируются в атомарных SQL-транзакциях (`BEGIN ... COMMIT`) для предотвращения состояний частичной синхронизации.
   - Все реляционные сущности используют первичные ключи **UUIDv7** (RFC 9562) для индексации, упорядоченной по времени, без фрагментации страниц B-Tree.
3. **Уровень резервного копирования (Google Drive `appDataFolder`)**:
   - Опциональная синхронизация зашифрованных архивов с использованием скрытой папки Google Drive `appDataFolder` (`https://www.googleapis.com/auth/drive.appdata`).
   - Изолирован от корневых файлов пользователя, что предотвращает случайное удаление вручную.

## 2. Жизненный цикл PWA и WebAPK

### Android (WebAPK)
- На современных устройствах Android (Chrome, Edge, Samsung Internet) Novus Life соответствует всем критериям WebAPK (валидный манифест, автономный режим отображения, адаптивные и стандартные иконки, зарегистрированный service worker).
- Операционная система создает полноценный пакет Android (`org.chromium.webapk.*`), предоставляющий:
  - Изолированную песочницу Linux UID, отдельную от процессов вкладок браузера.
  - Независимую запись приложения в **Настройки Android -> Приложения -> Novus Life**.
  - Управление разрешениями на системном уровне (Камера для фотофиксации показаний счетчиков, Push-уведомления для напоминаний об оплате).
  - Отчетность о выделении дискового пространства (кэш IndexedDB корректно отображается в настройках ОС).

### Desktop (Windows, macOS, Linux)
- Запускается в автономном оконном режиме с поддержкой `window-controls-overlay` и синхронизацией с системной темой.

### Apple iOS
- Запускается как Safari Web App («На экран „Домой“») в полноэкранном автономном режиме с оптимизацией под сенсорное управление.

## 3. Потоки данных и криптографические границы

1. **Создание локальных записей**:
   - Пользователь вводит показания счетчиков (например, электроэнергия T1/T2, холодная вода, газ).
   - Разность и суммы показаний рассчитываются «на лету» с использованием активной тарифной сетки.
   - Запись сохраняется в IndexedDB с уникальным локальным UUIDv7.
2. **Криптографическая защита (Zero-Knowledge)**:
   - Конфиденциальные данные передаются в `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Производный мастер-ключ хранится исключительно в оперативной памяти клиента (PBKDF2 с 100 000 итераций).
   - На удаленные конечные точки отправляется только зашифрованный шифротекст.
3. **Синхронизация**:
   - Служба синхронизации передает пакеты записей через `/api/sync`, аутентифицируясь с помощью стандартного JSON Web Token (JWT).
   - База данных PostgreSQL сохраняет строки сущностей с каскадным удалением (`ON DELETE CASCADE`), привязанным к `user_id`.

## 4. Матрица технологий

| Уровень | Технология | Роль |
|---|---|---|
| **Среда выполнения** | Node.js 26.x Active | Среда выполнения Backend API |
| **База данных** | PostgreSQL 18 (Docker) | Реляционная СУБД |
| **API-фреймворк** | Express 5.0.x+ / TypeScript | Маршрутизация и валидация HTTP API |
| **Первичные ключи** | UUIDv7 (RFC 9562) | Упорядоченные по миллисекундам идентификаторы без коллизий |
| **Фронтенд-фреймворк** | Vue 3.5+ Composition API | Реактивный веб-интерфейс |
| **Управление состоянием** | Pinia 3.x | Хранилище состояния клиента и сессий |
| **Движок стилизации** | Tailwind CSS v4 | CSS-система класса utility-first |
| **Локальная база данных** | Dexie.js 4.x (IndexedDB) | Клиентское хранилище данных с поддержкой offline-first |
| **Криптографический движок** | Web Crypto API | Шифрование AES-256-GCM на стороне клиента |
| **Обратный прокси** | Nginx 1.24+ | Терминация SSL, обратное проксирование, кэширование статического контента |

| **Экосистема** | SGC-NOVUS | Архитектурное владение и жизненный цикл релизов |
