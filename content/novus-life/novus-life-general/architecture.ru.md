# Обзор архитектуры: Novus Life

**Novus Life** — это приватная offline-first платформа для управления коммунальными и домашними расходами, разработанная и поддерживаемая **SGC-NOVUS** (System Generation Core). Она сочетает в себе клиентскую криптографическую изоляцию и автономную серверную инфраструктуру.

---

## 1. Высокоуровневая архитектура

Система работает на основе **модели гибридного хранения и Offline-First**:
1. **Основной клиентский слой (IndexedDB через Dexie.js)**:
   - Все текущие взаимодействия, ввод показаний счетчиков, расчеты тарифов и просмотр истории выполняются напрямую в локальной IndexedDB.
   - Защищен от удаления кэша на уровне ОС с помощью **Persistent Storage API** (`navigator.storage.persist()`).
   - Обеспечивает 100% работоспособность в автономных условиях (например, в подвалах, технических шахтах, изолированных сетях).
2. **Серверный слой синхронизации (Self-Hosted VPS)**:
   - Построен на базе **Node.js 22+ (Express + драйвер pg)** и **PostgreSQL 16**.
   - Доступен исключительно через внутреннее проксирование за Nginx по домену `https://novus-life.online/api/*`.
   - Данные фиксируются в атомарных SQL-транзакциях (`BEGIN ... COMMIT`) для предотвращения частичной синхронизации.
   - Все реляционные сущности используют первичные ключи **UUIDv7** (RFC 9562) для индексации с упорядочиванием по меткам времени без фрагментации страниц B-Tree.
3. **Слой резервного копирования (Google Drive `appDataFolder`)**:
   - Опциональная синхронизация зашифрованных архивов с использованием скрытой папки Google Drive `appDataFolder` (`https://www.googleapis.com/auth/drive.appdata`).
   - Изолирован от корневых файлов пользователя, что предотвращает случайное ручное удаление.

## 2. Жизненный цикл PWA и WebAPK

### Android (WebAPK)
- На современных устройствах Android (Chrome, Edge, Samsung Internet) Novus Life соответствует всем критериям WebAPK (валидный манифест, режим отображения standalone, маскируемые и стандартные иконки, зарегистрированный service worker).
- Операционная система создает полноценный пакет Android (`org.chromium.webapk.*`), предоставляющий:
  - Изолированную песочницу Linux UID, отдельную от процессов вкладок браузера.
  - Независимую запись приложения в **Настройки Android -> Приложения -> Novus Life**.
  - Системные разрешения (Камера для фотофиксации показаний счетчиков, Push-уведомления для напоминаний об оплате).
  - Отчетность о выделении хранилища (кэш IndexedDB корректно отображается в настройках ОС).

### Desktop (Windows, macOS, Linux)
- Работает в автономном оконном режиме (standalone) с поддержкой `window-controls-overlay` и синхронизацией с системной темой.

### Apple iOS
- Запускается через Safari Web App («На экран "Домой"») в полноэкранном режиме standalone с оптимизацией под сенсорное управление.

## 3. Потоки данных и криптографические границы

1. **Создание локальных записей**:
   - Пользователь вводит показания коммунальных услуг (например, электричество T1/T2, холодная вода, газ).
   - Разница и суммы показаний рассчитываются на лету с использованием активной тарифной сетки.
   - Запись сохраняется в IndexedDB с уникальным локальным UUIDv7.
2. **Криптографическая защита (Zero-Knowledge)**:
   - Чувствительные данные передаются в `cryptoVault.encrypt()` (Web Crypto API AES-256-GCM).
   - Производный мастер-ключ хранится исключительно в оперативной памяти клиента (PBKDF2 с 100 000 итераций).
   - На удаленные конечные точки отправляется только зашифрованный шифротекст.
3. **Синхронизация**:
   - Служба синхронизации передает пакеты записей через `/api/sync`, аутентифицированные с помощью стандартного JSON Web Token (JWT).
   - База данных PostgreSQL сохраняет строки сущностей с каскадным удалением (`ON DELETE CASCADE`), привязанным к `user_id`.

## 4. Матрица технологий

| Уровень | Технология | Роль |
|---|---|---|
| **Среда выполнения** | Node.js 26.x Active | Среда выполнения Backend API |
| **База данных** | PostgreSQL 18 (Docker) | Реляционная СУБД |
| **API-фреймворк** | Express 5.0.x+ / TypeScript | Маршрутизация и валидация HTTP API |
| **Первичные ключи** | UUIDv7 (RFC 9562) | Упорядоченные по миллисекундам идентификаторы без коллизий |
| **Frontend-фреймворк** | Vue 3.5+ Composition API | Реактивный веб-интерфейс |
| **Управление состоянием** | Pinia 3.x | Хранилище состояния клиента и сессий |
| **Движок стилизации** | Tailwind CSS v4 | CSS-система на основе утилит (utility-first) |
| **Локальная БД** | Dexie.js 4.x (IndexedDB) | Клиентское хранилище данных с поддержкой offline-first |
| **Криптографический движок** | Web Crypto API | Клиентское шифрование AES-256-GCM |
| **Обратный прокси** | Nginx 1.24+ | Терминация SSL, обратное проксирование, кэширование статики |

| **Экосистема** | SGC-NOVUS | Архитектурное владение и жизненный цикл релизов |
